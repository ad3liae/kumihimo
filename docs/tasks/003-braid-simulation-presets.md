# Task 003: 組み方プリセットとシミュレーション結果

- 状態: Blocked
- ブロック理由: 初期プリセット、生成規則、正解例の確定待ち
- 優先度: 高
- 仕様: `docs/specifications/project-editor.md`

## 目的

現在の糸本数と位置別の色から、アプリ内蔵の各組み方で得られる完成イメージを生成し、作品編集画面で比較・選択できるようにする。

## 着手前に必要な入力

- 初期対応する組み方の名称と対応糸本数
- 各組み方の手順または変換規則
- 正しさを検証できる既知の糸配置
- 各既知配置に対する期待パターンまたは期待画像

## 想定実装範囲

- アプリ内蔵プリセットのデータ構造
- UIから独立したシミュレーション処理
- 糸本数とプリセットの互換性判定
- 色変更時の結果再計算
- 計算中、成功、部分失敗、全失敗の画面状態
- 結果リストと単一選択
- 「組み方をまだ決めない」に戻す操作
- 既知入力に基づくシミュレーションの自動テスト

## 品質条件

- 見栄えだけの仮画像を実際の完成結果として表示しない。
- 同じ入力から常に同じ結果を生成する。
- 1つのプリセットの計算失敗で、他の結果や作品保存を妨げない。
- 選択したプリセットIDを保存・再読込できる。
