# Task 003: 組み方プリセットとシミュレーション結果

- 状態: 実装済み（実物照合待ち）
- 精度上の留保: 資料から読み取った移動規則は実装済み。糸の上下関係、張力、断面形状は実物との照合が必要
- 優先度: 高
- 仕様: `docs/specifications/project-editor.md`

## 目的

現在の糸本数と位置別の色から、アプリ内蔵の各組み方で得られる完成イメージを生成し、作品編集画面で比較・選択できるようにする。

## 採用した初期入力

- 組み方: 丸源氏
- 対応糸本数: 16本
- 変換規則: 下外側2本→上内側、上外側2本→下内側、右外側2本→左内側、左外側2本→右内側を1周期とする
- 初期位置: 位置1を12時方向として時計回りに1〜16
- 表示上の扱い: 実物照合前の暫定シミュレーションと明記する

## 想定実装範囲

- アプリ内蔵プリセットのデータ構造
- UIから独立したシミュレーション処理
- 糸本数とプリセットの互換性判定
- 色変更時の結果再計算
- 計算中、成功、部分失敗、全失敗の画面状態
- 結果リストと単一選択
- 「組み方をまだ決めない」に戻す操作
- 既知入力に基づくシミュレーションの自動テスト
- 2Dサムネイルから開く、回転・拡大縮小可能な3D詳細

## 品質条件

- 見栄えだけの仮画像を実際の完成結果として表示しない。
- 同じ入力から常に同じ結果を生成する。
- 1つのプリセットの計算失敗で、他の結果や作品保存を妨げない。
- 選択したプリセットIDを保存・再読込できる。

## 実装内容

- 16本の場合だけ丸源氏プリセットを結果一覧へ表示する。
- 4本、8本、12本では16本を選ぶよう案内し、配色だけの保存を維持する。
- 組み方の1周期をUI非依存の計算として実装する。
- 計算した各糸の経路から2DサムネイルとRealityKit用チューブメッシュを生成する。
- 3D詳細で1本指回転、ピンチ拡大縮小、ダブルタップリセット、代替操作ボタンを提供する。
- 丸源氏の選択、未選択への復帰、本数非互換時の解除、保存と再読込を実装する。

## 検証

- 1周期後の16本の配置と、全周期で糸が欠落・重複しないことを自動テストする。
- 位置別の色が3D経路へ維持され、生成座標が有限値であることを自動テストする。
- チューブメッシュの頂点、法線、三角形数を自動テストする。
- プリセットの選択・解除とSwiftDataでの往復保存を自動テストする。
- iPhoneシミュレータで16本の編集画面から3D詳細を開けることをUIテストする。

## 未解決事項

- 各交差点の厳密な上下関係
- 実物に近い締め具合、糸径、断面形状
