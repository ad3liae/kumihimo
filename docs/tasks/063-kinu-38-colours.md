   - `ThreadColorCatalog.color(for:)` と `contains` は、古いIDを渡されても新しい色を返す（読み替え表をデータとして持つ）。
   - 保存済みの作品は、開いたとき古いIDのまま正しい色で描かれ、次に保存したとき新しいIDで書かれる。
