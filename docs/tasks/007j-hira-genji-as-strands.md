## なぜこうなったか（レビュー側の判断の誤り）

Task 007E 第1版は、丸源氏の糸の仕組み（`BraidStrandSurfaceBuilder`）の上に平源氏を載せようと
した。**方向は正しかった。** しかし断面・畝・上下・撚り・谷・縦横比・照明・共通化を一度に
1,874行変えて穴を開け、差し戻した。

差し戻しのあと、レビュー側は**「もう一度あの規模の失敗をしない」ことを優先し、Task 007F の
格子の上に升を張る道を選んだ。** それが最短で「組紐に見える絵」に届く道だったからである。
**しかしその道は表現として誤っていた。** 糸を持たない面に、上下・位相・lap を1つずつ浮き彫りで
足していくことになり、007E 段階3、007G、007H、007I はすべて**その表現と戦う仕事**だった。

**作者はタイルを並べろとは一度も言っていない。** 段階を分けるという工程上の判断は正しかったが、
その工程を誤った表現の上で回した。

## 作り方

**丸源氏と同じく、糸で作る。** `BraidStrandSegment` / `BraidStrandSurfaceBuilder` を平源氏の
糸の経路に対して使えるようにする。丸源氏の生成メッシュは**1頂点も変えない**（ハッシュで示す）。

- **縦糸（1・3面、8本）**：紐に沿って走り、横糸の**上**を通る。腹は糸自身の断面で出る。
- **横糸（2・4面、8本）**：面の中央4列の**下**を横切り、**縁で向こうへ回って**戻る。
  **縁に見えるのは横糸の折り返しそのもの**である。升ではない。
- 上下は `layer` で決まり、**糸が糸の上を通る**。lap は丸源氏と同じ仕組みで出る。
- 位相は Task 007G の値を糸の到着の時刻として与える。
