#### ただし絵は合っていない。原因は比率ではない

作者から「形状が全く似ていない」との指摘があり、レビューでも同意する。ここで重要なのは、**周期が合っているのに絵が合っていない**という点である。

つまり周期は一致したが、**周期の中に入っている物が別物**である。これは比率の問題ではなく、格子の位相構造（どこで途切れるか）と起伏の問題であり、**段階3（交差の上下）と段階4（畝・AO）の担当**である。段階2.5の範囲ではない。

このため、以下を守ること。

## 段階5: 畝の高さを資料から決め直す（2026-09-05 追加。最終段階）

### レビュー側の実測（bookA p96 の完成写真、白い誌面を背景に）

紐幅 152.1px、1手のピッチ 43.6px。上辺のシルエットを列ごとに取り、ピッチ2つぶんの

| --- | ---: | ---: |

### 物理からの独立した裏づけ

半厚は糸1本の直径である（断面の周長が糸16本ぶん、紐は糸2本ぶんの厚み）。よって
`crestHeightRatio = 0.12` は「**糸が自分の直径の12%しか盛り上がっていない**」という意味に

0.12 は自然ではない。** 実測（3.4〜4.3倍 → 0.41〜0.52）と独立に同じところを指している。

**`crestHeightRatio` ひとつだけを変える。他は触らない。**

1. 上の実測を**自分で再現する**（手順は上に書いたとおり。高域の取り出し方まで含めて）。
2. **2つ目の資料でも測る。** 15%以内で一致しない場合は採用せず、食い違いを報告して止まる。
3. 一致したら `crestHeightRatio` をそこから導く。**先に値を決めない。**

### 段階5 の判定（2026-09-05）— 2資料の条件を外し、0.45 を採用する

実装側が合格条件どおり止まった。判断はレビュー側で行う。**`crestHeightRatio = 0.45` を

| 見積り | 値 |
| --- | --- |
| bookA p96、実装側の辺の取り方（σ 5.29%） | 0.554 |
| bookA p96、レビュー側の辺の取り方（σ 3.9%） | 0.408 |

| **3つが重なる範囲** | **0.41〜0.50** |
| 現在値 | 0.12（どれとも重ならない） |

2つの読みの差は「写真のぼけた辺をどの高さで取るか」という既知の系統差であり、雑音では

ないが、条件の目的は満たしている。**

**0.12 に留まることは確実に誤りであり、0.45 を採ることは誤りである可能性がある。**
前者のほうが確実に悪い。

採用値は重なる範囲の中央 **0.45**。これは Task 005I で `patternAspectRatio = 0.65` を

3つの見積りと採用理由を書くこと。**

実装側の較正式 **σ(%) = 9.55 × 頂** は良い成果である。以後この種の照合を線形の読み取りに
できる。Task 005J でも使うこと。
