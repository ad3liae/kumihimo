# Task 009: 江戸八つ組8玉の完成シミュレーション

- 状態: Ready（移動規則の独立資料照合が必要）
- 優先度: 高
- 前提: Task 008が完了していること
- 仕様: `docs/specifications/braid-preset-expansion.md`

## 目的

8玉の江戸八つ組を独立プリセットとして追加し、直線、点描〆、入組みの配色傾向を丸紐の2D／3D完成面へ反映する。

## 参考出力

参考方式IDは `edoyatu`、断面表示は丸紐である。配列は位置1〜8の順。

- 直線: `[#fecd92, #4f76c1, #fecd92, #4f76c1, #fecd92, #4f76c1, #fecd92, #4f76c1]`
- 点描〆: `[#a6cd74, #272532, #272532, #272532, #ef7a66, #272532, #272532, #272532]`
- 入組み: `[#faffff, #fbbd80, #6386ca, #fbbd80, #6386ca, #fbbd80, #fbbd80, #6386ca]`

## 必須実装

- 安定した江戸八つ組IDを追加し、8本用結果一覧へ表示する。
- 八つ金剛組とは別の移動規則と表面対応表を持つ。
- 独立資料で確認した1周期を順序付きイベントとして実装する。
- 3つの比較例を同じ汎用表面生成器で再現する。
- 八つ金剛組と同じ丸紐Viewerを共有しても、表面周期データは共有しない。
- 結果生成失敗が八つ金剛組の表示や作品保存へ波及しない。

## 必須テスト

- 8本以外では候補に出ない。
- 1周期・複数周期で糸IDが保存される。
- 3フィクスチャの表面空間シグネチャが互いに異なり、期待値と一致する。
- 八つ金剛組と同一入力を与えても、方式固有の結果になることを確認する。
- 端面なし、円周継ぎ目、長尺タイル継ぎ目、保存往復を検証する。

## 完了条件

- 江戸八つ組が八つ金剛組とは別に選択・保存できる。
- 直線、点描〆、入組みの配置傾向を参考出力と比較できる。
- 既存の丸源氏、平源氏、八つ金剛組に回帰がない。
