## 044-1. 「固める前に張る」の局所試験（保存状態から 1 手だけ。模型の変更はこの試験の中だけ、`FIX=taut`）

### 規則（同僚の 15 回目の答えのとおり。追加規則として試す）

手 h の `cover` で、糸 t の判定に合った最も外の球（先端 `free[t][cut]`）が決まったら、固める前に、既存の固定端から先端までの区間を張る:

1. **既存の固定端**（`made[t][-1]`）は**位置と材料を固定**する（今までどおり動かない。材料はそこを通らない）。
2. **新しい交差点**（先端の位置）は**位置を固定するが、糸の材料は通過できる仮想のガイド**として扱う——区間が短くなった分の材料は、
   ガイドを通って**縁側の自由部**（`free[t][:cut]`）へ、さらに縁の出し入れで**縁の外**へ移る。伸びない糸なので、**両端の材料を固定したまま
   区間を短くすることはできない**——短くなるのは材料がガイドを通り抜けるから。
3. 区間の張りは 022 の張り（縮め 0.1・置き直し・settle。settle は全部の球を相手に現行どおり——非貫入・台の押し出し・上限 d/4・
   040 の 10 の検査）。区間の置き直しは既存の固定端からガイドまでを d 間隔で置き直し、余った材料は縁側へ渡す（縁側は現行どおり置き直しと
   縁の出し入れ）。**短縮した長さが、縁側の自由部または縁の外へどれだけ移ったかを記録する**（区間の弧長の減少 ＝ 縁側の弧長の増加 ＋
   縁から払い出した長さ。**球の削除で長さを消しただけにならないこと**を人工例で確かめる）。
4. **張った後、元の固定条件（乗られている・他の糸の固定球か芯に 1.25 d 以内で触れている・縁の端でない）がガイドの位置の球で成立しているかを
   再確認する**。成立していれば既存固定端からガイドまでを固める。**外れていれば固定せず**（その手はその糸を固めない）、その結果を記録する。
5. 乗った区間の規則（still）・判定の条件・閾値・縮めの値・送り・上限・検査は変えない。**どう実装したかを先に書く**（ガイドの作り、置き直し、
   払い出し、再確認）。作りに迷ったら止まって報告——仕様を勝手に足さない。

### 試験

まとめて固まる手を 4 つ——still の **27・30 手目**、next の **29・34 手目**。**各手は同じ開始状態（`start-hNN.pkl`）から `FIX=now` と
`FIX=taut` を回して比べる**（検査つき）。still の `FIX=now` は保存済みの `h27`・`h30` と球ごとに一致するはず（一致しなければ止まって報告）。
**next 由来の開始状態でも `FIX=now` の対照をその場で作る**——元の `FIX=next` の終了状態を対照にはしない。

各手・各 run について、対照と試験で:

1. 固まった球数と run の長さ。**端点は別欄**——既存固定端の r・z、先端（ガイド）の r・z（端点を固定するので、区間の最大半径は端点の半径より
   小さくできない。「最大半径が 0.5 d 縮む」を一律の判定にしない）。
2. **区間内部の形**——内部の r の最大・中央値、z の中央値、下に何も無い球の数、区間の弧長と両端の直線距離（比だけでは、障害物を回るための
   長さと余りを区別できないので、比は参考）。
3. **移った長さ**——区間の弧長の減少、縁側の自由部の弧長の増加、縁から払い出した長さ（3 つが釣り合うこと）。
4. 張りの前後で区間の球がどれだけ動いたか（最大・中央値）、何 sweep で静まったか、settle の上限到達、上限が抑えた球。
5. 貫入 (a)、検査（接触・未確定）、縁の出し入れ、その手の時間。
6. **再確認の結果**——ガイドの球が固定条件を満たしたか。満たさなかった run は固定せず、その旨。
7. run が**どこへ行ったか**を 1 行——**下がる／内側へ寄る／浮く／変わらない**——を、内部の r と z の変化・移った長さ・接触で裏づける。

### 044-1: 止まった点（止まる条件 (d)。`FIX=taut` は実装していない）

**規則のうち、既存の道具でそのまま書ける部分**（迷いは無い）:

- 既存の固定端（`made[t][-1]`）は位置も材料も動かない——`made` にある球は解法がもともと保持している。
- 新しい交差点（先端の位置）を**張りのあいだ保持する**——settle の held マスクに先端の球を足すだけで書ける。
- 張りそのもの（縮め 0.1・settle・非貫入・台の押し出し・上限 d/4・040 の 10 の検査）は現行の道具のまま。
- 縁側の自由部が張りのあいだ動けること（材料が縁側へ移るために要る）と、乗った区間の扱い（`REST=still` は射影で動かせる）は
  両立する——現行仕様 2 のままでよい。
- 「移った長さ」の釣り合い（区間の弧長の減少 ＝ 縁側の弧長の増加 ＋ 縁から払い出した長さ）は、どの作りでも測れる。

**書けない部分（ここで止めた）**: **張った後の区間の置き直し**である。既存の `taut.respace`／`respace_free` は
**固定端から外へ向かって d 間隔で並べ、余りを縁の端へ逃がす**作りで（`respace` の doc comment: "from the braid end, and let the
surplus run off the tama end"）、**途中の点を保持する口が無い**。ガイド（先端の位置）を保ったまま区間だけを置き直すには、次の
どちらかを決めねばならず、**どちらも指示書に書かれていない**:

- **(A) 区間専用の置き直しを作る**（既存固定端からガイドまでを d 間隔で並べ、ガイドを球のまま保つ）。ガイドに球が残るので、
  指示書 4 の「**ガイドの位置の球**で固定条件を再確認する」がそのまま読める。**代わりに、区間の中に d 未満の繋ぎが 1 本できる**
  （弧長は d の整数倍とはかぎらない）。041 の検査は「縁以外の 0.5 d 未満の繋ぎ」を数えており、これまでの走りはすべて 0 である。
- **(B) 現行の置き直しをそのまま使う**（自由部全体を固定端から d 間隔で並べ、余りは縁へ）。繋ぎは d のまま、余りは縁の 1 本だけ、

  もう一度かけ、合った球まで固める」と読み替えることになる。

**この違いは飾りではない**: (A) と (B) では「移った長さ」がどこに溜まるか（区間の中か、縁側か）が変わり、044-1 の 3 の測定そのものが
変わる。**推し（決めるのは審査側）: (B)**。理由は 3 つ——既存の道具だけで書ける、検査の「縁以外の短い繋ぎ 0」を崩さない、
「元の固定条件を再確認する」の最も素直な読みが「判定をもう一度かける」である。(B) を採るなら、指示書 4 の文言を
「ガイドの位置の球で」から「張ったあとに判定をもう一度かけ、合った球（＝新しい先端）まで固める」に直していただきたい。
