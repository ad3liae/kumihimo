## 044-1. 「固める前に張る」の局所試験（保存状態から 1 手だけ。模型の変更はこの試験の中だけ）

**規則（試験の中だけ）**: 手 h の `cover` で、糸 t の判定に合った最も外の球（`free[t][cut]`）と固定端を**握り**、そのあいだの run
（`free[t][cut:]`）を**張ってから**固める。「張る」は 022 の張り（縮め 0.1・置き直し・settle）を run に当てること——ただし run の両端は
動かさず、run の余った材料は縁側（`free[t][:cut]`）へ払い出す（run の球数は減ってよい。縁側は現行どおり置き直しと縁の出し入れ）。
settle は全部の球を相手に現行どおり（非貫入・台の押し出し・上限 d/4・10 の検査）。張り終えたら run（握った球から固定端まで）を固める。
乗った区間の規則（still）・判定の条件・閾値・縮めの値・送りは変えない。**どう実装したかを先に書く**（run の置き直しをどうしたか、
払い出しをどうしたか、握った球の扱い）。作りに迷ったら止まって報告——仕様を勝手に足さない。

**試験**: まとめて固まる手を 4 つ——still の **27・30 手目**、next の **29・34 手目**（`start-hNN.pkl` から 1 手だけ回す。検査つき）。
各手について、現行（`FIX=now`、対照。still の手は保存済みの結果と一致するはず）と「固める前に張る」で:

1. その手に固まった球数と run の長さ、run の r の中央値・最大、run の z の中央値、run の弧長／両端距離の比、下に何も無い球の数
   （044-0 の 2 と同じ測り方）。
2. 張りの前後で run の球がどれだけ動いたか（最大・中央値）、何 sweep で静まったか、settle の上限到達、上限が抑えた球。
3. 貫入 (a)、検査（接触・未確定）、縁の出し入れ、その手の時間。
4. run が**どこへ行ったか**を言葉で 1 行（天辺に沿って下がった／脇を回った／浮いた／変わらない）。r と z の変化で裏づける。
5. 人工例 1 つ（`Scripts/task044/taut_check.py`）: 小さな状態（糸 2 本・芯数球）で、両端を握った run が (i) 障害物の上を張って下がる、
   (ii) 余りが縁側へ払い出される、(iii) 握った 2 球は動かない、を確かめる。

script は `Scripts/task044/taut_then_fix.py`（`Scripts/task043/delayed.py` の `Braid043` を継承し `cover()` だけ上書き。`FIX=taut` で有効。
`checked_run.py`・`probe.py`・040〜043 の script は変えない）。
