### 張力の前提は 016 に入っていたか — **入っていない**（3つのうち2つ）

作者の前提（`docs/architecture.md`「組み台の力学」）は3つある。016 の試作1／2b と突き合わせる。

| 前提 | 016 に入っていたか | 証拠 |
|---|---|---|
| 玉が鏡の縁を越えて垂れ、**外向き（下方）へ引き続ける** | **入っていない** | 玉の位置は**鏡の面の上**に運動学的に固定されていた |
| 紐の下端の錘が**下へ引き続ける** | **入っていた** | 尾の先端の粒に `TAKEUP / 16` を毎ステップ加えていた |
| **ゆるんだ糸は無い。どの区間も張った直線** | **入っていない。破れていた** | 「糸は…紐にならず**鏡の上に溜まる**」 |

1つ目の証拠は `braid.c` の `applyForces()` である。

```c
// The tama's position is imposed, carried or not: the hand puts it where
// the rule says. The tension is not a force on this bead — it is the
// elastic first segment below, and the tama pays out yarn when that
// segment's tension reaches its weight. See feed().
double a = slotAngle[y];
pos[i] = v3((RIM + 1.0) * cos(a), (RIM + 1.0) * sin(a), R);
```

**玉は鏡の面の高さ（`z = R`、糸の半径）に、縁のすぐ外（`RIM + 1.0`）で固定されている。**
垂れていない。**外向きの引きは、力としてはどこにも入っていない。** 玉が果たしていた役割は
「糸を繰り出す定荷重の供給源」（`feed()`）だけであって、**紐を外へ張る役ではない。**

そのため、016 で糸が鏡の上を走る区間は**張られていない**。016 が特定した第1の原因
（「鏡の上の水平部分と穴を下る垂直部分が角で繋がっているだけなので、糸は角を滑って引き出される」）
は、まさに**この区間に外向きの張力が無いことの言い換え**である。

**時系列も一致する。** 016 は 2026-09-06、作者が張力の前提を置いたのは 2026-09-07
（Task 021b-1）である。**016 は前提が存在しない時点の試みである。**

   両端（組み点と縁）で引かれた**張った区間**になる。016 では玉が面の上に固定され、この張力が

## 3. 糸（準静的）

- **直径 d のカプセルを繋いだ鎖。** 位置だけを持つ。**質量も慣性も持たない。**
- 一本の糸の**自由部分**は、**束から出ている点**（＝組み点）から**玉の側の端**（＝鏡の縁で
  糸が離れる点）までである。**その先の垂れている糸と玉は模型に入らない。** 玉がしているのは
  「縁の外へ張る」ことだけで、それは**端を縁に留めること**で表せる。
- **束に取り込まれた区間は剛体として固定**し、以後1度も動かさない。

### 張力は「張った道」として入る（**作者の決定**）

**張った糸とは、両端のあいだで、他のすべての外を通る最短の道である。** 力を数えない。
拘束は**2つだけ**。

  1. 隣り合う球の距離が d
  2. 太さ d のカプセルどうしが通り抜けない（線分間の最短距離。**021d のカプセル版の射影**）

**鏡は静的な障害物**として同じ非貫入に入る。**糸は当たった糸の上で曲がり、当たっていない
区間は真っ直ぐになる。** これで張力の効果は尽きている。

### 組み点の深さは錘の比から一度だけ決める

`docs/architecture.md`「組み上がりの解き方は準静的である」に導出がある。

    糸の本数 × 玉 × sin(水平からの角度) ＝ 吊りおもり

**16本・玉 100 g・吊り 570 g → 組み点は鏡の上面から −1.658 d。以後は定数。**
**022-1 の動力学で「結び目が穴の口へ上がる」と出たのと同じことを、2つの錘から解いたもの
である。**

### 束の周りに糸が立つ半径

**中心間距離 d で互いに接して立つ**ので、中心は1辺 d の正16角形の頂点、半径は
**d ÷ (2 sin(π/16)) = 2.5629 d**。**円周を 16 d と読むと隣どうしが 0.9938 d になり、
何も起きないうちから 0.6% 食い込む**（実際に残差が 6.5e-3 d で止まった。この読みに直して
2.3e-4 d になった）。

### 組み始め（種）は実際の組み始めと同じにする（**作者の決定**）

**糸の端を一点に結び、そこに吊りおもりを掛けて穴の下へ垂らし、糸を 32 の角度へ放射状に置いて
玉を縁に掛ける。** 準静的の模型では、これは「**16本が組み点から出て、それぞれの角度の縁まで
張る**」ことである。

- **組み始めの数サイクルは実物でも乱れる。端の除外区間とする。**
- **これで組めなければ、別の種に黙って切り替えない。組めなかった様子を報告して止まる。**

## 4. 一手（**質量・重力・慣性・減衰・時間刻みを持たない**）

  1. **運ぶ**  指定の糸の自由部分（束から出ている点から玉まで）を、**他の全部の糸の上を
               通して**新しい位置（鏡の縁の角度）へ移す。初期配置は**全部の上を越える高い弧**
               でよい。**閉じ移動も同じ。**
  2. **張る**  玉の側の端を縁の位置に固定し、束から出ている点を固定して、**糸の長さを縮める**
               （距離拘束を保ったまま余りを縁側へ送る）。収束判定は残差（021 と同じ）。
  3. **固定**  張り終えた糸のうち、**束に取り込まれた区間（組み点より下）を剛体として固定**し、
               以後動かさない。**新しい交差が組み点の上に積まれた分だけ、固定した束全体を
               下へ送る。送る量は新しい交差が占めた高さそのもので、別に決めない。**
  4. **記録**  各手の後の全カプセル中心を書き出す（021 の判定道具がそのまま読める形）。

**上下は運ぶ順序だけで決まる。** 後から置いた糸が、途中の糸の上を通る。**別の上下規則を
置かない。**

**ピッチは置いた結果として出る。3d と 0.3665 と並べて記録するだけで、合わせにいかない。**
