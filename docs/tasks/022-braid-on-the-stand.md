### 張力の前提は 016 に入っていたか — **入っていない**（3つのうち2つ）

作者の前提（`docs/architecture.md`「組み台の力学」）は3つある。016 の試作1／2b と突き合わせる。

| 前提 | 016 に入っていたか | 証拠 |
|---|---|---|
| 玉が鏡の縁を越えて垂れ、**外向き（下方）へ引き続ける** | **入っていない** | 玉の位置は**鏡の面の上**に運動学的に固定されていた |
| 紐の下端の錘が**下へ引き続ける** | **入っていた** | 尾の先端の粒に `TAKEUP / 16` を毎ステップ加えていた |
| **ゆるんだ糸は無い。どの区間も張った直線** | **入っていない。破れていた** | 「糸は…紐にならず**鏡の上に溜まる**」 |

1つ目の証拠は `braid.c` の `applyForces()` である。

```c
// The tama's position is imposed, carried or not: the hand puts it where
// the rule says. The tension is not a force on this bead — it is the
// elastic first segment below, and the tama pays out yarn when that
// segment's tension reaches its weight. See feed().
double a = slotAngle[y];
pos[i] = v3((RIM + 1.0) * cos(a), (RIM + 1.0) * sin(a), R);
```

**玉は鏡の面の高さ（`z = R`、糸の半径）に、縁のすぐ外（`RIM + 1.0`）で固定されている。**
垂れていない。**外向きの引きは、力としてはどこにも入っていない。** 玉が果たしていた役割は
「糸を繰り出す定荷重の供給源」（`feed()`）だけであって、**紐を外へ張る役ではない。**

そのため、016 で糸が鏡の上を走る区間は**張られていない**。016 が特定した第1の原因
（「鏡の上の水平部分と穴を下る垂直部分が角で繋がっているだけなので、糸は角を滑って引き出される」）
は、まさに**この区間に外向きの張力が無いことの言い換え**である。

**時系列も一致する。** 016 は 2026-09-06、作者が張力の前提を置いたのは 2026-09-07
（Task 021b-1）である。**016 は前提が存在しない時点の試みである。**

### したがって 022 は 016 と別の試みである（別である点）

1. **玉が垂れる。** 玉は鏡の縁を越えて外へ垂れ、**外向き下方の張力を生む**。鏡の上を走る区間は
   両端（組み点と縁）で引かれた**張った区間**になる。016 では玉が面の上に固定され、この張力が
   無かった。
2. **糸を繰り出さない。** 016 の `feed()`（張力で糸を継ぎ足す実装）は 022 には無い。糸は最初から
   十分な長さがあり、**玉が下がるぶんだけ組み点へ入る。** 016 の第2の原因（送りの暴走）は、
   **仕組みごと消える。**
3. **engine が違う。** 自作の XPBD（球の鎖・位置ベース）ではなく、**剛体カプセルの連鎖を Jolt に
   解かせる。** 摩擦・接触・スリープは engine のものを使い、値を記録する。

**016 の結論のうち、そのまま立つもの**（022 でも再挑戦しない）:
**完成した紐の平衡からは1手あたりの送りは出ない**（試作2、原理的）。**この道は二度と試さない。**

### 仮置きの値（**すべて d を単位とする。d = 糸の直径**）

一般的な丸台（鏡の直径 約 100 mm、中央の穴 約 30 mm、鏡面の高さ 約 150 mm）を、
組紐用の絹糸 **d ≈ 1 mm** で割った値を採る。

| 量 | 仮置き | 出所 |
|---|---|---|
| 鏡の半径 | **50 d** | 一般的な丸台 100 mm ÷ 2 ÷ d |
| 穴の半径 | **15 d** | 一般的な丸台 30 mm ÷ 2 ÷ d |
| 鏡の縁の丸め半径 | **1 d** | 仮置き。糸が角を越える所なので効きうる |
| 鏡の面の高さ（玉が垂れる余地） | **150 d** | 一般的な丸台の高さ |
| ノッチ | **32個。鏡の縁に等間隔**（11.25°ごと） | bookC の番号ディスクが32分割であること |

**016 の試作は鏡の半径 14 d・穴の半径 6 d だった**（`braid.c` の `RIM` / `HOLE`）。
**実物の 1/3 以下である。** 鏡の上を走る区間の長さと角度が違うので、**016 の数字を 022 の
予想に使わない。**

### ノッチの番号と角度

- **番号は bookC のディスクのもの**（1〜32）。`Scripts/task021/braid_geometry.py` の
  `DISK_TO_STAND` が、休むノッチ16個を台の位置1〜16へ写している。
- **休むノッチは8組（隣り合う2ノッチ）、組の間は3ノッチ。この8組は丸源氏の閉じの対と一致する**

- **番号が増える向き（時計回りか反時計回りか）は決めない。** これは **丸源氏の E/W の列順の

## 3. 糸

- **直径 d の剛体カプセルを関節で繋いだ鎖。** 長さは、玉が鏡の縁から垂れ、組み点を通り、
  穴を下って錘に届くまで**十分に長く**取る。**途中で継ぎ足さない**（016 の `feed()` は無い）。
- **上端は玉。** 鏡の縁を越えて外へ垂れ、**一定の張力で外向き下方へ引く。**
  重さは **bookA/bookB の 100 gf**。
- **束の下端は錘。** 16本の端を結んだところに付き、**穴を通って下へ一定の張力で引く。**
  重さは **bookA/bookB の 190 gf × 3〜4 = 570〜760 gf**。
- **摩擦は engine の既定値を使う。** **値を読み取って記録する**（**模型の定数ではない**。
  022-1 で Jolt のソースから確認して書く）。**合わせるために動かさない。**
- **力の単位は玉1個（100 gf）とする**（016 と同じ）。長さの単位は d ひとつ。

### 判断を仰ぐ（実装前に確認したい2点）

1. **「一定の張力」を、質量＋重力で出すか、力を直接加えて出すか。**
   前者（玉と錘を質量のある剛体にし、重力で引かせる）を採ると、**引きの向きを手で与えずに
   済む**——玉が縁から垂れれば外向き下方は幾何の帰結になる。後者だと向きを手で決めることに
   なり、規則を1つ足すのに近い。**前者を推すが、作者の言葉は「一定の張力で外向き下方へ」なので、
   選ばずに確認する。**
2. **組み始め（種）をどう作るか。** 016 が死んだのはここである。候補は
   (a) 16本を結んだ端を錘で下へ引き、糸は鏡の上を放射状に張った状態から始める、
   (b) 021 の占有履歴から数手ぶんの交差だけを与えた短い紐から始める（016 段階2b の方式。
   **寸法は与えず、交差の順序だけ**）。**どちらも種の依存を持つので、種2つの試験は必ず行う。**

## 4. 手の動き

- **bookC の1手ごとに**、指定の糸の玉を持ち上げ、鏡の上を運び、目的のノッチへ置く。
  **1手＝1本**（`docs/architecture.md`「正本の読み方」）。**行を左から右へ、行を上から下へ。**
- **運ぶ高さは他の糸の上**（鏡の面より上）。**これが上下を決める唯一の仕組みである。**
  後から置いた糸が、途中の糸の上を通る。**別の上下規則を置かない。**
- **閉じ移動（詰め直し）も同じ**に運ぶ。1周期は平源氏 24手（組み12＋閉じ12）、
  丸源氏 24手（組み8＋閉じ16）。
- **1手ごとに落ち着くまで待ってから次へ。** 待ち方（運ぶ時間、待つ時間、静止と見なす閾値）は
  **解法の設定**であって模型の定数ではない。**固定して記録する。**
- 玉の運びは運動学的（手が動かす）。**運んでいるあいだも糸は張力を受けている。**
