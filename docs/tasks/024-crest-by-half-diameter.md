## 作者の決定（2026-09-08）

> 糸の各位置（留まりの場所、交差点）の基準の高さに対して、別の糸がくぐる可能性のあるところ
> では、**越える糸を +d/2、くぐる糸を −d/2** だけ表面の法線方向にずらした山を作る。
> **山の形は弧でも直線（三角）でもよい。交差点での中心間距離はちょうど d になり、貫入は
> 構成で消える。solver は使わない。**

**裏付け**: **平源氏の膨らみの測定 0.45（輪郭）と 0.40〜0.50（物理の重なり）は d/2 = 0.5 に
一致する。これまで観測値として与えていた膨らみが d から出る。**

## 入力（**すべて既存の導出。定数は d だけ**）

023 から持ってきたものは出所を書く）。

## 構成

1. **表面で見える交差を列挙する**: 留まりと、その場所を越える渡りの端（到着と出発）、
   平源氏の腹を横切る横糸とその上下の縦糸の留まり。**どちらが上かは手順表の順序（後が上）と
   占有履歴（留まりが表面）で決まっている。**
2. **各交差で上の糸を +d/2、下の糸を −d/2、表面の法線方向にずらす。**
   **山の幅は障害物の直径 d**（中心から ±d/2 で最大、外で 0 に戻す）。
   **形は弧を既定、直線（三角）も選べるようにして両方の図を出す。定数は d だけ。**
3. **芯の中の渡りどうしは直線のまま。** 重なりは数えて記録するが**判定しない**（描画に出ない）。
4. **出力は糸ごとの折れ線と d**（021〜023 の判定道具が読める形）。

## 024-1 の結果（2026-09-08）— **構成は 0.12 秒。表面の非貫入は通らない**

### 作ったもの（`Scripts/task024/crest.py`）

`normal_at`）をそのまま呼び、**表面の交差を列挙して ±d/2 の山を足すだけ**である。
山の高さは **d/2**、幅は **d**（中心から ±d/2）、形は**弧**と**直線**の2通り。

### 走った結果（平源氏・丸源氏、2サイクル）

| | 平源氏 弧／直線 | 丸源氏 弧／直線 |
|---|---|---|

| 表面の交差 | 155 | 118 |
| 山の付いた区間 | 74 | 60 |
| **表面の交差で上下が逆** | **9 ／ 8**（最悪 0.059 ／ 0.171 d） | **23 ／ 22**（最悪 0.396 ／ 0.185 d） |
| **重なる糸の対**（120 対のうち） | **96**（最深 1.000 d） | **56 ／ 54**（最深 1.000 d） |
| 断面 幅／厚み（平均） | **7.88 ／ 3.41**（最大 4.50） | 6.81 ／ 5.87 |

### 立ったこと

- **長手は 3 d ちょうど。** 構成が積み重ね模型そのままなので、当然だが**伸びない。**
- **山の高さは d/2 = 0.5 d。** **平源氏の実測 0.45（糸幅比）に対して +11%。**
  **合わせにいっていない。これは d から出た値である。**
- **断面の比は平源氏 2.31、丸源氏 1.16。** 平源氏は扁平、丸源氏は丸——**向きは合っている**
  （実測 3.3359 と 丸）。
- **弧と直線でほとんど変わらない**（比 2.31 対 2.32、外径は同じ 10.13 d）。**山の形は効かない。**

### 立たなかったこと

- **表面の非貫入が 0 にならない。** **120 対のうち 96 対（平源氏）／56 対（丸源氏）の糸が
  どこかで重なっており、最も深いところは 1.000 d（完全に重なっている）。**
- **表面の交差で上下が逆になるものが残る**（平源氏 9、丸源氏 23）。**構成で保証されるはず
  だったので、これは構成の誤りである。**
- **面の見えが通らない。** 2サイクルなので丸源氏の 32/32 は判定できない（4サイクル要る）。
  **平源氏の「横糸だけに色」は本体9升のうち5升が色付き**で、**無彩色になるべきところが
  ならない。**

### どこが足りないか（**測って言えること**）

**±d/2 は「交差している2本」を離すが、「交差していないが近い2本」は離さない。**
最も深い 1.000 d は**同じ場所を前後で引き継ぐ2本の留まり**（端どうしが一点で出会う）で、
**これは交差ではないので山が付かない。** 023 でも同じものが出ていた。

**上下が逆になる 9 件・23 件は、1つの区間が複数の交差を持つ場合**である。ある交差で −d/2
下げられた渡りが、別の交差では +d/2 上げられるべきで、**山どうしが打ち消し合う。**

### 判断を仰ぐこと

1. **同じ場所を引き継ぐ2本の留まり**をどう扱うか。**交差ではないので ±d/2 の対象外**だが、
   端が一点で出会うので重なりとして数えられる。**層で d 離す**（積み重ね模型の中で）か、
   **重なりから除外する**か。
2. **1つの区間に複数の山が付く場合**の重ね方。**今は足し合わせている**ので打ち消しが起きる。

## 作者の決定（追記、2026-09-08）— **山の向きは面の法線で決める**

> **山の向きは対の関係（どちらが上か）から決めない。糸が今いる面の外向き法線で決める。**
> 白（基準面）を 0 とし、**表の糸は +d、裏の糸は −d** に既にずれている。**山はそのずれている
> 側へだけ膨らむ。実世界で重ね合わせの上下が逆になることは無い。**

`docs/architecture.md`「山は糸の半径から出る」に追記した。**平源氏の断面は3枚の面**
（中立 0、表 +d、裏 −d）で、**腹を横切る横糸は 0 を通るので表の縦糸とは初めから d 離れて
いる。** **一つの区間に複数の山が付くときは足さずに重ねる（各点で最大）。**
**同じ場所を引き継ぐ2本は、後から来た糸の到着層が前の糸の出発層の一つ上。**
