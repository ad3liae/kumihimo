# Task 055: 八つ金剛返しで、全ての色が「く」の字に折り返す

- 状態: **実装済み・作者の確認待ち**（2026-09-23）。指示書は作者との対話から Claude Code が起こした。枝 `claude/task-055-gaeshi-fold`。
- 作者の指摘:
  - 「金剛返しのパターンがおかしい。サムネイルで色も含めたきれいな『く』の字になっていない」（1・2赤、5・6青、残り生成りの配色）。
  - 16金剛返し組の写真を見て「組み目がおかしくなってるようだ。すまない、さっきのは僕が間違えてた。あと全ての色が折り返す。8も16も思想は同じだ」。
- 基準: main `21370cc`。

## 1. 原因は3つ

1. **束の傾き（Task 053 の最後、`88d53dd`）**: 「組み目は S・Z で同じ」として全束を S の向きへそろえた。Z では束の尾が違う色の束の下へ潜り、帯が切れた。作者が写真で指示を取り消したので戻した（`97bf796`）。
2. **本の組の置き場所**: 本のディスクの組（隣り合う2スリット）を、盤の 8・1、2・3、4・5、6・7 に置いていた（Task 053）。作者の配色は常に 1・2、3・4 …… で、1・2 の色は2つの組にまたがり、持ち替えで分かれた。**組を 1・2、3・4、5・6、7・8 へ置き直した**（`BookDiskKongo.pairsAtPlaces`）。本の手順の読みは変えていない。
3. **束が傾く向き**: 組の2本は、半周期ずれて隣り合って置かれる。色の線がつながるのは、先に置かれた束の尾が、あとから置かれる相方の下へ潜るときである。これは**運ぶ向きの逆**で、Task 045 以来の「運ぶ向きへ傾く」では組の色が階段状になった（作者配色は組をまたいでいたので、これまで目立たなかった）。
   返し組では、持ち替えの前の1周期だけ組の歩みが逆になる。導出から「どの周期の境目でも隣にいる糸」を相方として見つけ、束をその側へ傾ける（`RoundTube8SurfacePatternGenerator.leaningTowardPartners`）。S・Z ではどちらの隣も該当するので、表の向きのまま。

## 2. 結果

- 一覧カードで、作者配色・スクリーンショットの配色・本の配色・8本別色のすべてで、色が組ごとに「く」の字に折れる（`.build/t055/sheets/gaeshi-cards.png`、`E2/`）。
- S・Z 単独のカードは、どの配色でもきれいな斜めの帯（`E1-cards.png`）。作者配色の S・Z は以前と帯の向きが違って見える（束の傾きが逆になったため）。
- 返し組の既定配色の2色を本に合わせて直した（p.38 組みはじめ: 1・2 と 17・18 が橙、9・10 と 25・26 が桃）。

## 3. 検証

- 試験: `everyPairStaysOneLineThroughTheTurn`（占有履歴で、組 1・2 … 7・8 が返し組の全周期の境目で隣り合う。組でない 2・3 は離れる）、`everyRunLeansTowardThePartnerLaidAfterIt`（S・Z・返しで、先に置かれた束が相方の側へ傾く）。Z を S の鏡とする試験は、盤の1列分の回転を探して照合する形にした。形状ハッシュ更新（頂点数同じ）。
