### 1.2 本の1段と、repo の1周期

**本の1段は4手で4本だけを動かす**（各組の片方）。次の段で残りの4本が動くので、**2段 = repo の1周期（8本が1回ずつ）**。
「6段」は repo の3周期に当たる。

### 1.3 ディスクの番号のずれと、紐の周の位置

ディスク上で組は段ごとに1ノッチずつずれていくが、これは**ディスクの番号の上のずれ**である。
紐の周で意味があるのは8本の**並び順**で、組んだ糸は、残った相方の隣、つまり隣の組から抜けた糸の場所に入る。
並び順（repo の盤の8場所、等間隔）で数えると、

- **本の S: 1段で、各組の反時計回り側の1本が2場所戻る。1周期で8本すべてが −2 場所。**
- **本の Z: その鏡で +2 場所。**
- 隣り合う場所は、1段（半周期）ずれて新しい糸を受け取る。**Task 048 で作者が条件にした半ピッチが、表からそのまま出る。**

Task 035 の「bookC は +4、現行表は +3」の +4 は、組が一緒にずれていく座標での数え方だった
（`YatsuKongoAgainstBookCTests.cycle`）。盤の座標では −2。**現行表（+3、bookA p54 の絵の読み）と食い違うことは変わらない。**
bookC Fig.129 とこの本 p.36 は同じ作り（向かいの組へ14ノッチ）で、互いに合う。

### 5.6 作者の指摘と読み直し（2026-09-22）

作者:「こんな変な組目ができるわけがない。手順が間違っている。模様だけが変わるものだと考えてくれ」。

最初の実装は持ち替え（p.38 [4]・[8]）を**別の段（半周期の層）**として数えた。持ち替えが動かすのは直前の段が置いたばかりの4本なので、
同じ場所が2段続けて糸を受け取り、折り返しに**0.5周期と1.5周期の升**（小さな粒と長い束）ができた。これが「変な組目」である。

**読み直し**: 持ち替えは新しい層を作らず、**直前の段で置いた4本の置き場所を続けて決める手**としてその段に含める
（`BookDiskKongo.rounds`: ある手が直前の手で置いたばかりの糸だけを持ち上げるとき、同じ段の続き。それ以外の二度目の運びは拒む）。
返し組は6つの表になり、組目は S・Z と同じ格子のまま、変わるのは糸の行き先（色の帯の向き）だけになった。
試験 `theStitchesDoNotChangeOnlyThePattern`（全升が1周期、半ピッチが S と同じ）と `aThreadLaidEarlierCannotBeLiftedAgainInTheSameCycle` で固定した。

### 5.7 組み目は S・Z・返しで同じ（作者の指摘、2026-09-22）

作者（一覧の3枚のカードを見て）:「スパイラルの向きが逆になるだけで、基本の組み目の形は変わらないはず。同様にS&Zの組み目も全て同じになるはず。組み上げ方向は変わらないから」。

**確認結果: カードだけでなく立体も同じ誤り**だった。束の傾きを運ぶ向きの符号から取っていた（Task 045 以来の「S と Z は表が鏡なので鏡に描く」）ため、
Z は S の鏡の組み目、返しは S の部分と Z の部分で組み目が反転していた。

**直した**: 束の傾きは `RoundTube8SurfacePatternGenerator.stitchLean`（S の向き、051 で受領した組み目）で全束共通。
運ぶ向き（`leanDirection`）は色の螺旋の向きとしてだけ残る。S の出力は変わらない。Z と返しの組み目が S と同じになった。
S と Z の格子は、半ピッチの偶奇が1列ずれる（Z の最初の段が S と逆の偶奇の場所を動かす）だけで、紐を1列回せば一致する。
試験: `sZAndSAndZShareOneStitch`、`aRunLeansTheStitchsWayWhateverTheCarry`（旧 `theZBraidIsTheMirrorOfTheSBraid`・`aRunLeansTheWayTheCarryGoes` を置き換え）。
