### 1.2 本の1段と、repo の1周期

**本の1段は4手で4本だけを動かす**（各組の片方）。次の段で残りの4本が動くので、**2段 = repo の1周期（8本が1回ずつ）**。
「6段」は repo の3周期に当たる。

### 1.3 ディスクの番号のずれと、紐の周の位置

ディスク上で組は段ごとに1ノッチずつずれていくが、これは**ディスクの番号の上のずれ**である。
紐の周で意味があるのは8本の**並び順**で、組んだ糸は、残った相方の隣、つまり隣の組から抜けた糸の場所に入る。
並び順（repo の盤の8場所、等間隔）で数えると、

- **本の S: 1段で、各組の反時計回り側の1本が2場所戻る。1周期で8本すべてが −2 場所。**
- **本の Z: その鏡で +2 場所。**
- 隣り合う場所は、1段（半周期）ずれて新しい糸を受け取る。**Task 048 で作者が条件にした半ピッチが、表からそのまま出る。**

Task 035 の「bookC は +4、現行表は +3」の +4 は、組が一緒にずれていく座標での数え方だった
（`YatsuKongoAgainstBookCTests.cycle`）。盤の座標では −2。**現行表（+3、bookA p54 の絵の読み）と食い違うことは変わらない。**
bookC Fig.129 とこの本 p.36 は同じ作り（向かいの組へ14ノッチ）で、互いに合う。

## 5. 結果（2026-09-22、Claude Code）

### 5.1 段階1: S・Z を本の表へ（Task 035 の判定 (b)）

- `BookDiskKongo`（`BraidMethodCatalog.swift`）が、印刷された1段と番号のずれから本のディスクをノッチごとに回し、
  盤の等間隔の8場所へ**並び順**で写す（動かない糸はその場所に留まる、と読む）。S は p.37、Z は p.36 からそれぞれ写した。
- 結果: **1周期に各糸が2場所**（S は戻り、Z は進み）。Z は S の鏡（段ごとの手の集合で一致。段の中の2組の順は本によって違う）。
  **bookC Fig.129 を同じ関数で写すとアプリの Z と一致**（場所の呼び名の回転を除いて、段ごとに）。Task 035 の食い違いはこれで本の側で閉じた。
  bookA p54 の旧表は `yatsuKongoBookAP54Disk` として比較用に残した（3場所）。
- **半ピッチは表から出る**: 場所が糸を受け取るのは1周期の前半の段か後半の段かで、隣どうしは必ず逆。
  Task 048 の「完成紐を1周期に1列回す」と偶奇の選び方（`drawnColumn`・`wholeCycleOnEvenColumns`）は外した。
- **見え方は変わらない**: 旧表（+3）に048の回転（1列）を足すと描く面では実効 −2 で、新しい表と同じだった。
  **正面の立体は画素単位で同じ**（S・書籍配色と作者配色）。一覧カードは模様が同じで、束の境目の細い線だけが変わる（糸の顔ぶれが違うため）。
  反復は8周期から4周期になった（形状ハッシュ更新、頂点数は半分）。
- 模様図（占有履歴そのもの）は、旧表では立体と見え方がずれていたが、新しい表では両者がそろう。
- **記録する食い違い**: Task 008 の参考シミュレータの市松の出力は奇数の運び量でしか出ず、新しい表では縦縞になる（試験に残した）。

### 5.2 段階2: 返し組

- **導出の一般化**: `BraidWorking` / `BraidDerivation` / `BraidRecipe` / `BraidOccupancy` が「表の列」（周期ごとに表を替える）を扱う。
  1つの表は表1つの列として同じ結果になる（試験で同値を確認）。反復は列を丸ごと回した回数でだけ数える。導出に組み方の名前は無い。
- **返し組の表**: p.38 の数字を本のディスクで回し、S 3周期・持ち替え・Z 3周期・持ち替えの8つの表として写す。
  **1工程で全糸が組みはじめに戻る**（p.39「1工程終了」と一致。導出が見つけた反復が8つの表）。
- **持ち替えの読み**: 並び順で読むと、持ち替え [4] は**直前の S の段と同じ4本を2場所戻す**（S の段がもう1つ入る形）、[8] は Z の同様。
  **持ち替えは1段＝半周期の層として数えた**（4本を動かすので段と同じ単位）。1工程は7周期の長さ。
- **八つ金剛の模様**: 升を「糸が着いてから次の糸が着くまで」とし、段を半周期の層、束の傾きを**その糸を運んだ手の向き**にした。
  折り返しでは同じ偶奇が2段続くので、**0.5周期と1.5周期の升が4つずつ**できる（半ピッチが半周期ずれる）。これが「く」の角になる。
  束は**自分の升の長さ**を1周期として描く（一様な周期で描くと長い升の後半に下地が見えた。G1→G2）。S・Z の出力は変わらない（画素単位で同じ）。
- **「く」**: 一覧カードで色の帯が S の部分と Z の部分で逆に傾き、折れ曲がる（`sheets/gaeshi-G2.png`、iPad の手動）。
  試験は占有履歴で確かめる: S の部分は1周期に2場所ずつ一方へ、Z の部分は逆へずれる。
