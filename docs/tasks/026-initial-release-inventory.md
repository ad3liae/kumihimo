## 4. レシピの追加候補

**族の描き手があるのは2つだけである**——**平ら16本（面6列）と丸い筒16本。**

| 族 | 描き手 | いま載っている紐 | 足せる候補 |
|---|---|---|---|
| **丸い筒16本** | `RoundTube16SurfaceMesh` | 丸源氏（bookC Fig.32） | **bookC の図のうち、休むノッチが16で、どの糸も長手に留まらないもの。** repo には Fig.20 と Fig.32 しか写していないので、**本を読まないと数えられない** |
| **平ら16本** | `Flat16SurfaceMesh` | 平源氏（bookC Fig.20） | **当面ゼロ。** **判断 (b) の制約で、平らな族は平源氏のレシピ以外を `nil` にしている**（`Flat16SurfacePatternGenerator.drawsOnlyTheRecipe`）。**次の平らな紐の前に、中心化を対称な折り返しに直すこと**（`tasks/025-5-adding-a-recipe.md` 5節） |

**既に指示書がある紐（Task 008〜014）は、どれも族が違う。**

    八つ金剛組・江戸八つ組・八つ瀬組・唐八つ組   **8玉**  → 描き手なし
    江戸源氏組・方丈組・方丈組（中細）           **12玉** → 描き手なし

**したがって、8玉と12玉には族の描き手を作る作業がまず要る**（形の値も測り直しが要る）。
**模様図（2D）は族に関わらず出る**ので、**そこだけ先に出すことはできる。**
