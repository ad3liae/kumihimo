# Task 007G: 平源氏の縁の位相（周期内の手番差を解像する）

- 状態: 完了（2026-09-06）
- 優先度: 高（Task 016 の段階2b より先。出荷済みの表示の誤りであるため）
- 起点: 作者の指摘（2026-09-06）、bookA p97 左の矢絣の作例

## 指摘

> 平源氏だが、左右端は横糸由来だから半ノッチずれるんじゃない？
> 真ん中の4本の腹の下を通っているように見える。

## 現状

**モデルは縁と面が完全に同位相である。** 段階2.5c 以降のレンダーでは、谷が紐の上下端まで
一直線に通り、縁の升と面の升の境界が長手方向の同じ位置に並んでいる。

## なぜそうなったか

Task 007F の導出は **board を1周期に1回しか標本化していない**。Task 007E 段階3 の着手前確認
で、実装側がこれを明示的に報告している。

| 手 | 動き | 影響する列 |
|---|---|---|
| 1 | `eastOuterToWestCenter` | c5 が左縁へ渡る |
| 2 | `westOuterToEastCenter` | c0 が右縁へ渡る |
| 3–4 | inner の表裏交換 | c1・c4 |
| 5–6 | outer の表裏交換 | c2・c3 |

**縁で横糸が折り返すのは手1・2、面の升が入れ替わるのは手3〜6である。** 標本化で
この差が落ちている。

## レビュー側の判断の誤り（2026-09-05）

このとき「周期内の手番差は解像しない」と指示した。根拠は bookA p97 の作例に**本体の斜めが
無い**ことで、面については正しかった。**しかし縁については検討していなかった。**

縁の位相は、捨てた同じ情報の別の帰結である。**面に手を出さない理由は、縁に手を出さない理由
にならなかった。**

## 構造からの裏づけ

横糸は面の升と升の**あいだ**を渡って前後の段を綴じる。よってその折り返しが縁に現れる位置は、
面の升の中心ではなく**升の境目**に対応する。半ノッチずれるのが自然である。

写真からも、縁の色糸が面の白い升の下へ潜り込んでいるのが見える（作者の言う「真ん中の4本の
腹の下」）。**この上下関係自体はモデルに既にある**（`layer = .under`、`passedColumns`）。
足りないのは**位相**である。

## やること

**位相だけを直す。上下関係・断面・畝・縦横比・配色には触れないこと。**

1. **周期内の手番差を移動規則から導き、列ごとの長手方向の位相として与える。** 値を決め打ち
   しないこと。「縁は半ノッチ」も決め打ちにしないこと。**手番から出た値を使う。**
2. 出た位相を報告してから絵を見ること。

## 合格条件

1. **縁が面に対してずれること。** ずれ量が手番から導かれていること。
2. **本体に斜めが出ないこと。** c1・c4 は手3–4、c2・c3 は手5–6 で差は1手ぶんしかないので、
   面の6レーンはほぼ同位相のままのはずである。**本体に目に見える山形が出た場合は、
   bookA p97 右（黄茶・はしごの作例）と矛盾するので、直さずに報告して止まること。**
3. **矢絣の対照実験が通り続けること**（2・4面の中央2本を色X、奥と手前2本を色Y、他は無彩色
   → 本体は無彩色、縁取りだけに矢絣）。
4. **はしごの対照実験が通り続けること。**
5. 段階0の不透明テストが通り続けること。
6. Task 007E で決めた定数（3.3359 / 0.3665 / 0.45 / 弧長分割）が**1つも動いていない**こと。

## 見るべき資料

`.build/task007f-references/bookA-p97-...`（左の矢絣の作例）。作者が送った拡大写真では、
上の縁と下の縁の色が**互いに1つずれている**（矢絣の正体）ことと、色糸が白い升の下へ潜って
いることが読める。**縁と面の位相差そのものは、この解像度では写真から測れない。移動規則から
導くこと。**

## 結果（2026-09-06）

### 導いた位相（絵を見る前に出したもの）

`HiraGenjiWeaveDerivation.arrivalPhase(atWidthPosition:)` を足した。1周期の6手＋詰め直しを
7つの瞬間として、**糸が到着する瞬間**を数える（去る瞬間ではない。新しい糸が来た時点でそこの
見えが変わるため）。詰め直しを数えるのは、それが最外列 c0・c5 が糸を受け取る瞬間だからで、
数えないとこの2列には到着が1つも無くなる。

  幅 −1（左縁）  到着 手1        位相 0.143
  幅  6（右縁）  到着 手2        位相 0.286
  幅  1・4       到着 手3・手4   位相 0.500
  幅  2・3       到着 手5・手6   位相 0.786
  幅  0・5       到着 詰め直し   位相 1.000

**本体（長手方向に走る糸が持つ c1〜c4）の平均は 0.643。縁は 0.143 と 0.286。**

  左縁 − 本体 = 0.143 − 0.643 = **−0.500 段。ちょうど半ノッチ。**
  右縁 − 本体 = 0.286 − 0.643 = **−0.357 段。**

左縁がちょうど半段になるのは、本体の平均の瞬間 4.5 が手1 の 3.5 後だからである。
**「半ノッチ」を決め打ちにはしていない。手番の平均から出た。**

**ただしこの 0.500 は「瞬間を7つ数える」という数え方の帰結であって、紐の不変量ではない。**
詰め直しを数えなければ縁は 1/6 と 2/6 になり、ちょうど半段にはならない。詰め直しを数えるのは
最外列が糸を受け取る唯一の瞬間だからであって、半段を出すためではない。
`instantsPerCycle` のコメントにも同じことを書いた。

### 適用したもの・しなかったもの

**適用した**: 縁と本体の位相差。変化は最外列（c0・c5、面の上で横糸が見える列）で受け持たせた。
そこが構造上の受け渡し点であり、こうすると領域どうしの継ぎ目が合ったままになる。

**報告するが適用しない**: **本体自身も同位相ではない。** c1・c4 は手3–4、c2・c3 は手5–6 で
**0.286 段ずれる。** そのまま描くと面に山形が出るが、bookA p97 のはしごの作例は本体が平である。
合格条件2 に従い、描かずに報告する。`faceStitchLean` と同じ扱いとする。

### 描き方の制約（既知の副作用）

リピートの両端の継ぎ目は、これまでどおり直線に保っている。タイルは独立に並べられるので、
継ぎ目を端の外へ持ち出すと次のタイルとのあいだに穴が開く（**実際に一度開けて、段階0の不透明
テストが落ちた**）。そのため**位相はリピート内部の継ぎ目に出て、両端では戻る。** rowCount が 4
なので、縁では4段に1度、段の高さが不揃いになる。

**直すには、リピートの継ぎ目をまたぐ升をメッシュ側で扱えるようにする必要がある。**
今回は位相だけを直す範囲なので手を付けていない。

### 合格条件の確認

1. 縁が面に対してずれる — **満たす。** ずれ量は手番から導出（上記）。
2. 本体に斜めが出ない — **満たす。** 本体の継ぎ目は位相 0 のまま直線である。
3. 矢絣の対照実験 — **通る**（`theArrowFeatherColouringPatternsOnlyTheEdging`）。
4. はしごの対照実験 — **通る**（`HiraGenjiLadderExperimentTests`）。
5. 段階0の不透明テスト — **通る**（`hiraGenjiSurfaceIsOpaqueFromEveryLineOfSight`）。
6. Task 007E の定数 — **1つも動いていない。** 変更は `HiraGenjiWeaveDerivation` と
   `HiraGenjiSurfacePattern` の位相の機構のみで、メッシュ生成器には触れていない。
