## 2. すること

1. **出典をデータに持たせる**（レシピごとに、書籍と頁）。上の7つはすべて『かわいい組ひもの教科書』と頁だけ。
   ほかの本はいまは使わない（将来、教科書に無い組み方を足したときに、その本の正式な書籍名で書けるようにしておく）。
2. **手順のアニメーションの下（手の文と数の近く）に、出典を1行**: 例「出典：『かわいい組ひもの教科書』p.36–37」
   （頁は上の対応。見開きなら「p.94–95」）。小さめの文字でよい。VoiceOver でも読める。
3. **詳細の注記（`prototypeNotice`）から内部の呼び名を消す。** 教科書で足りるものは教科書だけを書く。
   - 八つ金剛 S:「手順は『かわいい組ひもの教科書』p.37（8S-スパイラル）から。立体は写真に合わせた描画上の近似です。」
   - 八つ金剛 Z: 同じ形で p.36（8Z-スパイラル）。
   - 返し組:「手順は『かわいい組ひもの教科書』p.38 から。Sを6段、Zを6段で1工程です。折り返しの見え方は小さな写真にしか照らしていない描画上の近似です。」
   - 丸四つ組:「手順は『かわいい組ひもの教科書』p.52 から。立体は写真に合わせた描画上の近似です。」（「対の2本のどちらが先かは読めません」は、
     教科書が「同時に行います」と書いているので消す）
   - 江戸八つ組:「手順は『かわいい組ひもの教科書』p.64–65 から。立体の目の形は同書 p.64 の写真に合わせた描画上の近似です。」
   - 丸源氏・平源氏の注記には本の名が無いので、そのまま。
   - 文言は上を目安に、同じ調子で整えてよい。**「bookA」「bookC」「組ひもディスクの本」「教科書」だけの略称を画面に出さない。**
4. コードとテストの中の説明（コメント）は直さなくてよい（`sources.md` の対応で分かる）。
