## 1. そろえるのは1段の終わりだけ

### 1.1 いまの作り（067）

`BraidBookWorking` は「島の数と大きさが組みはじめとそろったら寄せる」。八つ金剛は2手ごと、丸源氏は手2のあとに寄せ、台の面の組み方
（丸源氏・平源氏）は**手のたびに面の中の糸を等しい間に広げ直している**。作者の言う「1手ごとに位置を調整する」になっている。

### 1.2 すること

1. **本の1段を、データとして持つ**（組み方ごとに、何手で1段か。本の「1段目終了」の図のところ）:
   八つ金剛 S・Z 4手（教科書 p.36–37、p.38 の「これで［8S-スパイラル］の1段終了」）、返し組は S・Z の段が4手、持ち替えは4手でひとまとまり、
   江戸八つ組 8手（p.65「1段目終了」、図1〜10）、丸四つ組 2手（p.52）、丸源氏 4手（p.95）、平源氏 6手（p.96–97）。
2. **段の途中では、どの糸も本が置いた所から動かさない。**
   - ディスクの組み方: 本のスリットのまま（八つ金剛なら手1のあと北の島が3本・南が1本のまま）。
   - 台の面の組み方: 着いた糸は、本の言う所（「中央」「左端の糸の右側」）の**両どなりの糸のあいだ**に置き、ほかの糸は動かさない。
     玉が重なるなら、着いた糸を少し内側（中心寄り）に置く。
   - 本が刷っている仮置きの寄せ直し（江戸八つ組の図5・図10 など、何も渡らない手）は、いまと同じく、本の順でその手に続けて動かす。
3. **段の終わりに、組みはじめの形へそろえる**（八つ金剛なら「井」の形: 2本ずつ東西南北）。手には数えず、段の最後の手のあとに1つの動きとして
   見せる。台の下の文は「位置をそろえる」の形（段の語は使わない）。
4. 067 の「島の数と大きさがそろったら寄せる」は、この「段の終わりにそろえる」に置き換える。島を並びから決める規則（2/2/2/2・4/4/4/4・
   6/2/6/2）はそのまま使う（段の途中の島の見え方と、そろえる先の形を決めるのに要る）。

## 2. 丸四つ組

### 2.1 悪くなった所: 着いたあと、さらに回ってしまう（作者の録画で確かめた）

作者（2026-09-27、iPad シミュレータの録画）:「同時に回すでいいが、これは回しすぎ。」

審査側が録画をコマに分けて見た（main `b53ff71`）。手2（「場所2の糸を左回りに場所4の隣へ、場所4の糸を左回りに場所2の隣へ」）で、
2本は左回りに半周して向かいに着く（ここまでは正しい）。**そのあと、2本がさらに同じ向きに約90°回って場所1・3の脇まで行き、
それから元の4か所に戻る。** 手1でも同じことが起きている。067 の「島の数と大きさがそろったら、それぞれの島を元の向きへ戻す」が、
1本ずつの島（1/1/1/1、4回対称）で**どの島をどの向きへ戻すかの合わせ方を取り違え**、台を 90° 以上回して戻していると読める
（八つ金剛の 2/2/2/2 も4回対称なので、同じことが起きうる）。

**直すこと**:
- そろえる動き（1.2 の3）は、**糸が動く角度の和がいちばん小さい合わせ方**を選ぶ。どの糸も、となりの島までの間の半分より多くは動かない。
- 丸四つ組は、手のあとの寄せ直し（1ノッチ）で糸がもう組みはじめの位置にあるので、**そろえる動きは無い**（0°）。
- 066 より前（PR #51、`7b5e494`）と今で丸四つ組の手1・手2 を撮り比べ、ほかに悪くなった所が無いかも確かめる。

### 2.2 教科書 p.52 の手に合わせる（正本）

教科書の丸四つ組（p.52、道具は丸台）:
- 組みはじめ: 1〜4面の中央に1本ずつ（面の番号は丸源氏と同じ。1面＝上、2面＝左、3面＝下、4面＝右）。
- 1（縦方向）: 1面の糸を右手（親指にかけて）で3面へ、3面の糸を左手（4本指）で1面へ。**「この時計回りの移動は同時に行います」**。
- 2（横方向）: 2面の糸を右手（4本指）で4面へ、4面の糸を左手（親指にかけて）で2面へ。**「この反時計回りの移動は同時に行います」**。
- 1段目終了: 糸の色は組みはじめと同じ。

いまの表（`maruYotsuDisk`、レシピ本 p.56 の読み）は、**手1の2本を左回り**（上の糸は左側を下り、下の糸は右側を上る）に書いている。
教科書は**手1が時計回り、手2が反時計回り**。手2は合っていて、**手1の向きが逆**。

1. 手順の絵は教科書 p.52 の手で描く（丸源氏と同じ台の面の形で書いてよい。2本同時、縁に沿って教科書の矢印の向きに回る）。文も教科書の言い方
   （「1面の糸を3面へ、3面の糸を1面へ（時計回り、同時に）」の形）。
2. **3Dの表の手1の向きも教科書に合わせるか**は、2.3 のとおり作者が決める。直すなら `maruYotsuDisk` の手1を時計回りに書き直す
   （例: 1→16 と 17→32、そのあと 16→17 と 32→1 の寄せ）。

## 3. 試験

1. どの組み方も、段の途中で本が置いた所から糸が動かない（台の面の組み方で、着いた糸以外の糸の角度が手の前後で同じ）。
2. 段の最後の手のあとにだけ、そろえる動きがある。そろえたあとは組みはじめの形（八つ金剛は 2/2/2/2 で東西南北、丸源氏は 4/4/4/4）。
3. 1段の手の数が 1.2 の1 のとおり。
4. 丸四つ組の手1は時計回り、手2は反時計回り（絵）。2本が同時に動く。**どの糸も1手で半周（とその前後の寄せ直し1ノッチ）より多く回らない。**
   そろえる動きでは、どの組み方のどの糸も、となりの島までの間の半分より多く動かない。
5. 3Dの形状ハッシュ・カードの画素は変わらない（2.3 で表を触らないため）。ガードを通す。
