## 2. 046-0: 写真と基準の露出区間を、同じ方法で比べる

資料:

- `.build/task031-photos/bookA-p8-9-zoom-b-a-S.png` — 左からZ-b、Z-a、S。Sを主比較、Z-aを向きと形の確認に使う。
- `.build/task031-photos/bookA-p54-55-yatsu-kongo.png` — 配色と手順の参照。
- `.build/task045/sheets/{s,z}-plain-front.png`、`{s,z}-book-front.png` — 実物とA/B/Cの比較。Cの立体形状が現在の基準と同じ。
- `.build/task045/review-fixes/` — 向きを直したカードと立体の比較。

新しいモデルを作る前に、SとZ-aそれぞれ、輪郭を識別できる**少数の露出区間（目安3〜6か所）**を選ぶ。
元画像の座標、選んだ輪郭、中心線の読み、紐の軸と輪郭幅を注記して残す。
同色の別の糸が続いて見える所や、下に隠れた端は無理にひとつの区間として結ばない。
読めない部分は未確定とし、標本数を満たすために境界を作らない。

写真と基準レンダーを、輪郭幅を揃えた一様な拡大縮小で並べ、次を同じ定義で記録する:

- 露出区間の見かけの長さ／紐幅、幅／紐幅、長さ／幅。長軸と直交する幅を使い、画面の横幅と混同しない。
- 糸束の長軸の傾き。色帯の角、格子の歩幅、細い糸筋の角と分ける。
- 端が消える位置と、その先に見える隣の束。写真から隠れた内部経路や深さを決めない。
- 縁の起伏は別に目視で比較する。そこから谷の深さを逆算しない。

今回は**投影された見えの比較**を行う。写真の縁は周方向が縮むため、主寸法は中央付近の読みやすい区間で比べ、周辺は別欄にする。
少数標本の幅・角度を真の3D寸法や全周の代表値に読み替えない。レンダーは正面だけでなく既存の回転画像からも同じ位置帯を見て、向きによる幅を示す。
以前の36°を糸束の角に使わず、未計測の「1.5〜2サイクル」から目標長さを作らない。
写真とモデルで厳密に対応しない場合は、読みの範囲を記録して描画案の選択に使う。測定研究だけを続けない。

## 3. 046-1: 下地の露出と粒の輪郭を、形から減らす

**推奨する最初の案は、幅のある腹と、すぼまって隠れる先端を分けて作ること。**
現在の「肩でだけ最大幅、その後はずっと細くする」という形から、隣の束との間を覆う腹を保ち、先端側で幅と高さを落とす形を比較する。
まず頂の高さを保って幅の配分と潜り込みを比べる。高さや断面の変更も必要なら、幅だけの変更から効果を分けて示す。
必要に応じて端寄りの中心線を少し曲げ、先端が隣の束の縁に隠れる配置を試してよい。
単に長さだけを伸ばす、全体を太らせる、全ての糸束を平らにして隙間を埋めるだけで終えない。

具体式は小さく検証できるものをClaude Codeが選ぶ。最初は数周期の局所形状で比較し、**基準＋最大2つの形の案**を残す。
数値の総当たりや無制限の探索はしない。少数の意味と単位を持つ値で表し、採用理由を写真の読みと結びつける。
旧値が試験で固定されていても、見直した描画上の仮定なら理由を記録して更新できる。

満たすこと:

1. 単色・同じ照明でも、粒の四辺が独立して見える印象が弱まり、隣に覆われる端が読める。
2. 8色で、どの区間がどの糸に属し、どの別の区間に覆われるかが分かる。同色を結合条件にしない。
3. **端は、別の糸束の下に隠れてから終わる。** 露出した空間で一点まで細くなって終わる形や、平らな升の上へ単に載せた形を改善する。
   全糸の内部経路を再構築する必要はないが、比較する代表箇所で覆う側と覆われる側を特定する。
4. 目立つ三角形・帯状の平らな下地の露出を減らす。閉じた筒のために下地を残すことは可能だが、その面積を減らさず暗くするだけの変更は採らない。
5. 背景の穴、見える端面、面のちらつき、周期境界の段差を出さない。輪郭を基準よりさらに平らにして隙間を隠さない。

下地の見える割合は、レンダーの暗い画素数ではなく、**実メッシュの外側に当たった面が糸束か下地か**で基準と候補を比較する。
045の実メッシュ照合を必要な範囲で利用できる。全周1リピートの同じサンプルと、代表的な局所画像を対応づける。
写真の暗部をそのまま下地と数えたり、根拠なく露出率0を目標にしたりしない。露出率だけ下がって束の形が悪化する候補は採らない。

ここで改善するのは、完成外観のための形である。物理的な接触・張力・体積保存の解法、Task 036〜044の再実行は加えない。
現行の手順情報では決められない先後が必須になった場合は、その箇所と候補を示す。情報を捏造してTask 035を閉じない。

## 4. 046-2: 一覧と素材を追随させ、比較可能な状態で提出する

採用候補は詳細と一覧の両方へ接続する。可視区間を選ぶ規則は共通に保ち、カードだけ輪郭を到着順に上塗りする方式へ戻さない。
形の値を増やしたら、カード画像のキャッシュキーにも反映する。画像更新ローダーを別のものに置き換えない。

最初の形の比較では、色・照明・接触影・糸筋の密度を固定する。
糸筋や影の座標が新しい形に追随するための修正は行い、陰影の追加調整が必要なら形だけの比較と別に残す。
絹の艶、毛羽、ランダムな凹凸、共通照明の変更は今回の対象外。

`.build/task046/` に次を保存する:

- E2: 必要な場合だけ、第一候補と違いが説明できる第二候補。比較で劣れば採用しない。
- final: 採用候補。形の比較後に素材座標や影を調整した場合はその差も明記する。

形の変更に合わせて検証するもの:

- 糸ID・色の帰属、S/Zの鏡の対応、外向きの面、有限な法線、周方向と長手周期の継ぎ目。
- 新しい腹・先端の代表箇所で、実メッシュから覆う糸と覆われる糸を確認する。頂だけで全幅の先後を断定しない。
- カードの画素の所属と実メッシュの外側の所属。変更前後の不一致数と境界差の範囲を記録する。
  045で許容した除外帯を機械的に広げず、形が変わっても理由が成り立つか再確認する。
- 下地の露出割合と分布、写真と同じ測り方による露出区間の寸法。ハッシュ更新だけで外観を合格にしない。
- 頂点・素材数、形の生成時間とカード生成時間。iPadとiPhoneの実際の一覧・配色変更・詳細・回転・拡大・リセットを確認し、
  ライト／ダーク、標準／大きな文字の実施範囲と未確認範囲を明記する。

合格の中心は、**同じ表示条件で、平らな下地が目立たなくなり、幅を持つ糸束の先が隣の下へ差し込んで読めること**。
写真に対する細長さ・傾き・輪郭の起伏の改善と悪化を、測定の限界も含めて報告する。
一方向や一配色だけで成立するものを完成扱いにしない。露出率低下やテスト成功だけで実物らしさを断定しない。

通常は測定→局所候補→製品への接続→検証まで進め、段階ごとの承認待ちは挟まない。
最大2案とも改善にならない場合は、基準を悪化した案へ置き換えず、画像・値・失敗箇所を揃えて報告する。
この場合も物理研究や無制限の探索へ広げない。
