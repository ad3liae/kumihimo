## 3. 最初に試す変更

現行 `RoundTube16SurfaceMesh` は、幅方向の山を `1 - |across|²`、高さを公称半径の0.12、
幅を升の1.15倍としている。長手の高さは `crossingCrestFactor` と端の沈みで決まる。
**浅く広い山と、隣の面が肩を覆う位置の組合せ**を、平たい印象の原因候補として検証する。

1. 着手版をR0として、生成り・通常素材と、同じ照明で詳細地図を外した表示を残す。
2. R1は、まず**幅方向の高さの分布**を変える。050の持ち上げた余弦
   `h(u) = (1 + cos(πu)) / 2`（`u`は中央0・縁±1）を第一候補にしてよい。
   幅と頂の高さを保った比較から始め、広い頂面が腹から肩へ曲がるかを見る。式自体を完成条件にはしない。
   半円式へ替えれば必ず丸く見えるとは限らない。050での結果も、丸源氏では画像で確かめる。
3. R1でまだ平たい場合はR2として、**高さを控えめに増し、肩と隣が出会う高さを調整する**。
   必要なら谷の位置や局所の長手方向のふくらみを合わせる。高さ0.12を固定条件にしない。
   前後の潜り込みを保ち、長手の両端を丸く閉じる独立した楕円にはしない。
4. 形を選んでから通常素材を戻し、必要な範囲で丸源氏専用の陰影を追随させる。
   全周を濃い線で囲う、粗い糸筋や光沢を強めて丸みに見せる、照明を変更する方法は採らない。

R0と少数の候補で決める。R1で十分ならR2は不要。途中ごとの承認待ちは不要だが、
微調整を大量に繰り返したり、変化が乏しいのに試験だけ通して改善済みとしたりしない。
最終の係数は、写真から直接測れた値と、目で選んだ描画上の値を区別する。

## 4. 丸みと紐全体の太さを混同しない

丸源氏の0.12は半径比、平源氏の0.45は糸幅比、金剛の値も別の形での比である。
同じ値へそろえる指示ではない。旧005Jの「測る前に揃えない」は他の組の値を正解として移さないための注意として保ち、
**今回作者が求めた丸みの調整は、描画上の選択として進めてよい**。読めない3D寸法を写真から導いたと書かない。
写真の輪郭のさざ波から丸紐の畝の高さを逆算する、005Jで不成立だった方法へ戻らない。

高さを変えると外径と、外径に対するV字の間隔も変わる。設定値だけでなく、
候補の実際の輪郭幅D・V字間隔/D・見えている束の幅と高さの関係を比較する。
R0と候補はカメラ・倍率を固定した画像を残し、写真との並置にはDをそろえた一様拡縮を使う。
縦横を別々に引き伸ばしたり、候補だけズームして改善に見せたりしない。

まず1.25を保って、外径が大きく膨れずに肩の丸みを足す。高さ変更で密度が変わるなら、
基準面・谷と頂の配分を見直すか、必要最小限の縦横比補正を理由とともに比較してよい。
後者は一覧の縦横比にも反映する。旧密度の許容幅を広げて通すだけにしない。
`crestRadius` 等が新しい形の実際の寸法を表しているかも確認する。
