## 1. 今回直す印象

**束の端が隣の下へ続き、組まれた糸として読めること。**
楕円をさらに高くする、谷を一律に暗くする、糸筋を細かくするだけでは今回の指摘に答えない。
049の受領は区切りのためのマージであり、外観の合格ではなかった。今回の指摘を新しい受け入れ条件にする。

作者の画像では、各色の面が丸い両端を持つカプセルとして閉じ、横に連続して見える。
完成写真では、束の端の一部は隣の輪郭に隠れ、束どうしの境目が食い違って見える。
まずこの**輪郭と隠れ方の差**を直す。写真から見えない内部経路を創作する必要はない。

## 3. 試す形

最初の候補K1は、**丸い断面を持つ短い糸束が、幅を保って隣へ入り、隠れた先で終わる形**にする。
必要な可視区間と埋まる先端だけを作る。全長にわたる8本の経路や新しい汎用形状基盤は作らない。

1. **見える端を先に尖らせない。** 腹から肩へ丸く下がる断面を作り、隣に覆われる位置までは幅を保つ。
   先端を細くしたり切ったりするのは、隣の下に十分隠れた後にする。幅0・高さ0への収束自体で、見える楕円の端を作らない。
2. **潜る相手と場所を実際の形で確かめる。** 現行の半ピッチ配置から隣接する束を取り、
   どのrunのどの部分が覆うかを記録する。必要なら端の中心線を短い曲線で隣へ寄せて沈める。
   隣を選ぶのに色を使わず、同じ色だから同じ糸としてつながない。束の腹の位置・糸IDは維持する。
3. **覆う束の側面で境界を作る。** 見える輪郭が隣の輪郭に突き当たって消え、幅のある端が下へ続く形にする。
   2つの楕円の先端が接するだけ、薄い先端が他の腹を突き抜ける形、直線の板で隙間を覆う形にはしない。
4. **腹の丸みは保つ。** 一定高さの平板や、片側に寄った盛り上がりへ戻さない。
   丸い断面と長手の曲がりを分け、出会うところの高さを、見える長さと一緒の係数でしか動かせない作りから離す。

まず共通の単色材質でK0/K1を比較し、「楕円の輪郭が弱くなった理由」を中央と両端の拡大で説明する。
K1が単に太い楕円になったなら、そのまま材質仕上げや全件試験へ進まない。原因を特定してK2を1案だけ比べる。
少数の比較を挟んで作業を進め、途中ごとに作者へ承認を求める工程にはしない。
改善が出ない場合は比較と原因を報告し、微調整を大量に繰り返して完了扱いにしない。

## 7. 実装結果（2026-09-21、Claude Code）

### 7.1 採った形（K1）と理由

K0（049追補2）は、幅が両端で0へ絞るレンズで、高さもrun全長の円弧で両端0だった。
**見える部分の輪郭が両端とも自分の凸な先端で終わる**ので、覆われる端でも先端の尖りがそのまま見え、閉じた楕円が並ぶ（作者の指摘の原因）。
K1は幅・潜る位置・高さを分けた（`RoundTube8Bundle`、`Kumihimo/Domain/RoundTube8SurfacePattern.swift`）。

- **頭は鈍い**: 到着から 0.12 周期の丸みで全幅（`headRoundingCycles`）。後に置いた糸が上（architecture 組み台の力学）なので、頭は上に載り、自分の輪郭が見える。
- **尾は覆われるまで全幅**: 次の到着（1周期）まで全幅（`tailNarrowsFromCycles` = 1）、そこから run の終わり 1.55 周期で0。
- **尾は傾きの側の隣の列へ曲がる**: 0.5 周期から、終わりで傾きに加えて 0.55 列（`tailBendFromCycles`、`tailBendColumns`、二乗で離れるので折れない）。
  半ピッチ配置では、尾の位置で隣の列の束（半周期後に置かれたもの）がちょうど腹にあり、**尾はその側面の下へ、幅を保ったまま入る**。境界は覆う束の側面が作る。
  曲げはすべての run で同じで、隣を選ばない。色も糸IDも見ない。
- **高さは作者の偶の円弧のまま**、専用の幅 `arcSpanCycles` = 1.2 を持たせた。頂は 0.6 周期（式から出る）。1.2 以降は谷底で、そこは後に置かれた束の下。
  049の「谷を深くするには重なりを短くするしかない」の結び付き（高さと見える長さが同じ係数）はこれで外れた。
- 傾き 0.2 列/周期・腹の半幅 0.6 列・高さ 0.44・糸筋の角と密度は049のまま。

候補の探し方（原型は `.build/task051/proto/`、写真と同じ式を Python で展開面に描いたもの）:
両端を隣の列へ S 字に曲げる案は**同色の縄のように連続して見え**（指示書が禁じる形）、頭を丸く上に載せて尾をまっすぐ次の頭の下へ入れる案は**積んだ座布団（Task 033 のとうもろこし）**に戻った。
尾だけを曲げて隣の列の束の側面で切る案（K1）で、楕円の閉じた輪郭が消えた。K1が単に太い楕円にはならなかったので、K2は作っていない。

**楕円の輪郭が弱くなった理由**（`sheets/s-plain-roll0-nodetail-zoom.png`、`s-author-roll0-zoom2.5-zoom.png`）:
K0の束は右端（尾）も左端（頭）も自分の先端まで見えて閉じる。K1では、尾が細くなる前に下の列の束の上側の縁に突き当たって消えるので、**尾の見える終わりは幅のある斜めの線（覆う束の側面）**になり、頭は鈍い。
中央でも両端でも、1個の束の輪郭が自分で閉じる所が無い。
