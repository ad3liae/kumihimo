# Task 051: 八つ金剛を、楕円の粒の列から、隣へ潜る糸束の見え方へ改める

- 状態: **指示書・未実装**（2026-09-21）。Claude Codeが実装、Codexが審査する。
- 作者の指摘: 「金剛組なんだけど、やはり見た目の改善をしたい。現状、まだ楕円の丸いものが何個も繋がってるだけに見える」。
- 基準: main `57cfba2`（平源氏050をPR #32でマージ済み）。八つ金剛は049追補2の形。着手時のHEADを記録する。
- 範囲: 8本円筒の束の形・重なり・質感と一覧の対応。丸源氏・平源氏の描画、手順表、一般導出、保存・編集操作は変更しない。物理研究は再開しない。

## 1. 今回直す印象

**束の端が隣の下へ続き、組まれた糸として読めること。**
楕円をさらに高くする、谷を一律に暗くする、糸筋を細かくするだけでは今回の指摘に答えない。
049の受領は区切りのためのマージであり、外観の合格ではなかった。今回の指摘を新しい受け入れ条件にする。

作者の画像では、各色の面が丸い両端を持つカプセルとして閉じ、横に連続して見える。
完成写真では、束の端の一部は隣の輪郭に隠れ、束どうしの境目が食い違って見える。
まずこの**輪郭と隠れ方の差**を直す。写真から見えない内部経路を創作する必要はない。

現行 `RoundTube8Bundle`（`Kumihimo/Domain/RoundTube8SurfacePattern.swift`）は、
幅を両端で0へ絞るレンズと、run全長の両端で高さ0になる円弧を組み合わせている。
`RoundTube8SurfaceMesh.frame` はそれを円筒上に置き、1サイクルずつずらして重ねる。
**長手・幅の両方向に閉じる形が、1個ずつ完結した丸い粒に見える原因候補である。**
両端の中心点が他のrunに隠れる検査はすでに通っているが、それだけでは、幅のある端が隠れ、糸として続いて見えることを保証しない。

049の「谷を深くするには重なりを短くするしかない」は、その円弧と幅の式の中での制約である。
今回は**幅の維持、隣へ潜る位置、腹の高さを分けて設計してよい**。旧定数の微調整だけに限定しない。
以前の作者の「偏りのある膨らみではない。円弧というか半円状で良い」を踏まえ、腹は偏った山に戻さない。
一方、今回の「楕円の粒」という指摘を受け、run全長を1個の円弧で閉じる実装は見直してよい。
これは今回の描画案であり、以前の発言が断面だけを指定していたと断定するものではない。

## 3. 試す形

最初の候補K1は、**丸い断面を持つ短い糸束が、幅を保って隣へ入り、隠れた先で終わる形**にする。
必要な可視区間と埋まる先端だけを作る。全長にわたる8本の経路や新しい汎用形状基盤は作らない。

1. **見える端を先に尖らせない。** 腹から肩へ丸く下がる断面を作り、隣に覆われる位置までは幅を保つ。
   先端を細くしたり切ったりするのは、隣の下に十分隠れた後にする。幅0・高さ0への収束自体で、見える楕円の端を作らない。
2. **潜る相手と場所を実際の形で確かめる。** 現行の半ピッチ配置から隣接する束を取り、
   どのrunのどの部分が覆うかを記録する。必要なら端の中心線を短い曲線で隣へ寄せて沈める。
   隣を選ぶのに色を使わず、同じ色だから同じ糸としてつながない。束の腹の位置・糸IDは維持する。
3. **覆う束の側面で境界を作る。** 見える輪郭が隣の輪郭に突き当たって消え、幅のある端が下へ続く形にする。
   2つの楕円の先端が接するだけ、薄い先端が他の腹を突き抜ける形、直線の板で隙間を覆う形にはしない。
4. **腹の丸みは保つ。** 一定高さの平板や、片側に寄った盛り上がりへ戻さない。
   丸い断面と長手の曲がりを分け、出会うところの高さを、見える長さと一緒の係数でしか動かせない作りから離す。

まず共通の単色材質でK0/K1を比較し、「楕円の輪郭が弱くなった理由」を中央と両端の拡大で説明する。
K1が単に太い楕円になったなら、そのまま材質仕上げや全件試験へ進まない。原因を特定してK2を1案だけ比べる。
少数の比較を挟んで作業を進め、途中ごとに作者へ承認を求める工程にはしない。
改善が出ない場合は比較と原因を報告し、微調整を大量に繰り返して完了扱いにしない。

## 4. 配置・寸法・質感

**048で直したものを保つ。** 台の場所と描画列の対応、半ピッチの位相、1束ごとの交替、S/Zの鏡、
元の糸IDと占有、基準のピッチ/直径0.807は維持する。可視境界は重なりによって変わるが、糸の所属を書き換えない。
runの支えとなる升と、見える束の外形を区別する。異なるrunの間を同色の帯で塗りつないで連続に見せない。

束の幅・潜る長さ・高さなど描画側の値は今回調整してよい。追加する値は必要な役割に絞り、出所を記録する。
写真の「束1個の長軸」「色の帯」「糸筋」は別々に読む。楕円を斜めへ回すだけで直そうとしない。
049の見かけの傾き約17度／写真1〜5度は旧測定の記録として扱い、候補の採用前に同じ局所で確認する。
写真と製品は紐の輪郭幅Dをそろえ、縦横を別々に伸ばさない。新しい候補に旧測定値をそのまま貼らない。

形を選んだ後に、糸筋と陰影を整える。糸筋は束の局所方向に沿い、見える部分から潜る部分まで続ける。
各粒に同じ楕円の縁取りや中心だけの光沢を貼らない。接触部の陰影は実際に隠れる箇所に対応させる。
`RoundTube8StrandTexture.shading` は旧レンズの腹位置で頭と尾の暗さを決めているので、新しい潜り込みと照合する。
8本側に閉じた変更とし、16本側の共通素材定数を動かさない。大量の繊維メッシュは不要。

## 5. 比較と完了条件

最初はSの生成りと書籍配色、正面と少し回した固定角度に絞る。
形を選んでから作者配色 **1・2青、3・4赤、5・6青、7・8赤**、全8本別色、Zへ検証を広げる。
今回のスクリーンショットは見える色だけから盤の配色を断定せず、比較には入力位置が分かる配色を使う。

- **通常の大きさで**、閉じた丸い粒の横並びという印象がK0より弱く、束の端が隣の下へ続くことが読める。
- 端の拡大で、隠れる直前にも幅があり、覆う束の輪郭が境界を作っていることを示す。単色と色分けの両方で見る。
- 作者配色の1束交替と半ピッチの帯が維持される。全8本別色で、形をつなぐために糸IDを取り違えていない。
- 背景の穴、下地の目立つ露出、突き抜け、周と長手の継ぎ目の断絶が増えていない。
- 一覧カードも同じ可視束の規則を使い、形・色の境界を更新する。最新配色のローダーを保つ。

報告には写真・K0・採用案を同じ条件で並べ、通常寸法と拡大、形のみと最終材質を区別する。
「高さが増えた」「先端の中心が隠れた」「試験が通った」だけを、楕円の粒の印象が解消した根拠にしない。
形の完全な写真一致や、未確定の物理的な糸の経路を証明したとは書かない。

## 6. 検証と作業範囲

対象は `RoundTube8SurfacePattern` 内の描画用束、`RoundTube8SurfaceMesh`、`RoundTube8StrandTexture`、
`RoundTube8ThumbnailView` と関連試験。形状ハッシュや旧円弧そのものを固定した試験は、変更の理由と新しい条件を明示して更新してよい。
旧run全長の円弧への一致を維持するために今回の形を戻さない。

追加の検査は、中心点だけでなく**端の幅方向の数点と、覆う束との境界の前後**を対象にする。
埋まる部分の糸IDと上に見える糸IDを区別し、実メッシュの視線で確かめる。隠れる相手を取り違えた人工例も拒むこと。
既存のカード対立体の広い標本、除外の条件と内訳、半ピッチ・交替・配色非依存・背面除去・反復の検査を維持する。
除外を広げたり、下地で覆われればすべて合格にしたりしない。曲がる先端で分割が必要なら、その位置を含めて標本化する。
