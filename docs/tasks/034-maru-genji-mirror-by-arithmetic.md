## 結果（2026-09-12）

### 答え: **鏡は違いを生まない。「どちらが実物か」という問いは消えた**

**占有履歴の輪を鏡に写すと、元の履歴に戻る。**したがって描いた面が手順表の鏡であること
（Task 032）は、**紐の違いではない。**外の資料は要らない。

**輪は16スロット全部で取った。**面の8列ではない——鏡はスロットをスロットに移すので、先に
詰め直しの対へ折りたたむと「その折りが鏡を越える」ことを別に論じなければならなくなる。

**除いた自由**（指示のとおり）: 周方向にどこから読むか、長手方向にどのサイクルから読むか。
**加えて、糸の名前も自由とした。**糸は出発スロットで名づけてあるが、それは名前であって、
紐の実体は「どの升が同じ糸か」である。ただし対応は**全64升で同じ1つの全単射**でなければならない。
**自由でないのは、どちらの端が組み点かである**（行はサイクル＝時間であり、紐は一方向に伸びる）。

| 読み方 | 合う軸・ずれ |
| --- | --- |
| **鏡あり、行はサイクル順** | **軸 3, 7, 11, 15（s + s' ≡ c mod 16）。ずれは 0〜3 のどれでも** |
| 鏡なし、行はサイクル順 | 回転 0, 4, 8, 12 のみ（紐自身の4回対称）。ずれはどれでも |
| 鏡あり、行を逆順（端を入れ替え） | **1つも無い** |
| 鏡なし、行を逆順 | **1つも無い** |

**糸の名前の対応は探索の産物ではない。**軸3・ずれ0で、対応はその鏡自身であることを別に固定した:
**スロット s から出発する糸が、s の鏡像から出発する糸に移る**（糸 t → (3 − (t−1)) mod 16 + 1）。
4本の軸はどれも**スロットとスロットの隙間**を通り、どのスロットも動かさない（だから軸は奇数）。

**この判定は違いを見分けられる。**端を入れ替えた読みが1つも合わないことが、それを示している——
上の自由さ（回転・ずれ・名前の付け替え）は、何でも通してしまうものではない。

### 配色での一致は、弱い証拠である（指示のとおり分けて書く）

bookA の配色でも鏡は合う（軸15・ずれ0、軸7・ずれ2）。**しかしこれは弱い。**配色が対称なら、
糸が合わなくても鏡で一致して見えるからである。実際この配色が合うのは4軸のうち2軸だけで、
片方は2サイクルのずれが要る——**配色は紐より対称性が低い。**
`bookAsColouringOfMaruGenjiAgreesThroughTheMirrorAsWeakerEvidence` で、糸の一致とは別の試験として
固定した（**色は名前ではないので、色の付け替えは許していない**）。
