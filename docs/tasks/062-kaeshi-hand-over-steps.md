## 0. 作者の答え（2026-09-25）

審査側の問い「丸台で返し組を組むとき、S から Z へ移る所では実際に何をするか」に、作者:
**「切り替える時、隣の紐を向こう側へ跨がせる。」**

教科書 p.38 の [4]「隣り合う糸の右側を動かします。8→6、16→14、24→22、32→30」と [8]「隣り合う糸の左側を動かします。
32→2、8→10、16→18、24→26」がこれにあたる。どちらも2スリットの手で、**動く糸は相方1本の上を越えて、その向こう側へ移る**。

## 1. いまの作り（審査側が読んだ。Task 061 の報告の読みを1つ訂正する）

- `yatsuKongoGaeshiRounds`（`BraidMethodCatalog`）は、S を2段ずつ3つの表、Z を2段ずつ3つの表にし、**持ち替え（`over`・`back`）を
  3つ目と6つ目の表の最後に入れている**。`BookDiskKongo.rounds` は、持ち替えで動く糸が**その直前の段で運ばれたばかりの糸**である
  ことを確かめたうえで、**その段の運びと持ち替えを、糸1本の1手にまとめて書く**（`BraidMethod` は1つの表で1本の糸を1回しか
  運べないため）。
- だから Task 061 のアニメーションで表3の最後の4手（と表6の最後の4手）が「4場所・3本の上を渡る」のは、**6段目の運び（3場所、
  2本の上）と持ち替え（1場所、相方1本の上）が1手に足されたもの**である。審査側が「2スリットの手が半周に見える」と書いたのは
  言い過ぎで、正しくは「**持ち替えが、直前の運びに黙って足されて見えない**」。
- 作者の答えのとおり、持ち替えは丸台でも**独立した動作**で、しかも糸の上を渡る（仮置きの寄せ直しとは違う）。**手に数えて見せる。**
- 3Dの導出はこのまとめた表で作られ、写真に照らして受領済み（Task 053・055）。**表と導出は変えない。**

## 2. すること

1. **手の台本で、まとめた手を2つに分ける。**
   - 6段目の運びは、ふだんの段と同じ3場所の手として見せる（着くのは相方の手前）。
   - そのあと、**持ち替えを4本それぞれ1手**として見せる: 「場所 p の糸を、隣の糸を越えて場所 q へ」（1場所、相方1本の上を渡る）。
     向きは本の [4]・[8] のとおり（[4] は後ろ向き＝左回り、[8] は前向き＝右回り）。
   - 手の順は本のとおり（6段目の運び4手 → 持ち替え4手）。
2. **分けるための材料は、表のデータに持たせる。画面や台本で組み方の名前を読まない**（`check-braiding-is-general.sh`）。
   例: `BookDiskKongo.rounds` が、まとめた手のうち「持ち替えの部分」（どの糸が、どちら向きに、何ノッチ）を表の付けたりとして
   返す。`BraidMethod` と導出はそれを読まない。名前と置き方は任せる。
3. **分けても、1回り終えたときの糸の場所は、まとめた表と同じになること**（試験）。途中の並びは、分けた手のとおりに描く。
4. **表の名前**: 「表4：」をやめる。表の付けたりに、本の言い方の短い名前を持たせる（データ側。例: S の表は「Sの組み」、
   Z の表は「Zの組み」、持ち替えの手の文には「持ち替え：」）。手の文は例えば「Sの組み：場所5の糸を、左回りに場所2へ」
   「持ち替え：場所2の糸を、隣の糸を越えて場所1へ」。
   **表が1つだけの組み方（江戸八つ・丸四つ・八つ金剛S/Z・丸源氏・平源氏）は名前を出さない**（いまと同じ）。
5. **数え方**: 持ち替えの手は「k / n 手目」に数える。

## 3. 試験

1. 返し組: 表3の手は 8＋4＝12。最後の4手はどれも1場所・相方1本の上を渡り、左回り。その前の4手は3場所・2本の上。
   表6も同じで、持ち替えは右回り。
2. 分けた手を1回り進めた糸の場所が、`BraidMethod` の手（まとめた表）で進めた場所と同じ。
3. 返し組以外の組み方の台本が、Task 061 と同じ（手の数・向き・渡る場所・文）。
4. 手の文に「表」「段」の語が出ない。返し組の文は「Sの組み：」「Zの組み：」「持ち替え：」で始まる。
5. 形状ハッシュ・カードの画素は変わらない。ガードを通す。

## 結果（2026-09-25、Claude Code）

### 1. 手の場所数は「3場所＋1場所」ではなく「2場所＋2場所」だった（指示書の 1・3.1 と違う所）

- `BookDiskKongo.rounds` の中で、段ごと・持ち替えごとの糸の場所（`placeOf`）を書き出して確かめた（S の3つ目の表）:
  6段目の運びは **どの段とも同じ 2場所**（場所6→4 など。1本の上）、持ち替えは **さらに 2場所**（場所8→6 など）で、**渡るのは相方1本だけ**。
  足して 4場所（Task 061 で1手に見えていた4場所）。Z の6つ目の表も同じで、向きが逆。
- **なぜ2場所か**: 持ち替えで動く糸は、相方のすぐ手前（隣の場所）から、相方を越えて**相方の向こう隣**へ移る。ディスクでは2スリット
  （8→6、あいだの7が相方）。台の8か所は等間隔なので、これも2か所で、あいだの1か所が相方の場所になる。**指示書の「1場所」は、
  相方1本の上を渡ることを場所で数え違えたものと読んだ**。「6段目の運びは3場所・2本の上」も、ふだんの段と同じ2場所・1本の上だった。
- 意味（ふだんの運びで相方の手前に着き、相方1本を越えて向こう側へ移る）は指示書のとおりなので、**数だけデータに合わせて試験を書いた**。

### 2. したこと

- **表の付けたり**（`BraidDiskNotation`）: `name`（表の短い名前）、`handOvers`（まとめた運び1つにつき、段の運びが糸を置いた場所 `via` と、
  2つの部分それぞれの本のディスクでの向きとノッチ数）、`handOverName`。**`method`（`BraidMethod`）と導出はどれも読まない**。
  返し組以外の表は `name` も `handOvers` も持たない。鏡（`reflected`）は付けたりを持たない。
- **`BookDiskKongo.rounds`**: 持ち替え（直前の段で置いた糸だけを動かす段）を見つけたとき、その糸の直前の場所と向きを `handOvers` に書き残す。
  表の手（`moves`）は前と同じ。`names`・`handOverName` を受け取れるようにし、返し組は「Sの組み」×3・「Zの組み」×3・「持ち替え」を渡す。
- **手の台本**（`BraidStepScript`）: `handOvers` が指す運びは `via` で止め（6段目の運び）、分けた運びのうち最後のもののあとに、持ち替えを
  1本ずつ手として置く（本の [4]・[8] の順）。向きはそれぞれの部分の本のディスクでの短い向き。持ち替えの手は、運びが置いた糸をそのまま
  動かすこと（そうでなければ台本を作らない）。`Hand` に `isHandOver` と `name` を足した。**組み方の名前は読まない**（ガードを通した）。
- **文**: 持ち替えは「持ち替え：場所8の糸を、隣の糸を越えて場所6へ」、ほかは「Sの組み：場所5の糸を、左回りに場所3へ」
  「Zの組み：場所7の糸を、右回りに場所1へ」。**「表4：」はやめた**（名前の無い表に「表」の字を出す仕組みも外した）。表が1つだけの組み方は
  名前を出さない（いまと同じ）。持ち替えの手は「k / n 手目」に数える。
- **1回りの長さ**: 返し組はレシピの配色で **6周期・56手**（表1・2・4・5 が8手、表3・6 が 8＋4＝12手）。Task 061 では 48手だった。

### 3. 試験（`KumihimoTests/BraidStepScriptTests.swift`）

   はじめの場所 1・2、3・4 …）、左回り、名前は「持ち替え」。その前の4手（6段目の運び）は2場所・1本の上、左回り、名前は「Sの組み」。
   表6は右回り・「Zの組み」。表1〜3は全部左回り、表4〜6は全部右回り（持ち替えを含む）。
2. 分けた手で進めた糸の場所が、周期の終わりごとに（1回り＝6周期のすべてで）`BraidMethod` の手で進めた場所と同じ。
