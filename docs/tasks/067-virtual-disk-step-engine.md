## 2. 新しい作り

### 2.1 本の手（データ）

- どの組み方にも「本のディスクの手」を持たせる: ノッチ数、組みはじめに各場所の糸が居るノッチ、表ごとのノッチの手の並び。
  - 江戸八つ組・丸源氏・平源氏・丸四つ組: いまの `BraidDiskNotation` の手がそのまま本の手（丸四つ組は本の図が無く、このリポジトリの書き方）。
  - 八つ金剛 S・Z・返し組: `BookDiskKongo` が等間隔へ書き直す**前の**手（刷られた段を、段ごとのずれで回したもの。返し組の持ち替え
    `over`・`back` を含む）。066 の (b) で持たせたものがあれば使う。
- 3Dの導出はこれを読まない。

### 2.2 仮想ディスクの上で回す（ドメイン。組み方の名前を読まない）

1. 糸の位置は**ディスクの角度**（ノッチ、描くときは連続の角度）で持つ。場所や `rank` は使わない。
2. 本の手を1つずつ動かす。**動く途中で他の糸の上を渡る（短い向きに通るノッチに糸が居る）手は「手」、何も渡らない手は「調整」**。
   調整は手に数えず、直前の手の動きに続けて動かす。これ1つで、仮置きの寄せ直し（江戸八つ 11→12・30→29、丸四つ・丸源氏の寄せ）は
   調整に、持ち替え（相方の上を渡る）は手になる。組み方ごとの特別扱い（`handOvers` で割る、`closing` を後に回す）は要らなくなる。
3. **寄せ**: 手のあと、**島の数と大きさが組みはじめと同じにそろったら**、それぞれの島を組みはじめの向きへ戻す（手に数えない。その手の
   終わりに動かす）。066 の「対がそろうたび」を、2本ずつに限らない形にしたもの。八つ金剛は2手ごと（066 と同じ）、江戸八つ組は
   仮置きの調整のあと、丸源氏は寄せ直しのあと。島の大きさがそろわないあいだは寄せない。
4. **島はその時々の並びから決める**: となりの糸とのノッチの差が、平均の間隔（ノッチ数÷本数）より小さいものをひとまとまりとする。
   2/2/2/2・4/4/4/4・6/2/6/2 を同じ規則で扱い、手の途中で島が3本・1本になってもよい。
5. **食い違わないこと**: 1周期のあと（寄せたあと）の場所ごとの糸は、`BraidMethod` で1周期進めたものと、**台を回した分を除いて**
   同じ糸の並び（まわりの順）になること。八つ金剛は、本の枠では1周期に糸が向かいまで（4場所）動き、`BraidMethod` の枠では2場所に
   見える。これは台を 90° 回して見た違いで、紐は同じ（審査側が回した。下の 3）。

### 2.3 絵（`BraidStepLayout` と `BraidStepFrame` を置き換える）

- 玉はその時の角度に置く。島の中で玉が重なるなら、島の真ん中を保って重ならない最小の間まで広げる（066 と同じ考え）。
- 向きは、**場所1・2 の島（066 の追加指示で本のスリット4・5）が上**。本の図と回さずに重なる。
- 手の間は、運ぶ玉を縁に沿って短い向きに滑らせ、渡る糸の線の上を通す。調整と寄せは手の終わりに続けて動かす。
- 文: 糸の出る所と着く所を、**組みはじめの場所の番号**で言う（寄せで島が元の向きに戻るので、番号は台の決まった位置の名前になる）。
  066 の文の形（「場所5の糸を、左回りに場所2の隣へ」、持ち替えは「隣の糸を越えて」）を全部の組み方に使う。表が複数ある組み方は
  表の名前を添える（いまと同じ）。

### 2.4 置き換えるもの（描き方と台本を1つにする）

- **全部の組み方を 2.2 の1つの作りで描く。** 丸源氏・平源氏・丸四つ組にも本の手（2.1）を持たせ、場所と `rank` で描く道を消す。
- **手の区切りを本の手から取る**（2.2 の2）。`BraidStepScript` の、`BraidMethod` から手を作る所（`ways(of:on:)`、`handOvers` で割る所、
  `closing` を後に回す所）は、使われなくなったら消す。導出が読まないデータ（`BraidDiskNotation.handOvers` など）も同じ。
  `BraidStepStage` を土台にしてよい（名前は任せる）。
- 066 の「2本ずつの対」を前提にした所は、2.2 の3・4 の規則に置き換える。

### 2.5 丸源氏・平源氏は、教科書の丸台の手で描く（作者、2026-09-27）

作者:「16丸源氏なんだけど、2/2/2/2/2/2/2/2 ではない。4/4/4/4 が基本。かわいい組ひもの教科書 p.94, 95 を参考にしてほしい。」

- **教科書では、十六丸源氏（p.94–95）と十六平源氏（p.96–97）の道具は丸台**。いまの表（book C Fig.20・Fig.32、ディスクの2本ずつの対）は
  3Dの導出のためのもので、**手順の絵には教科書の丸台の手を使う**（導出は変えない）。
- **台の形**: 4つの面（島）に4本ずつ。教科書の面の番号は **1面＝上、2面＝左、3面＝下、4面＝右**（反時計回り。アプリの場所の番号とは別）。
  面の中の糸は、面の真ん中を中心に等しい間で広げる（教科書の図のとおり扇に並ぶ）。
- **手（p.94–95、丸源氏）**: 1手で両手に1本ずつ、**2本を同時に**運ぶ（「左手で」「右手で」）。
  1. 3面の左端（左手）と右端（右手）→ 1面の中央へ
  2. 1面の左端（左手）と右端（右手）→ 3面の中央へ
  3. 4面の奥（右手）と手前（左手）→ 2面の中央へ
  4. 2面の奥（右手）と手前（左手）→ 4面の中央へ
  4手で1段。「糸の色は4段ごとに戻ります」。教科書はこの動きを「丸源氏手取り」（外側の糸を取って対面の内側に持っていく）と呼ぶ。
- **島の大きさは手ごとに変わる**: 手1のあと 1面6本・3面2本（6/4/2/4）、手2のあと 4/4/4/4 に戻る。**4/4/4/4 にそろったら寄せ**（2.2 の3）。
  6/2 のあいだも、面の中の糸は面の真ん中を中心に等しい間で広げる（6本の面は広く、2本の面は狭く）。
- **データ**: この手を「面から、面の中の何番目（左端・右端・奥・手前・左から2番目…）を取り、どの面の、どこ（中央・左端の糸の右側…）へ
  入れるか」という形で持つ（平源氏 p.96 の「3面の左から2番目」「1面の左端の糸の右側に」も同じ形で書ける）。この形は 2.2 の仮想ディスクの
  「ノッチの手」とは別の書き方だが、**回した結果は同じ「糸の並び順と島」になり、同じ絵・同じ寄せ・同じ試験で扱う**。
- **運ぶ道**: 教科書の矢印のとおり、鏡の上をまっすぐ対面へ（縁に沿って回さない）。2本は同時に動き、左手の糸は左側、右手の糸は右側に着く
  （図1・図2 の矢印は交わらない。図3・図4 の奥と手前が交わるかは図で確かめ、2.2 の5 の試験で決める）。
- **文**: 教科書の言い方で。例:「3面の左端と右端の糸を、1面の中央へ（左手・右手）」。
- **食い違わないこと**（2.2 の5）: 1段（4手）×必要な段数を回したあとの糸のまわりの順が、`BraidMethod`（book C の表）と台の回りを除いて
  同じになること。**同じにならなければ、奥と手前の読みを入れ替えて試し、それでも合わなければ止めて報告**（3Dの表と教科書の手の
  どちらかの読みが違うことになるので、作者の判断が要る）。
- **平源氏**: p.96–97 を読み、同じ形で書けるなら同じ作りで描く。書けない手があれば、丸源氏だけ済ませて報告する。

## 4. 試験

1. 江戸八つ組・八つ金剛 S・Z・返し組・丸四つ組・丸源氏・平源氏の1周期（返し組は全部）で、手と調整の数が上の表と、いまの台本の手の数と合う。
2. どの手も、運ぶ糸は他の糸の上を1本以上渡る。どの調整も、何も渡らない。
3. 寄せは、島の数と大きさがそろった手のあとだけ（八つ金剛は2手ごと）。寄せのあと、どの島も組みはじめの向きに戻る。
4. 1周期のあとの糸の並びが、`BraidMethod` の1周期と、台の回りを除いて同じ（2.2 の5）。
5. 島の決め方: 2/2/2/2（八つ金剛）、4/4/4/4 と手1のあとの 6/4/2/4（丸源氏、教科書の丸台の手）、1本ずつ4つ（丸四つ）。**6/2/6/2 の作りものの並び**（試験の中だけの、
   16本・32ノッチ）でも、6・2・6・2 の島が出る。
6. どの時点でも、止まっている玉どうしが重ならない（066 の試験を引き継ぐ）。
7. 3Dの形状ハッシュ・カードの画素は変わらない。ガードを通す。
