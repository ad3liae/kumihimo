# Task 050: 平源氏の中央の丸みと、縁の潜り込みを描く

- 状態: **実装済み・外観審査待ち**（2026-09-21）。Claude Codeが実装、Codexが審査する。実装結果は末尾。
- 起点: 作者「正直なところあまり改善していないが、PR作成させてマージした。平源氏の見た目の改善に取り組みたい」。
- 基準: main `47f396a`（PR #31）。048/049はマージ済みだが、八つ金剛の外観が合格したという意味ではない。残る差は保留し、今回は平源氏へ進む。
- 対象: 平ら16本の描き手、平源氏の立体と一覧カード。物理計算、手順表の再検討、他の組み方の改善は含めない。

## 1. 今回の到達点

**中央には糸束の丸い腹があり、縁の糸束は中央へ曲がってその下へ潜る。**
通常の表示寸法でもこれが分かるようにする。細かい糸筋を増やしただけ、明暗を強めただけの変更では完了にしない。

現行の `Flat16SurfaceMesh` は、各升を断面に沿わせて高さを加える構造である。
`crossingRelief` は腹と横向きの盛り上がりの最大値を取り、どちらも同じ升の色で描く。
この構造では、別の糸が中央の下へ入り込む関係を表しにくい。
`Flat16StitchTexture` の四辺の暗化と、カードの升ごとの輪郭線も格子の印象を強める候補である。
これはコードからの診断であり、現行版の比較画像H0で見える問題と照合してから直す。

**配色の場所を表す升と、糸束の外形を分ける。** 升の占有履歴は保ち、可視部分の糸束を
丸み・肩・潜る端を持つ面として描く。少なくとも縁と中央の接点には、実際に前後して隠れる別々の面が必要である。
全16本の内部経路や繊維1本ずつのメッシュ、接触を解く物理模型は不要。

## 3. 維持する対応と、変更してよい形

手順表、一般の導出、糸ID、4行の反復、各場所の占有、表裏・縁の対応、現在の到着位相を維持する。
製品経路は `Flat16SurfacePatternGenerator.working` と `Flat16WeaveFromWorking` である。
旧 `HiraGenjiWeaveDerivation` を製品の正本に戻さない。

描画用の区間は、糸ID・行・表裏・場所へ戻れるようにする。
`Flat16WeavePattern` の `patches`・`edgePlaces`・`weftCrossings` と次の場所を使い、
同じ色の隣接区間を同じ糸と見なしてつながない。配色を変えても形は同じであること。

- 中央の本体は片面の列1〜4。最外列0・5と、その外の縁の場所を混同しない。最外列0・5の可視束を消さない。
- 横切る糸は本体の下を通る。縁には表側・裏側の糸があり、それぞれ自分の半分にいる。**縁の1本を表から裏へ厚み一周のU字にする案は採らない。** 007Jで対応の誤りが判明している。
- 縁から中央へ入る箇所では、外で隣り合う区間と、中央の下へ潜る区間を分ける。外の腹に中央の薄い端を突き刺して「重なった」としない。見える端を切断面のまま並べない。
- 同じ糸が縁の場所から最外列へ続く箇所で、升の端というだけの理由で厚みを0にしない。007Jで両端付近に背景の穴が開いた原因である。全周と長手の反復の継ぎ目も連続させる。
- 中央の腹・肩・縁の引き込み・繊維の局所方向は変更してよい。色の段の傾きと、腹の輪郭や撚りの傾きを分ける。`faceStitchLean = 0` を理由に腹まで長方形に固定せず、逆に写真の糸筋だけを根拠に本体のはしご模様を斜めに変えない。

寸法はピッチ/紐幅 `0.3665`、素の断面の幅/厚み `3.3359`、旧形状の頂 `0.45` を開始値とする。
旧関数の係数0.45を新しい形の写真一致の証明には使わない。形状関数が変われば、最終輪郭の幅・厚みと束の見える長さを確かめ直す。
写真に近づけるための形の調整は今回の範囲で行ってよい。動かした値、根拠、写真から測れた量と描画上の選択を記録する。
一律の暗い溝や、全面を覆う平らな色板で形の隙間を隠すことは解決としない。

007I/007Jは失敗と訂正を読む資料であり、旧ブランチ全体を取り込む指示ではない。
過去の「定数を変えず、各段階で承認まで止まる」という作業手順を再開しない。
このタスクの範囲で、小さな比較を挟みながら実装と検証を進める。糸の対応に資料と矛盾が出た場合は、矛盾点を報告し、その部分の対応を推測で変更しない。

## 4. 形を先に比較し、その後に材質とカードを整える

1. **H0**: 現行mainの生成り単色と、既存の横糸着色または矢絣の配色を撮る。正面と縁が見える斜めの固定角度に絞る。
2. **H1**: 同じカメラ・照明・配色で、中央の腹と縁の潜り込みを変更した製品レンダーを出す。形の比較用に細かい糸筋を外した共通材質の対照も少数残す。中央・縁それぞれについてH0との差を確認する。
3. **最終候補**: 形が読めることを確かめてから、束に沿う糸筋、反射、接触部の陰影を調整する。候補はまず1つ、必要なら対照をもう1つに絞る。形がほぼ変わって見えないまま大量撮影や全件試験へ進まない。

八つ金剛や丸源氏の形状係数を平源氏の正解として転用しない。共通の材質定数を変更して他の紐まで変えない。
最終比較は通常表示寸法と拡大した中央・縁の切り抜きを両方示す。拡大した糸筋だけで改善を主張しない。

**カードも今回の対象。** 現行 `Flat16ThumbnailView` の輪郭付き升を残して、立体だけ別の外形にしない。
立体と同じ描画用区間・糸ID・重なりから可視部分を決め、一周の展開図として描く。
Task 029-2の上から右縁・表・左縁・裏の順、16場所を一周すべて見せる意味は保つ。
投影方法が違うので画素の一致ではなく、対応する場所で見える糸と境界の向きを照合する。

047の申し送りにあるカードの密度差は、平源氏自身のピッチと断面を基準に確認する。
丸源氏の比1.25へそろえるために平源氏を伸ばしたり、片面だけへ戻したりしない。
現行比0.54975には「表の弧＝紐幅」の近似がある（029に記録）。今回、最終形状と整合させる必要があれば

## 5. 受け入れ条件

| 観点 | 最終製品で確かめること |
| --- | --- |
| 中央の形 | 単色の通常表示でも、腹から肩へ丸く下がる束が読める。升ごとの平板、連続した横棒、全面の深い格子が主役にならない。H0と同条件で示す。 |

| 継ぎ目 | 縁の区間と最外列の接続、長手の反復、表裏と縁の境目に不自然な切断、背景の穴、色の飛びがない。 |

配色の検査は元の占有配列だけで終えず、**新しいメッシュまたはその可視面判定に対して行う**。
中央と縁の重なる箇所、反復の境目を含める。検査が製品と同じ式をそのまま再計算するだけにならないよう、
三角形への視線などで可視の糸IDを確認し、別の糸IDや上下逆の人工例を拒む小さな検査も置く。
全体の最大値が部分集合の最大値以上、というような自動的に成立する条件で不一致を除外しない。

メッシュの水密性自体は要求しない。実際の輪郭の外まで不透明を要求せず、紐の内側での不自然な背景露出を調べる。
既存の平源氏には三角形の向きに既知の問題がある。変更した面の表裏・法線を確認し、背面を消す通常設定で穴が出ないこと。
全体の符号反転、両面表示への切替、検査範囲の切り捨てで不具合を隠さない。

### 1. 何を変えたか

**升と糸束を分けた。** 升（`Flat16SurfacePatch`）はそのまま——場所・糸ID・色・行・表裏・
到着位相は1つも動かしていない。その上に**可視の糸束**（`Flat16Bundle`）を新しく載せ、
立体・一覧・検査の3つがその1つの形を読む。

| ファイル | 変更 |
| --- | --- |

| `Kumihimo/Domain/Flat16SurfacePattern.swift` | 升ごとに束を作る。区画の弧の割り当て（`arcSpan`）をここへ移した（メッシュは読むだけ） |

### 2. 中央の形

**束は自分の升より幅広く（1.694レーン）、長い（1.855段）。** 隣の升の脇に乗り、同じレーンの
前後の区間と重なる。**どの方向にも谷まで落ちない**——落としていたのが、H0の「全面の深い格子」の
正体である。

- **腹**: 盛り上がりは**持ち上げた余弦**。円弧（＝丸い糸の断面そのもの）も放物線も試したが、
  どちらも幅の中ほどがほぼ平らで、正面からの照明では**平らな升に細い溝を切った**ようにしか
  見えなかった。余弦は半分の位置で半分の高さになるので、腹から肩へ丸く下がる。
  **これは「束がどう読めるか」の描画上の選択で、糸の断面についての主張ではない。**
- **レンズ**: 升の両端で幅が 0.62 に絞られる。四つの束が**点**で分かれるので、レーンの境目が
  一直線の溝にならない。等幅で試すと面が長方形の刺し子になった（＝「升ごとの平板」）。
- **絞りすぎると別の失敗をする**: 本体の升は全レーンが同じ位置で終わるので、絞った幅が
  1レーンを割ると**紐を横断する一直線の隙間**が開き、床が見えた（1.18×0.7=0.83で実見）。
  いまは 1.694×0.62=1.050 で、いちばん細いところでも重なっている。

### 3. 縁と、中央への潜り込み

- **縁の2レーン**は超楕円の先端を回る束として描かれ、斜めから**厚みのある丸い粒の連なり**に
  見える（`.build/task050/sheets/edge-h0-h1.png`）。
- **最外列 c0・c5 の区間**は007Jが移動規則から決めた形をそのまま使う——
  **曲がり始めはその糸の横切りが始まる位置、向きは `passedColumns.first`、速さは
  1段で `passedColumns.count + 1` レーン。3つとも読んだ値で、選んでいない。**
- **曲がると同時に潜る**（`Flat16Bundle.diving`）。1レーン進む＝自分の升の終わりまでに完全に
  床下へ入る。**これは見栄えではなく必須だった**: ゆっくり沈めると、本体の四隅が分かれる点から
  横糸の色が覗き、「横糸だけの着色が中央4列へ露出しない」が破れる（実際に破れた）。

### 4. 動かした寸法と、動かしていない寸法

**動かしていない**: `stitchPitchPerBraidWidth` 0.3665、`crestHeightRatio` 0.45、
`widthToThicknessRatio` 3.3359、`faceStitchLean` 0、`edgeStitchLean` 0.24、
`longitudinalPhases`（到着位相）、手順表・一般導出・糸ID・4行の反復・占有・表裏と縁の対応。

**新しく置いた形の値**（すべて `Flat16SurfaceMesh.shape` に出所つきで載る）:

| 値 | 出所 |
| --- | --- |
| 同じレーンの前後の区間が出会う高さ 0.16 | 目視（bookA p.72の紺の本体と作者の紐の粒の分かれ方） |
| 隣のレーンの束と出会う高さ 0.36 | 目視。長手より浅い——長手は2本が入れ替わる交差、幅方向は並んで押し合うだけ |

### 8. 残る差（**ここが審査の要点**）

1. **本体の粒が長方形の格子に並ぶ。写真は斜め（千鳥）である。** bookA p.72を拡大すると、
   紺の粒は長軸が紐の軸から30〜40度傾き、隣のレーンとは半粒ずれている。いまの描画は
   粒1つ1つは丸いが、並びは升の格子そのままである。
   - 束の輪郭を傾ければ写真に近づくが、**30度に足りる傾き（1段で1.27レーン）は束を隣の
   レーンへ運んでしまい、色の対応が壊れる。** 小さい傾き（0.5レーン＝12度）では写真に届かない。
   - **導出側には材料がある**: 一般導出は列1・4が手3〜4、列2・3が手5〜6で**0.286段ずれる**と
   言っており（`longitudinalPhases` の「報告するが適用しない」）、写真の千鳥と向きが合う。
   ただし050は「現在の到着位相を維持する」と指示しており、**位相は動かしていない。**
   - もう1つの候補は**横糸の通り道そのもの**である。横糸は1段で面を横断するので、その下を
   通る位置はレーンごとに1/6段ずつずれた斜めの線になる。縦糸がその上へ乗る盛り上がりを
   そこに置けば斜めが出る。ただし各面を1段に2本が**逆向きに**横切るので出るのは矢羽根で、
   「本体は平ら」というp97の読みと突き合わせる必要がある。**推測で置かず、報告に留める。**
2. **一覧と立体の密度差は縮んだが閉じていない**（丸源氏1.25 対 平源氏0.6113、2.05倍）。
3. **縁と本体のあいだで横糸が0.5%覗く**（上の5節）。束が隣へ乗る以上起きることだが、
   これでよいかは外観の判断である。
4. **「いちばん手前が裏向き」が1%未満残る**（上の6節）。穴ではないが、折り返しの描き方に
   まだ余地がある。
5. `crestHeightRatio` 0.45 は007Eの測定のまま。**形の式が変わったので、この値が同じ波を
   描くかは測り直していない。** シルエットの波の測り直しは今回やっていない。
