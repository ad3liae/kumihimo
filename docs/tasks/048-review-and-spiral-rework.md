### 1. 何を何へ対応させたか

**台の場所を完成紐の同じ列に固定するのをやめた。** 手順表・占有履歴・糸IDの計算は1行も変えていない。
変えたのは `(サイクル r, 台の場所 s, 糸ID)` を完成表面の `(列 j, 長手)` へ写す描画上の写し方である。

- **`j = (s − lean × r) mod 8`**（`RoundTube8SurfacePatternGenerator.drawnColumn`）。S（lean −1）は `j = s + r`、Z は `j = s − r`。
  **1サイクルに1列、完成紐が回る。** bookA p.54 の「鏡の下でひもが回転しながら組み上がります」に沿う描画候補で、
  **回転量1列はこの注記から導いたものではなく、4場所周期の配色が1束ごとに替わる最小の回し方として選んだ描画上の決めである。**
- **半ピッチの位相は移した先の列に付ける**（`drawnPhase(ofColumn:)`）。偶数列が1サイクル、奇数列が½（S）。
- **どちらの偶奇を1サイクルにするかは手順表から決める**（`wholeCycleOnEvenColumns`）。**色は見ない。**
  規則は「**傾きの向きへ半ピッチ進んだ先が、台の 1と2・3と4・5と6・7と8 の対になるほう**」。鏡はこの対を対へ移すので S と Z が同じ規則で決まる。

**写真での裏取り**（bookA p.8-9 の S、書籍の配色）: Task 031 の `colour_angle` で、この選び方の色の帯は **+38°**、
写真は **+53°** と同じ向き。もう一方の選び方（Codex の候補A）は **−27°** で符号が逆になる。**符号が合うほうを採った。**
（0.403 のときの比較。C=0.807 では中央の帯が1列ぶんしかなく読みが量子化されるので、この比較には使っていない。Task 032 が記録した穴と同じ。）

**初回048の二重化がどう消えたか**: 場所を固定していたとき、Sの場所1を長手に並べた糸は 1,4,7,2,5,8,3,6 で、
4場所周期の配色では色が2つずつ続いた。新しい写し方では固定した**列**1に並ぶ糸が S で 1,3,5,7,1,3,5,7、Z で 1,7,5,3 となり、
**1束ごとに色が替わる**。作者指定の配色（青青赤赤青青赤赤）でも書籍の配色でも、列に沿って1束ごとに交替する。
