## 1. いまの作り（審査側が読んだ）

  - 丸源氏・平源氏: `diskRestingNotches`（book C の 16 本。2本ずつ、8組が等間隔）
  - 丸四つ組: `diskRestingNotchesForFour`（1・9・17・25。等間隔）
  ただし `BraidRecipe` には持たせていない。八つ金剛の表（`BookDiskKongo.rounds`）は、導出のために等間隔の
  `diskRestingNotchesForEight` へ書き直してあるので、**表のノッチからは対が読めない**。
- `BraidStands.round8` の `groups`（north [8, 1] …）は Task 055 より前の対の取り方のまま（いまの対は 1・2、3・4、5・6、7・8）。

## 2. すること

1. **データ**: `BraidRecipe` に「本の組みはじめで、場所ごとの糸がどのスリットに居るか」（ノッチ数と、場所順のスリット番号）を持たせる。
   値は 1 のカタログの定数から入れる（新しく書き写さない）。導出と手の台本はこれを読まない。
2. **並べ方（絵だけ）**: 手順のアニメーションの台の上で、各場所の玉を**そのスリットの角度**に置く。
   - **向き**: 場所1を含む**島**（となりのスリットとの間が、平均の間隔より狭いものをひとまとまりとする）の真ん中が真上に来るように回す。
     八つ金剛・江戸八つ組・返し組は、場所1・2の島が北、3・4 が東、5・6 が南、7・8 が西になる（配色の画面の場所1が上、と同じ向き）。
     丸四つ組は島が無く、いまと同じ等間隔（場所1が真上）。丸源氏・平源氏は2本ずつの島が8つ、等間隔に並ぶ。
   - 島の中の2本の間隔は、本のスリットのままだと玉が重なるなら、重ならない最小の間まで広げてよい（島どうしの間ははっきり空ける）。
   - 場所の番号の添え書きも、玉の位置に合わせて動かす。
3. **脇に寄せた糸・滑る糸**: いまの「来た側の脇」「縁に沿って滑る」はそのまま。ただし**島の相方の玉と重ならない**こと
   （相方の側に寄るときは内側へずらすなど）。江戸八つ組の手1（場所7→場所1、場所1の脇で待つ）は、場所8の側（島の外側）で待つ。
4. **このデータが無い組み方**（今後の組み方で本の図が無いもの）は、いまの等間隔で描く。

## 3. 試験

1. 八つ金剛 S・Z・返し・江戸八つ組: 場所1・2、3・4、5・6、7・8 がそれぞれ島になり、島の真ん中が 0°・90°・180°・270°。
   島の中の2本は、島どうしの間より近い。
2. 丸四つ組は等間隔で場所1が真上（いまと同じ）。丸源氏・平源氏は島が8つ。
3. どの手のどの時点でも、玉どうしが重ならない（江戸八つ組の手1〜4、八つ金剛の1周期、返し組の持ち替えを含む）。
4. 手の台本（手・向き・渡る糸・文）は Task 062 と同じ。形状ハッシュ・カードの画素は変わらない。ガードを通す。

## 結果（2026-09-26、Claude Code）

枝 `claude/task-066-stand-layout-in-pairs`。コミットは `fc02aea`（審査側の文書）、そのあとに実装、そのあとに記録。

### 1. したこと

- **データ**: `BraidStartingSlits`（ノッチ数と、場所順のスリット番号）を `BraidRecipe.startingSlits` に持たせた。7つの組み方すべてに
  カタログの定数から入れた（新しく書き写していない）:
  - 八つ金剛 S・Z: `yatsuKongoStartingSlits`（S・Z の表を作るときに書いていた `[12, 13, 20, 21, 28, 29, 4, 5]` を名前の付いた定数にして、
    表と同じものを使う。値は同じなので表は変わらない）。返し組: `yatsuKongoGaeshiStartingSlits`（同じく `[1, 2, 9, 10, 17, 18, 25, 26]`）。
    江戸八つ組: `edoYatsuStartingSlits`。
  - 丸源氏・平源氏: `diskRestingNotches`（ノッチ → 場所の表を場所 → ノッチに引き直す `init(notchCount:placeByRestingNotch:)`）。
    丸四つ組: `diskRestingNotchesForFour`。ノッチ数は各表の `notchCount`（八つは `BookDiskKongo.notchCount`）。
  - 導出と手の台本は読まない（`startingSlits` を外したレシピで同じ台本・同じ `BraidMethod` になる試験）。
- **並べ方**（`Kumihimo/Features/BraidSteps/BraidStepLayout.swift`、絵だけ）:
  - 各場所の玉を、そのスリットの角度に置く。となりとの間が平均の間隔より狭い場所を島とし、場所1を含む島の真ん中を真上に回す。
  - **島の中の間は、本のスリットのままで玉が重なるときだけ**、重ならない間に少しの隙間（台の半径の 0.04）を足した所まで広げる。
    八つ金剛・江戸八つ・返し組は本の1ノッチ（11.25°）では重なるので 19.6° に広げた（島どうしは 70.4° 空く）。丸源氏・平源氏は
    本の1ノッチのままで重ならないので広げていない。玉の大きさは前と同じ。
  - 場所の番号と矢印の端も、玉の位置（`turn(of:)`）に合わせて動く。
- **脇で待つ玉**（`BraidStepLayout.beside`）: 自分の場所の玉と、その側のとなりの場所の玉の両方から離す。島の外側（間が広い側）では
  いまと同じく縁の近く、脇に寄せて置く（離れが足りないときだけ少し外へ）。**島の相方の側は間に入らないので、2つの玉の間の内側へ
  ずらし、場所が空いて滑り込むまでの道のりでも相方と重ならない所を選ぶ**（相方の側へどれだけ回すかを、道のりが相方から離れる範囲で
  いちばん大きく取る）。江戸八つ組の手1（場所7→場所1、場所1の脇で待つ）は、指示書のとおり場所8の側（島の外側）で待つ。
- **データが無い組み方**は、台の等間隔（`BraidStand.positions[].rim`）で描く。
- `BraidStepFrame.at` と `polarPoint` は台（`BraidStand`）の代わりに並べ方（`BraidStepLayout`）を受け取る。滑り方（縁に沿う、持ち上がる、
  視差効果を減らすでは切り替え）は変えていない。
- `architecture.md` の手の台本の段落に1段落。

### 2. 試験（`KumihimoTests/BraidStepLayoutTests.swift`、新しい）

1. 八つ金剛 S・Z・返し・江戸八つ組: 島は `[[1, 2], [3, 4], [5, 6], [7, 8]]`、真ん中は 0°・90°・180°・270°。島の中の2本の間は
   島どうしの間より狭く、玉は重ならず、本の1ノッチより広い。
2. 丸四つ組は島が無く、場所1が真上で、前と同じ等間隔。丸源氏・平源氏は2本ずつの島が8つ、真ん中が 45° おき、島の中は本の1ノッチ。
   データの無いレシピは台の等間隔。カタログの定数と同じスリット。
3. **7つの組み方の1回り（台本の全部の手）で、0.05 秒おきに、視差効果を減らす／減らさないの両方で**、運ばれていない玉どうしが
   重ならない。手の始めと終わり（全部が止まっている時）は全部の玉どうしが重ならない。**運ばれて滑っている玉は、通り過ぎる糸の上を
   渡るように描いているので（仕様）、その間は数えない。** 江戸八つ組の手1は場所8の側、縁の近くで待つ。
4. `startingSlits` を外したレシピで、台本（手・向き・渡る糸・文を含む `BraidStepScript` 全体）と `BraidMethod` が同じ。
   既存の `BraidStepScriptTests` は並べ方を受け取るように直した（主張は同じ。江戸八つ組の脇の玉は「場所8と場所1の間」を、島の角度で確かめる）。

途中、2つ直した: (1) 島を広げる条件を「重なるなら」にした（はじめは「隙間込みで近いなら」で、丸源氏・平源氏まで 0.0000061 回転広げていた）。
(2) 島の相方の側で待つ玉が、場所へ滑り込む途中で相方と 0.28（玉2つ分は 0.30）まで近づいた（返し組・八つ金剛の手3・4）ので、
道のりも確かめて待つ所を選ぶようにした。

### 5. 判断が要る点（八つ金剛 S・Z・返し組）

**1段目のあと、アプリの島の組み方が本と1つずれる。** 台本（場所の動き）は本と同じ糸の並びだが、絵の島は場所1・2、3・4 … に
固定してある。本では1段で4本が運ばれ、**運ばれた糸は向かいの対の残る糸の隣に入る**（S の手1: スリット20 → 6、場所8〔スリット5〕の隣。
手2: 4 → 22 は場所4 の隣、手3: 12 → 30 は場所6 の隣、手4: 28 → 14 は場所2 の隣）。1段目のあと本の対は 場所8・糸3、場所2・糸5、
場所4・糸7、場所6・糸1 で、ディスクの上では対が1ノッチずつずれる（本の「スリット番号は…一つずれます」）。
アプリの台本は同じ糸を場所3 → 1、7 → 5、1 → 7、5 → 3 と運ぶ（場所を2つ戻る。Task 053 の読み）。**並びは本と同じ**（1段目のあとの
時計回りの並びが 糸8、3、2、5、4、7、6、1 で本と一致する）が、アプリは場所1・2 を1つの島に描くので、**糸3 は北の島（場所2 の隣）に入って
見え、本のように西の島（場所8 の隣）には入らない。** 運ぶ距離も、本はほぼ半周、アプリは4分の1周に見える。江戸八つ組は対がずれないので
本と同じに見える。比較図の S・Z の手2〜4 で見える。
