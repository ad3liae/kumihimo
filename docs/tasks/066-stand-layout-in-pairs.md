## 2. すること

2. **並べ方（絵だけ）**: 手順のアニメーションの台の上で、各場所の玉を**そのスリットの角度**に置く。
   - **向き**: 場所1を含む**島**（となりのスリットとの間が、平均の間隔より狭いものをひとまとまりとする）の真ん中が真上に来るように回す。

   - 島の中の2本の間隔は、本のスリットのままだと玉が重なるなら、重ならない最小の間まで広げてよい（島どうしの間ははっきり空ける）。
   - 場所の番号の添え書きも、玉の位置に合わせて動かす。
3. **脇に寄せた糸・滑る糸**: いまの「来た側の脇」「縁に沿って滑る」はそのまま。ただし**島の相方の玉と重ならない**こと
