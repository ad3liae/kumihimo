## 1. 模型（039 の 1 節に、次の 1 つを足す。**これだけ**）

### 天辺に乗った区間（**新しい区間**）

一本の糸は三つの区間から成る。**固定部**（039 と同じ）、**乗った区間**（固定端の先、天辺の上に置かれている。**縮めない**）、
**扇**（天辺を離れてから穴の縁の点まで。**縮める**＝最短）。

**乗った区間の定義**: 自由部を固定端から縁へ辿って、**固定部の球（芯を含む。どの糸のものでもよい）に接触の閾値（1.25 d）以内で
触れている最も遠い球まで**。あいだに触れない球があってもよい（別の自由部の上を渡っている所）。その先が扇。**乗った区間の球は、
その手の `shrink` を受けない**（held と同じ扱い）が、**間隔 d の置き直し（`space_out`）と押し離し（`push_apart`）は受ける**——
後の手に乗られれば横へ避ける（作者の見立て「下にあったものは避ける方向へズレる」）。**固定はされない**（乗られるまで）。
判定はその手の「運ぶ」の直後（張る前）に 1 回。

**乗られた判定・固定端の前進は 039 のまま**（後の手・1.25 d・上・水平 < d。固定端は「乗られていて、かつ固定部に触れている」
最も遠い球まで）。乗った区間の球は定義から固定部に触れているので、**乗られれば固まる**。

### 種

039-1'' の芯（六方格子・間隔 d・r ≤ 束の半径・19 球）を **結び目と同じ面（z = 組み点。`--core-lift 0`）**に置き、**その下に同じ
格子を 3 層**（z = 組み点 − d・−2 d・−3 d、r ≤ 束の半径 + d/2）足す——結び目は塊の天辺の縁に乗っている。**弦が結び目の下へ
回る道を塞ぐ**（039-1'' の潜り）。芯の球は結び目の球と重なってよい（held どうし。残差から外す。039-1'' の読み）。

## 2. 一手（039 の 2 節と同じ順。**2. 張る**だけ違う）

  1. 運ぶ    022 の `carry`（越える物の d 上、弧なし）。**置いたものがそのまま乗った区間になる。**
  2. 張る    全糸同時、022 の `taut.tighten`。**乗った区間は縮めない**（`shrink` の対象から外す。`space_out`・`push_apart` は受ける）。
            扇は固定（乗った区間の最後の球）と穴の縁の点のあいだで縮める。
  3. 固める  039 のまま。
  4. 送る    039 のまま（固定部の柱の最高点、固定部だけ下げ、下げるだけ、張り直す）。
  5. 記録    039 のまま ＋ 手ごとの乗った区間の球数（糸ごとの合計と、0 本の糸の数）。

1. **1〜3 手目から固まる**（弦は芯の上に置かれたまま、次の弦に乗られる）。
