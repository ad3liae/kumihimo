# Task 002: 作品編集画面の基盤

- 状態: Blocked
- ブロック理由: Task 001のレビュー完了と `docs/specifications/project-editor.md` の設計承認待ち
- 優先度: 高

## Workerへの依頼

新規作品と保存済み作品で共用する編集・詳細画面の基盤を実装する。

作業前に、ルートの `AGENTS.md` と以下を読むこと。

- `docs/product.md`
- `docs/architecture.md`
- `docs/specifications/home-screen.md`
- `docs/specifications/project-editor.md`

## 実装範囲

- ホームの新規作成・保存作品から共通編集画面への遷移
- 永続化モデルを直接変更しない `ProjectDraft`
- 新規保存、上書き保存、名前をつけて保存
- 右上に常設する保存ツールバー
- 作品名入力シートと入力検証
- 4、8、12、16本の糸本数選択
- 円形天板、中央穴、糸位置、糸を表す俯瞰図
- 仮の固定色カタログと色選択シート
- 組み方を未選択にできる永続データ構造
- Previewと、保存・複製・糸配置に関する自動テスト

## このTaskでは実装しないもの

- 実在の組み方に基づくシミュレーション計算
- 実際の完成結果に見せた仮の模様
- ユーザー独自の組み方
- 商品色コードとの連携

シミュレーション結果セクションの本番実装は、`docs/tasks/003-braid-simulation-presets.md` で扱う。Task 002では、後続処理を受け取れる画面状態と境界までを用意し、Preview専用fixtureを本番データと分離する。

## 完了条件

- シミュレーション結果以外について、仕様書の該当する受け入れ条件を満たす。
- 新規保存、上書き保存、名前をつけて保存のID・日時・元作品への影響を自動テストできる。
- 組み方を未選択のまま保存・再読込できる。
- 糸本数と位置別色IDを保存・再読込できる。
- 外部パッケージを追加せず、利用可能なビルドとテストが成功する。
