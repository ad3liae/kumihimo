# Task 002: 作品編集画面の基盤

- 状態: Done
- 優先度: 高
- 仕様: `docs/specifications/project-editor.md`

## Workerへの依頼

新規作品と保存済み作品で共用する編集・詳細画面の基盤を実装する。

作業前に、ルートの `AGENTS.md` と以下を読むこと。

- `docs/product.md`
- `docs/architecture.md`
- `docs/specifications/home-screen.md`

## 実装範囲

- ホームの新規作成・保存作品から共通編集画面への遷移
- 永続化モデルを直接変更しない `ProjectDraft`
- 新規保存、上書き保存、名前をつけて保存
- 右上に常設する保存ツールバー
- 作品名入力シートと入力検証
- 4、8、12、16本の糸本数選択
- 円形天板、中央穴、糸位置、糸を表す俯瞰図
- 仮の固定色カタログと色選択シート
- 組み方を未選択にできる永続データ構造
- Previewと、保存・複製・糸配置に関する自動テスト

- 実際の完成結果に見せた仮の模様

- 商品色コードとの連携

シミュレーション結果セクションの本番実装は、`docs/tasks/003-braid-simulation-presets.md` で扱う。Task 002では、後続処理を受け取れる画面状態と境界までを用意し、Preview専用fixtureを本番データと分離する。

## 完了記録

- 完了日: 2026-08-23
- 実装概要:
  - ホームの新規作成と保存作品から、同じ作品編集画面へ遷移するようにした。編集画面はSwiftDataモデルを直接変更せず、`ProjectDraft` と専用の保存サービスを介して、新規保存、上書き保存、名前をつけた複製保存を行う。
  - 永続モデルへ任意の組み方プリセットIDと、安定した位置番号・固定カタログ色IDからなる糸配置を追加した。組み方未選択、4・8・12・16本の糸配置を保存・再読込できる。
  - 右上の保存ツールバー、名前入力と検証、糸本数Picker、減数確認、円形天板・中央穴・糸・位置番号の俯瞰図、44ポイントの選択領域、12色の選択シートを実装した。確認・選択後は表示状態を先に解除し、ダイアログやシートが確実に閉じてからDraftへ反映する。
  - Task 003でシミュレーション処理を接続できる画面状態境界を用意し、計算中・失敗表示のfixtureはDebug Previewへ分離した。新規／16本多色／未選択・選択済み既存作品／長い名前／ライト・ダーク／最大文字サイズ／保存名シートのPreviewを追加した。
- 検証結果:
  - Xcode 27.0 Beta、iPhone 16（iOS 18.5）で単体テスト14件とUIテスト7件の計21件が成功した。新規保存、上書き時のID・作成日時維持、複製時の元作品不変、新しい編集対象への切替、未選択状態と位置別色IDの再読込、糸本数の増減を自動テストした。
  - ホームから新規・既存編集画面を開く、新規作品へ名前をつけて保存する、既存の削除をキャンセル・確定するUIフローに加え、8本から4本への減数確認で「減らす」「キャンセル」のどちらを選んでもダイアログが閉じることと、色選択直後にシートが閉じることを確認した。
  - Debug構成とRelease構成のiOS Simulatorビルドが成功した。
  - Simulatorで、標準文字サイズ・ライトモードの4本新規作品と、最大アクセシビリティ文字サイズ・ダークモードの16本多色作品を目視確認した。位置番号の過拡大を修正し、16位置を重ならず判別できることを再確認した。
- 残った制約:
  - 実在の組み方、完成イメージ生成、組み方の選択UIはTask 003で実装する。現時点では配色だけを有効な作品として保存できる。
  - 未保存の変更がある状態で戻る操作をした場合の扱いは仕様上未決のため、このTaskではiOS標準の戻る挙動を維持している。
  - VoiceOverの実際の読み上げ順序、iOS 17ランタイム、実機での操作は未確認。

## 追補: 糸本数の減数確認

- 修正日: 2026-08-23
