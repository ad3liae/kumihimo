# Task 021: 反発による深さの導出

- 状態: 未着手（指示書のみ。**この段では実行しない**）
- 優先度: 高。Task 020 段階3（汎用の3D描画）の前提
- 作成日: 2026-09-07
- 前提: Task 020 の積み重ね模型（`docs/architecture.md`「積み重ねの模型（確定版・密に積む）」）

## 目的

積み重ね模型に欠けている**半径方向（厚みの中の深さ）**を出す。

**物理で「組ませる」のではなく「詰めさせる」。** トポロジー（どの糸がどの糸の上か）は手順表が
決めてある。**幾何は反発が決める。** Task 016 が解けなかったのは組み点を解くことであって、
これはそれとは別の問い——**すでに決まった上下のもとで、糸がどこへ落ち着くか**である。

## なぜ要るか

Task 020 積2 で、積み重ね模型の最上層を「外から見えるもの」と読み替えて Task 004 の表と
比べたところ一致しなかった。**原因は模型の誤りではなく、層が長手方向に並ぶので「最後に置いた」
が「外側」を意味しないことにある。模型は深さを持っていない。**

丸源氏では次の3つが揃っている（Task 020 の記録）。

- 南北の8本が一度も最上層にならない。
- 面に出る糸が一度に3〜4列にまたがる。
- **実物には長い浮きが1つも無い。**

**向かい側へ動いた糸は表面ではなく厚みの中を通っている**という読みになる。深さが出れば
確かめられる。

## 入力（すべて既存の導出から。手で置く値は無い）

- **各糸の到着点**: 縁位置（`BraidStand` の座標）と、長手座標（積み重ね模型の層番号 × d）。
- **各交差の上下**: 積み重ね模型の置き順（あとから置いた方が上）。**初期配置に埋め込み、
  緩和のあいだは非貫入が保つ。**
- **糸の直径 d。**
- **断面の環**（`BraidCrossSection`）。平源氏は畳みまで含む。

## 模型

各糸を**直径 d の球の連鎖**とする。拘束は**3つだけ**。

1. 隣り合う球の距離
2. 球どうしの非貫入
3. **長手座標の固定**

糸は軸へ向けて一様に引く（張力の代わり）。**引きの大きさは結果に効かないことを確かめる。**

**剛性・摩擦・減衰は導入しない。**

長手座標を固定する理由は Task 016 の結論である（**出来上がりの釣り合いはピッチを決めない**）。
ピッチは積み重ね模型が別に出しているので、**動かすのは断面内の位置だけ**にする。

## 合格条件（前もって書く。**後から緩めない**）

1. **丸源氏**: 緩和後の表面で、各表面点において最も外側にある糸を取り、展開面に置いて
   Task 004 の 8×4 と比べる。**数と交互性。鏡像は一致扱いとし、鏡像で一致した事実は別に記録。
   E/W の列順は未決のまま**（Task 020 の記録どおり。今回の作業で決まったように書かない）。
   **「長い浮きが無い」が結果として出るかを併記。**
2. **平源氏**: bookA p97 の3実験（横糸だけに色 / 矢絣 / はしご）を、緩和後の可視出力で
   再実行。**横糸が縦糸の腹の中を通ることが結果として出るかを併記。**
3. **非貫入が最終状態で満たされていること。**
4. **引きの大きさを変えても 1〜3 の判定が変わらないこと。**

**不合格なら止まる。定数を足して合わせにいかない。拘束を増やさない。**

## やらないこと

- 組み点を解くこと（Task 016 の問い）。これは**すでに決まった上下のもとでの詰め**である。
- 見た目に合わせて定数を置くこと。
- 拘束を増やすこと。3つで足りなければ、足りないことを報告して止まる。
- 既存の生成器（`MaruGenjiSurfaceMeshGenerator` / `HiraGenjiSurfaceMeshGenerator`）に触ること。
