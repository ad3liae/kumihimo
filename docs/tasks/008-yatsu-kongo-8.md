# Task 008: 八つ金剛組8玉の完成シミュレーション

- 状態: Ready（移動規則の独立資料照合が必要）
- 優先度: 高
- 前提: Task 007が完了していること
- 仕様: `docs/specifications/braid-preset-expansion.md`

## 目的

8玉の八つ金剛組を、8本用で最初の内蔵プリセットとして追加する。丸紐断面、位置別配色、2Dサムネイル、端面なし長尺3Dを一貫して生成する。

## 参考出力

参考シミュレータの方式IDは `yatukongo`、断面表示は丸紐である。次の2例をブラックボックス比較に使う。配列は位置1〜8の順。

- 市松: `[#ffffff, #4a649f, #ffffff, #de6473, #ffffff, #4a649f, #ffffff, #de6473]`
- 斜線: `[#52884e, #a5cc6f, #ffffff, #ffffff, #52884e, #a5cc6f, #ffffff, #ffffff]`

色値は比較用フィクスチャであり、商品色カタログへ追加する指定ではない。

## 必須実装

- 安定したプリセットIDと日本語名「八つ金剛組」を追加する。
- 8本の場合だけ結果一覧へ表示する。
- 独立資料で確認した1周期の移動規則を順序付きDomainイベントとして実装する。
- 位置1〜8から丸紐の完成表面周期を生成する。
- 市松と斜線の双方を表現でき、特定の色数や配色へハードコードしない。
- Task 007までに抽出された共通の素材、長尺表示、Viewer操作を利用する。
- 丸源氏の16本用64パッチ表を流用しない。

## 必須テスト

- 8本以外では候補に出ない。
- 1周期後も8本の糸IDに欠落・重複がない。
- 8色識別入力で各位置の表面帰属を固定できる。
- 市松と斜線フィクスチャの空間シグネチャが保存済み期待値と一致する。
- 円周継ぎ目と長手タイル境界が連続し、端面を生成しない。
- 選択、保存、再読込、本数変更時の選択解除が動作する。

## 完了条件

- 8本選択時に八つ金剛組を選択・保存できる。
- 市松と斜線の比較画像で、色面の順序と周期が参考出力に一致する。
- iPhone／iPadで丸紐として回転・拡大縮小できる。
- 未照合事項を試作表示の留保文に反映している。
