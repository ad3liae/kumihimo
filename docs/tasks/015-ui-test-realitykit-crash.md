# Task 015: UIテストが毎回どれか1件だけ落ちる（RealityKit / CoreMedia）

- 状態: 未着手
- 優先度: 中
- 起点: Task 007E 段階5 の報告

## 症状

UIテストを通しで走らせると**毎回1件だけ落ちる。落ちるテストは毎回違う。**
単独で実行するといずれも通る。

クラッシュのスタックは全て RealityKit / CoreMedia の内部で、Kumihimo のフレームが
1つも含まれない。

```
re::TimebaseManager::beforeFrameUpdate → CoreMedia の timebase で null 参照
```

## 判断

**Task 007E の変更による退行ではない。** クラッシュレポートは 2026-09-03・09-04 ぶんも
残っており、段階3以降の変更より前から出ている。

## 調べること

1. クラッシュレポートを集め、いつから出ているかを確定する。
2. 落ちるのが常に「直前のテストで RealityView を破棄した直後の起動」かどうか。
   テスト間でシーンの後始末が終わる前に次が始まっている可能性。
3. テスト間に明示的な待ちを入れて再現率が下がるか。
4. 直るまでのあいだ、CI が赤にならないための扱いを決める（再実行か、隔離か）。

## やらないこと

- 症状を隠すためにテストを削る、あるいは無効化したまま放置すること。
