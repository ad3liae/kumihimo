# Task 007H: 平源氏のリピート継ぎ目で縁の段が乱れる

- 状態: 完了（2026-09-06）
- 優先度: 高（目に見える欠陥であり、出荷済みの表示に出る）
- 起点: Task 007G の既知の副作用（実装側が自己申告）

## 症状

Task 007G で縁に位相を与えた結果、**縁の継ぎ目が4段に1度だけ乱れる。**

位相はリピートの内部に出て両端で戻る。`rowCount = 4` なので、タイルの継ぎ目にあたる1段だけ
段の高さが揃わない。レビュー側でも比較画像で確認した。斜めの継ぎ目が等間隔に並ぶ中に、
**約4段ごとに1か所、形の崩れた継ぎ目が現れる。**

## なぜそうしたか（007G の判断は正しい）

位相をタイルの端の外へ出すと、**次のタイルとのあいだに穴が開く。** 実装側が実際に試し、
段階0の不透明テストが落ちることを確認している。そこで継ぎ目を端で直線に戻した。

**穴を開けるよりは段が乱れるほうが良いという判断であり、これは正しい。** 007G の範囲は
「位相だけ」であり、メッシュ側に手を入れるのは範囲外だった。

## やること

**リピートの継ぎ目をまたぐ升を、メッシュ側で扱えるようにする。**

- 位相を端で戻さず、タイルの継ぎ目をまたいだまま描けるようにする。
- **穴を開けないこと。段階0の不透明テストが通り続けること。** これが最優先である。
- 位相の値そのものは変えない。Task 007G が移動規則から導いた値をそのまま使う。

## 合格条件

1. **縁の段の高さが揃うこと。** 4段に1度の乱れが無くなること。比較画像で示すこと。
2. 段階0の不透明テストが通り続けること。
3. Task 007G の合格条件がすべて通り続けること（縁が面に対してずれる／本体に斜めが出ない／
   矢絣・はしごの対照実験）。
4. **Task 007E で決めた定数が1つも動いていないこと**（3.3359 / 0.3665 / 0.45 / 弧長分割 /
   `faceStitchLean = 0`）。

## 結果（2026-09-06）

### 直し方

**升を描いてから切るのではなく、升のうちタイルに入っている範囲を先に求め、それを分割する。**
切り口が必ず格子線になるので、捨てなければならない切りくずが出ない。**切りくずを捨てることが
穴の正体である。**

- 範囲は**解いて**求める。升の位置は升自身の座標について線形なので、タイル端は升の座標の中で
  直線であり、一次方程式1本で出る。近似すると切り口が端の平面から外れ、
  `interiorBoundaryEdges` が 0 でなくなる（下記の発火確認 (c)）。
- 前後に1リピートずつ余分に回す。模様はリピート周期なので、**端で落ちた材料は反対の端で
  足りない材料そのもの**である。新しい模様データは要らない。
- 升がタイルの外へ完全に出る u では範囲を潰し、**穴にせず角へすぼめる。**
- `HiraGenjiSurfacePattern.boundary` から端の直線化を外した。位相は全ての継ぎ目に効く。

**穴が開かない理由**: 新しくできる切り口はタイルの両端だけで、そこはもともと境界である。
そして**位相は列ごとではなく継ぎ目ごとに持たせてある**（Task 007G）ので、領域が共有する縁では
両側が同じ位相を持ち、同じ位置で切れる。

### 途中で設計を変えた

当初の案（三角形ごとにタイル端で切る）は**必ず切りくずを出し、捨てると穴になった**。実際に
`interiorBoundaryEdges` が出た。上の案に差し替えている。

### 番人が発火することの確認

**3つとも、それが守る欠陥に対して実際に落ちることを確かめた。**

  (a) 端の直線化を戻す（007G の状態）
      → `everyStitchJoinRunsStraightAcrossItsLane` が落ちる
  (b) 前後の余分なリピートを止める（破片を回さない）
      → `consecutiveTilesMeetOnTheSameSurface` と
        `hiraGenjiSurfaceIsEdgeWatertightAwayFromItsTileEnds` が落ちる
  (c) 切り口を解かずに格子へ丸める
      → `hiraGenjiSurfaceIsEdgeWatertightAwayFromItsTileEnds` が落ちる

**`consecutivePatternRepeatsKeepColorAndBoundaryMaterialPhase` は (a)(b)(c) のどれでも
落ちない。** 分け方を直した結果、比べているのが内側の2リピートで、この3つの欠陥はそこを
触らないからである。**これは 007H の番人ではない。** 元の失敗は分け方が誤っていたことによる
偽の失敗であり、それを直した。守っているのは以前と同じ「リピートをまたいで配色と材料の位相が
ずれないこと」である。

### 落ちていた3つのテストの書き直し

いずれも**「タイルの両端は同じ切り方」という、位相を入れた時点で偽になった前提**を書いていた。

1. `repeatedTileGeometryNormalsBoundaryAndTwistPhaseMatch`
   → `consecutiveTilesMeetOnTheSameSurface` に改めた。**「両端が同じ点で標本化されている」は
   本質ではなく、「隣り合うタイルが隙間なく合う」が本質である。** 始端の各頂点に対して終端の
   面上に一致する点があること（両方向）を見る。標本点の一致は要求しない。
2. `consecutivePatternRepeatsKeepColorAndBoundaryMaterialPhase`
   → x の符号ではなく**三角形がどのリピートに属するか**で分ける。リピートは、紐に沿った位置と
   升の中の位置から逆算する（位相のある段はリピート境界をまたぐので、位置だけでは決まらない）。
   4リピートにして**内側の2つ**を比べる。両端のリピートは切られている側なので、切られたものと
   切られていないものを比べることになってしまう。
3. `everyStitchJoinRunsStraightAcrossItsLane`
   → row 0 と rowCount−1 の除外を外した。**その除外は欠陥があったから存在していた。**
   最外列が**全ての段で同じだけ傾く**ことを主張する。

### 配色の割り当ての検査

**矢絣とはしごの対照実験が、回した破片の配色の割り当ての検査になっている。** 破片は
repeat −1 と repeat `repeatCount` から来るので、模様のリピート周期が正しく効いていなければ
縁と本体の色が入れ替わる。矢絣は「本体が無彩色・縁だけに矢絣」、はしごは「奥と手前で色が
逆になるはしご」を要求するので、破片の色が1リピートずれれば両方とも落ちる。どちらも通る。

### 三角形と頂点

  平源氏 頂点 359424 → 366552（+1.98%）、三角形 119808 → 122184（+1.98%）

前後に1リピートずつ余分に回し、ほとんどを捨てるぶんである。`MaruGenjiViewportCoverage` は
タイル長で枚数を数えるので**枚数は不変**、1枚あたりが 2% 増える。`defaultPatternRepeatCount`
を 6 → 4 にする件（Task 007E からの積み残し）の材料になる。
