## なぜ今これをやるか

Task 005E〜005I（丸源氏）と Task 007E/007F（平源氏）で、**1つの組み方を実物へ合わせるのに
10段階前後かかる**ことが分かった。資料写真を測り、定数を導き、対照実験で裏を取る。この
密度でやったからこそ信用できるものになったが、**Task 008〜014 の7本に同じことを繰り返すのは
現実的ではない。**

一方、この2つのタスクは副産物として**判定の道具**を残した。

- 正規化した並置による目視の計数（Task 005I）
- シルエットのさざ波（周期が1手と一致するかの確認つき）と較正式 σ(%) = 9.55 × 頂
- 単色の行に沿った輝度変調
- 配色だけを変えて構造を検証する対照実験（3件、いずれも合格）

**「物理で解いた結果が正しいか」を判定する装置がすでにある。** 判定できる状態で作れるので、
いまが検討の時期である。

## 決定的に効く前提

**組み上がりの形は配色に依存しない。** 色は解いたあとのメッシュへ塗るだけである。したがって
シミュレーションは**組み方ごとに一度**解けばよく、実時間で走る必要がない。事前計算して
結果を焼き込めばよい。この前提が成り立つ限り、要求される性能は問題にならない。

**この前提が崩れる材料があれば、その時点で報告すること。**

## 入力と出力

**入力は物理量と組み方だけとする。**

- 糸の太さ（1種類。太さの違う糸は扱わない）
- 糸の曲げにくさ、糸どうしの接触
- 張力（玉の重さ、吊り重り）
- 移動規則（すでに3資料で照合済み。`HiraGenjiWeaveDerivation` ほか）
- 台の形（丸台。16本なら4面×4本）

**出力は形だけとする。** 断面の輪郭、1手あたりの送り、糸の通り道、表面の起伏。

**現在コードにある形の定数は、1つも入力にしないこと。** それらは出力として再現できるかを
測る対象である。入力に混ぜたら調査が無意味になる。

## この調査が解くべき絡まり（Task 005J 段階2b、2026-09-06 追加）

**畝の高さと模様の縦横比は、実物写真からは分離できない。** 写真から測れるのは
「見かけの山形密度」という両者の組み合わせ1つだけで、片方を動かせばもう片方も動かさないと
写真に合わなくなる。丸源氏では次のとおり。

紐幅 = 畝の稜線での外径（2 × 半径 × (1 − 谷の深さ + 頂)）で測った値。写真が測っているのは
紐の外形の幅なのでこれを採る。**基準を書かない密度の数字は使わないこと**
（`docs/architecture.md`「紐幅の取り方」）。

  頂 0.12（現状）・aspect 0.65   見かけの密度 2.14   写真の帯（1.8〜2.15）の上端ぎりぎり
  頂 0.24・aspect 0.65           見かけの密度 2.37   帯の外
  頂 0.353・aspect 0.65          見かけの密度 2.59   帯の外。戻すには aspect 0.75 付近が要る

0.12 が帯の内か外かは決められない。上端との差が 0.5% しかなく、紐幅の取り方を1つずらせば
外へ出る。**言えるのは「0.24 と 0.353 は明確に外で、0.12 だけが桁違いに近い」ことである**
（上端からの距離は 0.5% / 10% / 20%）。

0.353 は平源氏で決めた 0.45 糸幅ぶんを半径比へ直した値である。**物理はこれを指し、写真は
反対を指す。** 手で合わせ込む道では、この2つを独立に決める材料が無い。

**物理から解けば両方が独立に出るので、この絡まりは自然に解ける。よってこれを解けるかどうかが、
この調査が成立するかの判断材料の1つである。** 段階2（丸源氏を1つ解く）で、`crestHeightRatio`
と `patternAspectRatio` に相当する2つの量が**それぞれ独立に**出てくるか、そして両方を入れた
ときの見かけの密度が写真の 1.8〜2.15 に入るかを見ること。

なお **016 の結論が出るまで、丸源氏の `crestHeightRatio` と `patternAspectRatio` の
どちらも動かさない**（`docs/architecture.md`「畝の高さと模様の縦横比は、実物写真からは
分離できない」）。

##### 糸を何として表すか

候補を3つ検討した。

**A. 球の鎖（採用）** — 半径 r = d/2 の球を r 以下の間隔で並べた鎖。伸び・曲げ・接触を
位置ベースの拘束（XPBD）で解く。

**B. 離散弾性ロッド（DER）** — 中心線＋断面フレーム。曲げと**捻り**を正しく扱う。

**C. ばね質点** — 節点をばねで結び、曲げは角度ばね。

**A を採る理由**:

1. **貫通を許さないことが要件である。** A と B は接触を**不等式拘束**として位置で解けるので、
   重なりを毎反復で押し出せる。C は罰則力なので、張力が高いほど食い込みが残る。**第1版の
   平源氏が面に穴を開けたのと同じ失敗を、物理の側で繰り返すことになる。**
2. **糸の太さが表現に直接入る。** 球の半径がそのまま糸の太さで、入力が1つの長さだけという
   要件と形が合う。B は断面を別に持つので、接触の半径と曲げの断面が食い違いうる。
3. **捻りは要らない。** 糸自身の撚りの縞は現在も法線マップであって形ではなく、段階2・3 で
   測る量（山形の密度・断面比・1手のピッチ・畝の高さ）はどれも捻りに依らない。B の主な
   利点を使わない。
4. 球の鎖は糸レベルの布・編みの標準的な扱いで、収束の癖が知られている。

**A の弱点を先に書いておく。** 球の鎖は断面が円のままで、**押されて潰れない。** 実物の糸は
交差で扁平になる。これが効くと、断面比（平源氏 3.34）が丸く出る方向に外れる。**外れた場合、
断面の潰れを入れるのが次の一手であって、定数で補正しないこと。**

##### 接触をどう扱うか

- 球の間隔を r 以下にして鎖を隙間なく覆う。**他の糸が通り抜ける隙間を作らない。**
- 広域探索は一様格子（セル 2r）。
- 非貫通は不等式拘束 |xi − xj| ≥ 2r。同じ糸の隣接球は除く。**毎反復で射影する。**
- 摩擦はクーロン則で接触の接線方向に。**これは飾りではない。** 摩擦が無いと締まりが解けて
  1手あたりの送りが伸び、ピッチが出ない。
- 鏡（中央に穴の開いた平面）とも接触させる。

##### 静的な釣り合いか、動かして落ち着かせるか

**準静的。動かして落ち着かせるが、慣性は答えに入れない。**

組み上がりの形は**履歴で決まる**。どの糸がどの糸の上を通ったかは移動の順序の結果であり、
静的な釣り合いを直接解こうとすると、**その上下関係をすでに持った初期配置**が要る。それは
まさに導きたいものなので、循環する。接触が非平滑で Newton 的な静解法の条件が悪いことも
ある。

そこで**組む過程をそのまま回す**。

  1手 = [移動規則どおりに糸を面から面へ運ぶ] → [残留運動が閾値を下回るまで緩和] → [送り]

緩和は減衰の強い XPBD の反復で行う。**慣性が答えに入っていないことは確認して示す**:
移動の速さを半分にして同じ答えが出ること（速度非依存）。出なければ準静的になっていない。

##### 1つの組み方を解く見込み

  活性な球  1本あたり 60〜120 個（鏡の縁から凍結線まで）× 16本 ＝ 1500〜2000 個
  1手あたり 数千サブステップ × 20 反復程度
  必要な手数 助走を含めて 30 手ほど（ピッチと断面を測るには十数手の完成部が要る）

コンパイル言語で **1つの組み方あたり数分**。掃引（EI と μ で 3×3）を含めて**1時間以内**。
事前計算なので問題にならない。**律速は速度ではなく、高い張力下で緩和が跳ねずに収束するか
である。** そこに時間を積む。

##### この調査の本丸: 畝の高さと模様の縦横比の絡まり

写真から測れるのは**見かけの山形密度**という両者の積ひとつだけで、分離できない
（`docs/architecture.md`）。物理から解けば、この2つは**別々の機構の出力**になる。

  模様の縦横比  ← **1手あたりに紐が伸びる量**（張力と詰まりの帰結。送りの問題）
  畝の高さ      ← **糸が平均面からどれだけ出るか**（断面と詰まりの帰結。表面の問題）

**同じ数へ2つのつまみを当てはめるのではなく、1回の求解が2つの別の量を返す。** これが
成立すれば絡まりは解ける。

**ただし、畝の高さが自明に出るだけの危険がある。** 球の鎖では、糸が平均面から出る量が
ほぼ半径 r そのものになりうる。それは「解いた」のではなく表現の言い換えである。

**先に判定基準を書いておく。**

  張力（吊りおもり 570g と 760g）を変えて畝の高さが**動けば**、詰まりから出た量である。
  張力を変えても r 比で一定なら、**自明であって解けていない。** そう報告すること。

同じ理由で、畝は**写真と同じ手順で測る**こと（シルエットから）。メッシュの頂点から
直接読むと、表現の半径をそのまま読み返すことになる。
