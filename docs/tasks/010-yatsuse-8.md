# Task 010: 八つ瀬組8玉の完成シミュレーション

- 状態: Ready（移動規則の独立資料照合が必要）
- 優先度: 高
- 前提: Task 009が完了していること
- 仕様: `docs/specifications/braid-preset-expansion.md`

## 目的

8玉の八つ瀬組を追加し、平紐断面と、平紐・斜め〆の配色傾向を2D／3Dへ反映する。

## 参考出力

参考方式IDは `yatuse`、断面表示は平紐である。配列は位置1〜8の順。

- 平紐: `[#86cdd3, #6696d4, #ffffff, #ffffff, #86cdd3, #6696d4, #ffffff, #ffffff]`
- 斜め〆: `[#f7d08d, #875d5e, #875d5e, #875d5e, #ffabcd, #875d5e, #875d5e, #875d5e]`

## 必須実装

- 安定した八つ瀬組IDを追加し、8本用結果一覧へ表示する。
- 独立資料で確認した移動規則をDomainイベントとして実装する。
- 平源氏で導入した平紐メッシュ基盤を利用しつつ、八つ瀬固有の幅／厚さ比と表面周期を持つ。
- 表、裏、左右縁の対応を明示し、丸紐メッシュの押し潰しで代用しない。
- 2つの参考配色を同じ汎用表面生成器で再現する。

## 必須テスト

- 8本以外では候補に出ない。
- 1周期後に糸IDの欠落・重複がない。
- 表、裏、左右縁の区画が存在する。
- 平紐と斜め〆の空間シグネチャが期待値と一致する。
- 幅／厚さ比、角の法線、長尺タイル境界、端面なしを検証する。
- 平源氏と同じ入力を与えても、八つ瀬固有の周期になる。

## 完了条件

- 八つ瀬組を8本用の平紐プリセットとして選択・保存できる。
- 参考2例と色面の順序、表裏、縁を比較できる。
- 既存の丸紐・平紐プリセットに回帰がない。
