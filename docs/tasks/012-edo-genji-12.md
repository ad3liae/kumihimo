# Task 012: 江戸源氏組12玉の完成シミュレーション

- 状態: Ready（移動規則の独立資料照合が必要）
- 優先度: 高
- 前提: Task 011が完了していること
- 仕様: `docs/specifications/braid-preset-expansion.md`

## 目的

12玉の江戸源氏組を、最初の角紐系プリセットとして追加する。4つの主要面を区別した完成表面と端面なし長尺3Dを提供する。

## 参考出力

参考方式IDは `edogenji`、出力は角紐用の視点切替を使用する。ハート模様の位置1〜12は次のとおり。

`[#cceeff, #cceeff, #445566, #445566, #445566, #445566, #eeccaa, #eeccaa, #445566, #445566, #445566, #445566]`

## 必須実装

- 安定した江戸源氏組IDを追加し、12本用結果一覧へ表示する。
- 独立資料で確認した移動規則を順序付きDomainイベントとして実装する。
- 角を適度に丸めた4面の断面プロファイルを新設する。
- 各主要面と角部へ、位置1〜12に由来する表面パッチを割り当てる。
- ハート模様を特別な画像として貼らず、位置別色から生成する。
- 丸紐・平紐とViewer操作、素材、長尺カバレッジを共有する。

## 必須テスト

- 12本以外では候補に出ない。
- 1周期後も12本の糸IDを保存する。
- 4つの主要面と丸めた角部が存在し、法線が連続する。
- ハート模様フィクスチャの各面の空間シグネチャが期待値と一致する。
- 回転して全主要面を観察でき、端面は見えない。
- 選択、保存、再読込、本数変更時の解除を検証する。

## 完了条件

- 江戸源氏組を12本用の独立プリセットとして選択・保存できる。
- ハート模様を4面の長尺角紐として比較表示できる。
- 既存の8本・16本プリセットに回帰がない。
