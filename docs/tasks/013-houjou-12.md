# Task 013: 方丈組12玉の完成シミュレーション

- 状態: Ready（移動規則の独立資料照合が必要）
- 優先度: 高
- 前提: Task 012が完了していること
- 仕様: `docs/specifications/braid-preset-expansion.md`

## 目的

12玉の標準方丈組を角紐プリセットとして追加し、12位置すべてを識別できるチェック柄フィクスチャで表面対応を固定する。

## 参考出力

参考方式IDは `houjou`、断面表示は角紐である。チェック柄フィクスチャは位置1〜12へ次の異なる色を割り当てる。

`[#ff7755, #ffeedd, #bbbbff, #112266, #ee0000, #bbdd99, #ffbb66, #11ddee, #337733, #ccffee, #88bb44, #3388ee]`

この12色例は、各位置の表面帰属を識別する主要フィクスチャとする。

## 必須実装

- 安定した標準方丈組IDを追加し、12本用結果一覧へ表示する。
- 江戸源氏組とは別の移動規則と表面対応表を持つ。
- 独立資料で確認した1周期を順序付きイベントとして実装する。
- 12色フィクスチャから4面と角部の位置対応を検証可能にする。
- 江戸源氏組の角紐メッシュとViewerは再利用し、方丈固有の表面周期を個別化する。

## 必須テスト

- 12本以外では候補に出ない。
- 1周期・複数周期で糸IDが欠落・重複しない。
- 12色すべてが期待する面と周期位置へ現れる。
- 位置1〜12のうち1色だけを変更するパラメータ化テストを行う。
- 江戸源氏組と同一入力を与えても方丈固有の結果になる。
- 4面、角部、タイル継ぎ目、端面なし、保存往復を検証する。

## 完了条件

- 標準方丈組を12本用の独立プリセットとして選択・保存できる。
- 12色チェック柄の位置対応が自動テストと目視比較で固定されている。
- 江戸源氏組および既存プリセットに回帰がない。
