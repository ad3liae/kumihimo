## 段階1: 4本の台と、丸四つ組の手順表

### 台

`BraidStands.round4` を足す。`round(id:positionCount:groups:)` をそのまま使い、
**群は16本・8本と同じ数え方**（外側から、北・東・南・西）で1位置ずつ:

    north: [1], east: [2], south: [3], west: [4]

`BraidMethodCatalog.stands` に加える。`stand(for:)` は休む位置の数で選ぶので、**分岐は増えない。**

### 休むノッチ

32ノッチのディスクに4本は8ノッチおき。**bookA は丸台の本でディスクの図を持たないので、この番号づけは
この repo のもの**（`diskRestingNotchesForEight` と同じ事情。doc comment にそう書くこと）:

    diskRestingNotchesForFour = [1: 1, 9: 2, 17: 3, 25: 4]

位置の番号とノッチが同じ向きに回るように選んである。

### 手順表（bookA p.56）

本が刷るのは2手と「1〜2をくり返す」である:

| 刷られた手 | 本の言葉 | 動く糸 |
| --- | --- | --- |
| 1 | 右手R が上の糸、左手L が下の糸 | **縦の対を入れ替える**（北↔南） |
| 2 | 右R が左の糸を右へ、左L が右の糸を左へ | **横の対を入れ替える**（西↔東） |

**ディスクの記法へ写したもの**（審査側が先に回して1サイクルになることを確かめた。
`BraidDiskNotation.method(...)` と同じ手順を紙の上で回している）:

    maruYotsuDisk の moves:
      (1, 18), (17, 2), (18, 17), (2, 1),      // 刷られた手1: 縦
      (9, 26), (25, 10), (26, 25), (10, 9),    // 刷られた手2: 横

長い手（15ノッチ）が組みの手、1ノッチの手が着地の詰めで、`isRepositioning` が距離だけで
見分ける。**検算の結果**: 運ばれた糸は 1・3・2・4 の順、終わりの休み場所は
**1→3、3→1、2→4、4→2**、`closing` は空。**`threadsPerStep` は 2、`stepNames` は 2 つ。**

- **`stepReading` は `.oneStepAnInstant`。** bookA は1手に右手と左手の2本を刷り、**どちらが先かを
  書いていない**（`docs/architecture.md` の bookA p94–95 と同じ事情）。bookC に丸四つ組の図は無い。
  八つ金剛が `diskOfEight` で採ったのと同じ読みにする。
- **ただし八つ金剛と違い、この紐では対の2本が互いの場所へ行く。** 八つ金剛では Task 031 のテスト6が
  「先後を入れ替えても立体が1頂点も動かない」ことを示したが、**それはその紐に交差が無かったからである。**
  **丸四つ組では対が交差するので、先後が形に届く可能性が高い。**
  → **段階1 の報告に、先後を入れ替えた表との差（占有履歴・断面・メッシュ）を数で付けること。**
  届くなら `unsettled` に「対の中の先後は bookA から読めない」と書いて残す（八つ金剛と同じ扱い）。

### 検算（025-5 の1）

- `BraidRecipe.worked(on: round4)` が `nil` を返さないこと。返したら**表がこの台の1サイクルに
  なっていない。**
- **1サイクルで全糸が2場所進むこと**（位置1→3、2→4、3→1、4→2）。
  **これは八つ金剛と同じ構造である**（8本で2場所）——半分の本数で同じ2場所なので、
  **丸四つ組のほうが速く回る。** 螺旋はここから出る。
- **紐のまわりの並び順は台の縁の順そのまま**（管なので何も宣言しない。025-5 の4）。

## 段階3: 4本の描き手

**作者の判定（2026-09-22）: 4本専用の描き手を新しく作る。** 既存の筒8本の描き手を広げない。

- 族は `.roundTube(threads: 4)`。`BraidFamilyDrawing.Drawing` に case を足し、`families` に
  `RoundTube4SurfaceMesh.shape` を足す。**族の読み方そのもの（`BraidFamily.family(of:)`）は
  触らない。**
- **`RoundTube8SurfaceMesh` と `RoundTube8SurfacePattern` を先に読むこと。** 構造は同じ
  （1サイクルに2場所進む筒、対が半ピッチで交替する）ので、**作りは真似てよいが共通化はしない**
  ——族ごとに描き手を持つのが今の作りで、形の値は族のものである。
- 組み目は **Task 051・053 で受領したもの**（頭は鈍く上に載り、尾は幅を保って隣の列へ曲がり、
  後に置かれた束の下へ潜る。束の傾きは運ぶ向きの符号から取らない）を 4本へ持ち込む。
  **051・053 で直した誤りを作り直さないこと。**
- 一覧カードの展開図・詳細の立体・模様図が 4本で出ること。**模様図（2D）は族に関わらず出るので、
  段階2 の時点で出ているはず**——出ていなければ段階2 に穴がある。

### 予言

- 4本は8本の倍の速さで回るので、**展開図の斜めは8本より急**になる。
- 束は**縦の対と横の対が半サイクルずれて交替する**（八つ金剛の半ピッチと同じ構造）。
- 写真（bookA p.10 の b）との差は残る。**寄せ切らなくてよい。差を測って報告すること**
  （測り方は `docs/measurement-procedures.md`。新しい測り方を作る前に読む）。
