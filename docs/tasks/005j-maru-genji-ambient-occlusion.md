# Task 005J: 丸源氏の遮蔽マップを ambientOcclusion スロットへも与える

- 状態: 段階1 完了（遮蔽マップ）／段階2 完了・頂は変えず（資料が周期を持たない）
- 優先度: 低（Task 007E の完了後に判断する）
- 起点: Task 007E 段階4a

## 背景

Task 007E 段階4a で、平源氏の遮蔽マップを `baseColor` への色付けだけでなく
`ambientOcclusion` スロットへも与えたところ、長手方向の輝度変調が **0.463 → 0.618** に
上がった。定数は1つも変えていない。資料の完成写真は 0.670〜0.884 である。

**丸源氏は `baseColor` のみで、同じ手順で測ると 0.605 である。** 資料より浅い可能性が高い。

詳細は `docs/architecture.md`「遮蔽マップをマテリアルのどのスロットへ与えるか」。

## やること

1. 丸源氏の完成写真（`.build/task005i-references/` ほか）から、Task 007E 段階4a と**同じ手順**で
   輝度変調を測る。単色の行を選び、長手方向の `(p95 − p5) / p95` の中央値。
2. 現在の丸源氏のレンダーを同じ手順で測る（参考値 0.605）。
3. 資料より明らかに浅い場合にかぎり、遮蔽マップを `ambientOcclusion` スロットへも与える。
   **定数は変えないこと。**
4. 正規化した並置の比較画像を出す。

### 段階2 に入る前の予測（測る前に書く）

**残りの差は畝の高さの側にあると予測する。** 遮蔽マップの与え方は段階1で平源氏と揃った。
定数を触らずに残っている未照合の量が畝の高さだけであり、平源氏では資料がモデルの
3.4〜4.3倍深かった。丸源氏の 0.12 も同じ由来なので、上げれば変調も上がり、下限 0.738 との
差が縮むはずである。

**測ってから照合する。閉じなければ、それ自体が情報である**（谷の陰の深さが畝の高さでは
説明できない、ということになる）。あとから理由を作らないためにここへ書いておく。

## やらないこと

- 遮蔽の定数（`valleyOcclusion`、`crossingOcclusion` など）を変えること。
- 幾何・移動規則・配色に触れること。
- 資料の数値へ ±15% で合わせにいくこと。資料の変調には糸の繊維のざらつきとカメラの
  周辺減光が混じっている。**下限と目視で判断する**（Task 005H の失敗を繰り返さない）。

## 併せて確認すること: 畝の高さ

`MaruGenjiSurfaceMeshGenerator.crestHeightRatio = 0.12` も**実物のシルエットと照合されて
いない**。Task 007E 段階5 で平源氏を bookA p96 の完成写真と照合したところ、**資料は
モデルの 3.4〜4.3倍深かった**。丸源氏の 0.12 も同じ由来なので、同じく浅い可能性が高い。

手順は Task 007E 段階5 と同じ。白い背景の上にある完成写真の上辺のシルエットを列ごとに取り、
1手のピッチ2つぶんの移動平均で高域を取り出し、σ と p95 − p5 を1手のピッチ比で出す。

**残差の自己相関でさざ波の周期を求め、1手のピッチと一致することを必ず確認すること。**
一致しない資料は使わない。糸のけばを測っているだけであり、これを飛ばすと物理的にありえない
値（糸が自分の直径より高く盛り上がる）を資料から読んでしまう。Task 007E 段階5 では
bookB p23 がこれで失格になった。

**較正は自分で取り直すこと。** 平源氏では σ(%) = 9.55 × 頂 だったが、これは平源氏の断面と
1手のピッチに依る。丸源氏では現在の 0.12 を含む3つの頂でレンダーして直線を引き直す。

### 段階2 の結果（2026-09-06）: 測れなかった。頂は変えていない

**較正は取れた。丸源氏は平源氏と別の式である。**

単色フィクスチャを頂 0.00〜0.48 の8点でレンダーして測った。

  頂    0.00  0.06  0.12  0.18  0.24  0.30  0.36  0.48
  σ(%)  0.02  2.11  3.49  4.74  5.95  6.93  8.08 10.03

  **σ(%) = 17.31 × 頂^0.752**（残差 0.044）

平源氏の σ = 9.55 × 頂 は**直線**だったが、丸源氏は**直線ではない**。丸い紐のシルエットは
接線の包絡なので、畝が高くなるほど隣の畝の谷が隠れて飽和する。**引き写していたら大きく
外していた。** 頂 0 で σ = 0.02% なので、測定の床は無く、この曲がりは実体である。

  レンダーの端の波形の周期は 62px（1手の山形 141px の 4/9）で、頂によらず一定。
  自己相関 r = 0.96〜0.98。

**資料はどれも周期を持たない。1枚も使えない。**

15px 以上のラグでの自己相関の最大（レンダーは 0.98）:

  bookA p94（白い紙・背景は最良）  σ 1.72% / 1.98%   r = 0.41 / 0.24 → 周期なし
  bookB p23 #24b（コンクリート）    σ 5.10%           r = 0.24        → 周期なし
  作者の真上からの写真（木目）      σ 4.66%           r = 0.12        → 周期なし
  bookB p23 #24a                    測定できない。端の糸が目ごとに紺と白へ替わるため、
                                    形と無関係に測定点が動く（平源氏で単色フィクスチャを
                                    作った理由と同じ）。

### 結論: この測り方が丸い紐に使えない（「良い写真が無かった」ではない）

根拠が3つ揃った。

1. **実物の外周が滑らかで、畝の列に見えない。** 4枚とも、拡大しても縁は1本の滑らかな紐で
   ある。**丸源氏には糸が折り返す縁が無く、糸は斜めにシルエットを横切るだけなので、
   滑らかなのが正しい可能性が高い。**
2. **シルエットの特徴が目と1対1に対応しない。** レンダーの端の波形の周期は1手ではなく
   1手の 4/9。平源氏では1手そのものだった。何を数えているのかが組ごとに変わる。
3. **較正が飽和する。** 接線の包絡なので、畝が高くなるほど隣の畝の谷が隠れる。頂を2倍に
   しても σ は2倍にならない。逆に読むとき、上の方ほど分解能が落ちる。

**平源氏のシルエット法は、縁で糸が折り返す平たい紐だから成立した道具である。**
Task 008 以降の丸い組み方でこの手順を繰り返さないよう、`docs/measurement-procedures.md`
「適用範囲: 丸い紐には使えない」と `docs/architecture.md` に記録した。

**周期の確認を飛ばしていたら、いまの値を追認していた。**

  上の σ を較正へ通すと 頂 0.045 / 0.056 / 0.193 / 0.171 が返る。**現在の 0.12 は
  この範囲のまん中に落ちる。** つまり資料は「0.12 で合っている」と答える。測っているのは
  糸のけばと紙・木目のざらつきである。007E の「周期を必ず確認する」はこのために要る。

**よって頂は変えていない。0.12 は追認されても否定されてもいない。**

#### 頂を上げると Task 005I の受け入れが動く

005I の受け入れは「山形/幅 が実物の 1.8 に対して ±15%、すなわち 1.5〜2.1」
（実物のもう一つの読みは 2.15）。

幾何には触れていないが、**畝を上げると紐が太くなるぶん、見かけの山形密度は下がる。**

  頂 0.12 → 1.87（帯の中）
  頂 0.24 → 2.06（帯の中、上寄り）
  頂 0.35 → 2.21 / 2.30（**帯の上端を超える**）

`theChevronDensityFollowsTheDeclaredAspectAtAnySize` は `mesh.baseRadius`（公称半径）で
計算しているため、頂を変えても値が動かず**この動きを捉えない。** 頂を上げるなら、005I の
受け入れを見かけの紐幅で測り直すか、外側の寸法を含めた不変量へ置き換える必要がある。

### 平源氏の結果（2026-09-05、Task 007E 段階5b）

`HiraGenjiSurfaceMeshGenerator.crestHeightRatio` を **0.12 → 0.45** にした。資料の1枚から
0.41〜0.55、物理（面に置かれた糸は自分の直径の半分ほど盛り上がる）から 0.40〜0.50、
重なりは 0.41〜0.50 で、その中央を採った。

**丸源氏の 0.12 は平源氏から引き写して決めてよい数ではない。** 平源氏の値は糸1本の幅に
対する割合、丸源氏の値は半径に対する割合で、単位が違う。`docs/architecture.md`
「2つの組の畝の高さは揃っていない」に経緯がある。**このタスクで測るまで揃えないこと。**

## 併せて確認すること: 完成した紐の外側の縦横比

頂を動かすと、完成した紐の外側の寸法が必ず動く。平源氏では頂 0.45 で外側の比が
`3.336 → 2.59` になった。**平均面の比には根拠があるが、外側の比が実物と合うかは
どちらの組についても測っていない。** 頂を決め直すこのタスクで、両方の組について
実物の側面写真（`.build/task005h-references/hiragenji-edge-view.png` ほか）と照合すること。

## 受け入れ

- 変調がレンダー・資料の両方について報告されていること。

- 変更した場合、丸源氏の既存の受け入れ（Task 005I の山形の密度）が崩れていないこと。
