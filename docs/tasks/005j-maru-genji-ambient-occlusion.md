# Task 005J: 丸源氏の遮蔽マップを ambientOcclusion スロットへも与える

- 状態: 未着手
- 優先度: 低（Task 007E の完了後に判断する）
- 起点: Task 007E 段階4a

## 背景

Task 007E 段階4a で、平源氏の遮蔽マップを `baseColor` への色付けだけでなく
`ambientOcclusion` スロットへも与えたところ、長手方向の輝度変調が **0.463 → 0.618** に
上がった。定数は1つも変えていない。資料の完成写真は 0.670〜0.884 である。

**丸源氏は `baseColor` のみで、同じ手順で測ると 0.605 である。** 資料より浅い可能性が高い。

詳細は `docs/architecture.md`「遮蔽マップをマテリアルのどのスロットへ与えるか」。

## やること

1. 丸源氏の完成写真（`.build/task005i-references/` ほか）から、Task 007E 段階4a と**同じ手順**で
   輝度変調を測る。単色の行を選び、長手方向の `(p95 − p5) / p95` の中央値。
2. 現在の丸源氏のレンダーを同じ手順で測る（参考値 0.605）。
3. 資料より明らかに浅い場合にかぎり、遮蔽マップを `ambientOcclusion` スロットへも与える。
   **定数は変えないこと。**
4. 正規化した並置の比較画像を出す。

## やらないこと

- 遮蔽の定数（`valleyOcclusion`、`crossingOcclusion` など）を変えること。
- 幾何・移動規則・配色に触れること。
- 資料の数値へ ±15% で合わせにいくこと。資料の変調には糸の繊維のざらつきとカメラの
  周辺減光が混じっている。**下限と目視で判断する**（Task 005H の失敗を繰り返さない）。

## 併せて確認すること: 畝の高さ

`MaruGenjiSurfaceMeshGenerator.crestHeightRatio = 0.12` も**実物のシルエットと照合されて
いない**。Task 007E 段階5 で平源氏を bookA p96 の完成写真と照合したところ、**資料は
モデルの 3.4〜4.3倍深かった**。丸源氏の 0.12 も同じ由来なので、同じく浅い可能性が高い。

手順は Task 007E 段階5 と同じ。白い背景の上にある完成写真の上辺のシルエットを列ごとに取り、
1手のピッチ2つぶんの移動平均で高域を取り出し、σ と p95 − p5 を1手のピッチ比で出す。

**残差の自己相関でさざ波の周期を求め、1手のピッチと一致することを必ず確認すること。**
一致しない資料は使わない。糸のけばを測っているだけであり、これを飛ばすと物理的にありえない
値（糸が自分の直径より高く盛り上がる）を資料から読んでしまう。Task 007E 段階5 では
bookB p23 がこれで失格になった。

**較正は自分で取り直すこと。** 平源氏では σ(%) = 9.55 × 頂 だったが、これは平源氏の断面と
1手のピッチに依る。丸源氏では現在の 0.12 を含む3つの頂でレンダーして直線を引き直す。

### 平源氏の結果（2026-09-05、Task 007E 段階5b）

`HiraGenjiSurfaceMeshGenerator.crestHeightRatio` を **0.12 → 0.45** にした。資料の1枚から
0.41〜0.55、物理（面に置かれた糸は自分の直径の半分ほど盛り上がる）から 0.40〜0.50、
重なりは 0.41〜0.50 で、その中央を採った。

**丸源氏の 0.12 は平源氏から引き写して決めてよい数ではない。** 平源氏の値は糸1本の幅に
対する割合、丸源氏の値は半径に対する割合で、単位が違う。`docs/architecture.md`
「2つの組の畝の高さは揃っていない」に経緯がある。**このタスクで測るまで揃えないこと。**

## 併せて確認すること: 完成した紐の外側の縦横比

頂を動かすと、完成した紐の外側の寸法が必ず動く。平源氏では頂 0.45 で外側の比が
`3.336 → 2.59` になった。**平均面の比には根拠があるが、外側の比が実物と合うかは
どちらの組についても測っていない。** 頂を決め直すこのタスクで、両方の組について
実物の側面写真（`.build/task005h-references/hiragenji-edge-view.png` ほか）と照合すること。

## 受け入れ

- 変調がレンダー・資料の両方について報告されていること。
- 畝の高さについても、さざ波の周期が1手と一致することを示したうえで報告されていること。
- 変更した場合、丸源氏の既存の受け入れ（Task 005I の山形の密度）が崩れていないこと。
