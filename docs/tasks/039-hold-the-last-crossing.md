## 1. 模型（**これが定義。読みを変えたら別の模型である**）

単位は d。台は `Scripts/task022/stand.py`（鏡・穴・丸め・32 の角度）。

### 糸

- **直径 d のカプセルの鎖。伸びない。質量無し。** 022 と同じ。
- 一本の糸は二つの区間から成る。**固定部**（乗られた球から手前。動かない）と**自由部**（最後に乗られた球から
  縁側の端まで。動く）。**落ち着き区間は無い。**
- **縁側の端は、穴の縁の点**（半径 `stand.hole + stand.fillet`、その糸の縁の角度、z = +0.5 d）**に固定**。
  その先は鏡の上に寝ていて紐に効かないので置かない（036・037 と同じ。022 は縁まで置いていた）。
  余れば端から出て行き、足りなければ端から入る（036 の縁の出入り）。

### 力

**無い。** 自由部は両端（最後に乗られた球と、穴の縁の点）のあいだの最短の道（022 の `shrink`）。

### 拘束（**二つ＋台**。022 と同じ）

1. 隣り合う球の距離が d。
2. 太さ d のカプセルどうしが通り抜けない（`Scripts/task021/given_length.py`）。**押し離しは両側に振り分ける。
   固定部の球は `held`。**
3. 鏡は静的な障害物（`stand.push_out`）。

### 固定の規則（**ここが 022 と違う。これだけ**）

**球 b（糸 X）は、別の糸 Y の球 c が b の上に置かれていれば「乗られた」**——c は b より後の手で運ばれ、
|c − b| ≤ 接触の閾値（解法の設定、既定 1.05 d）、c_z > b_z、**水平距離 < d**（022 の `note_crossings`・021 の `under` と
同じ「上に置かれた」の判定。横に並んで触れているだけの球は乗られていない。**2026-09-15 の判定 5**）。
**糸 X の固定端は、X の固定端から自由部を辿って、「乗られていて、かつ固定部の球に触れている」最も遠い球まで進む。**
固定部の球はどの糸のものでもよく（X 自身の固定端を含む）、触れているとは接触の閾値以内。**その手の 3. に入る前の固定部で
判定する**（この手で固めた球を支えに数えない）。そのあいだの球は全部固める（乗られた球より手前は、乗られた球に押さえられて
動けない）。**乗られていても固定部に触れていない球は固めない**——穴の中の空中で別の自由部に乗られた交差は、埋められていない
交差であり、次の張りで滑る（作者の決定「置かれた交差が次の層に埋められて動けなくなる」。**2026-09-15 の判定 6**。
数は記録する）。**固定は取り消さない**（乗った糸が後で動いても）。

**閉じ移動で運ばれた糸も同じ扱い**（乗れば固め、乗られれば固まる）。

### 種

結び目の 16 球（1 辺 d の正 16 角形、半径 2.5629 d、組み点 −1.658 d）が最初の固定部。**並びは断面の環順**（037 の判定 2、
`architecture.md`「台の座標と紐の座標は別である」——束の入口は紐の断面の環順に等間隔。回る向きと位置 1 の角度は
`stand.bundle_angle` のもの。丸源氏は縁の順と同じ、平源氏は違う。**「022 と同じ」と書いたのは審査側の書き誤り。2026-09-15**）。
各糸の自由部は結び目から穴の縁の点へ（022 と同じ直線。種の弧は 0 が主）。
**組めなければ、別の種に黙って切り替えず、様子を報告して止まる。**
