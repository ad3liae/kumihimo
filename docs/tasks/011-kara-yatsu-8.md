# Task 011: 唐八つ組8玉の完成シミュレーション

- 状態: Ready（移動規則の独立資料照合が必要）
- 優先度: 高
- 前提: Task 010が完了していること
- 仕様: `docs/specifications/braid-preset-expansion.md`

## 目的

8玉の唐八つ組を独立した平紐プリセットとして追加し、波縞、M/W字、ハート模様を位置別配色から生成する。

## 参考出力

参考方式IDは `karayatu`、断面表示は平紐である。配列は位置1〜8の順。

- 波縞: `[#97d3cb, #97d3cb, #feee97, #feee97, #97d3cb, #97d3cb, #f09882, #f09882]`
- M/W字: `[#e66079, #e66079, #e66079, #ffffff, #ffffff, #ffffff, #ffffff, #e66079]`
- ハート模様: `[#fefdf9, #fefdf9, #fefdf9, #fefdf9, #7c8acb, #734c79, #fefdf9, #fefdf9]`

## 必須実装

- 安定した唐八つ組IDを追加し、8本用結果一覧へ表示する。
- 八つ瀬組とは別の移動規則と表面パターンを持つ。
- 独立資料で確認した1周期を順序付きイベントとして実装する。
- 波縞、M/W字、ハート模様を色名や色数へ依存せず生成する。
- 平紐Viewerと素材基盤は再利用し、唐八つ固有の周期と面対応だけを個別化する。

## 必須テスト

- 8本以外では候補に出ない。
- 1周期・複数周期で糸IDを保存する。
- 3つの参考フィクスチャが期待する異なる空間シグネチャを持つ。
- 1位置だけ色を変更したとき、その位置に帰属する表面だけが変わる。
- 表裏、左右縁、タイル継ぎ目、端面なし、保存往復を検証する。

## 完了条件

- 唐八つ組が八つ瀬組とは別に選択・保存できる。
- 3つの参考模様を同じ位置別表面生成で再現できる。
- 8本用4方式を結果一覧で比較しても操作と保存が安定する。
