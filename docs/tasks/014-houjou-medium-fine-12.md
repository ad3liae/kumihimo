# Task 014: 方丈組（中細）12玉の完成シミュレーション

- 状態: Ready（標準方丈との差と移動規則の独立資料照合が必要）
- 優先度: 中
- 前提: Task 013が完了していること
- 仕様: `docs/specifications/braid-preset-expansion.md`

## 目的

参考シミュレータで標準方丈とは別方式として扱われる「方丈組（中細）」を、独立した12本用プリセットとして追加する。

## 参考出力

参考方式IDは `houjou2` で、標準方丈の `houjou` とは別の表面図形を持つ。直線フィクスチャの位置1〜12は次のとおり。

`[#ddaaee, #ddaaee, #333388, #ffeeff, #ffeeff, #333388, #ddaaee, #ddaaee, #333388, #ffeeff, #ffeeff, #333388]`

## 実装前の必須確認

「中細」が次のどれを意味するかを、独立資料または実物で確認する。

- 玉ごとの糸束太さの違い
- 断面の縦横比または各面幅の違い
- 標準方丈と異なる移動規則
- 表面パッチ幅だけの違い

確認できない場合、標準方丈を単に細く表示したものとして実装せず、未確定点を報告する。

## 必須実装

- 標準方丈とは異なる安定したプリセットIDを追加する。
- 12本用結果一覧で「方丈組」と「方丈組（中細）」を区別して表示する。
- 確認した差をDomainの移動規則、表面区画、断面プロファイルの該当箇所へ明示的に保持する。
- カメラ倍率やViewのscaleだけで中細差を作らない。
- 直線フィクスチャを位置別配色から生成する。
- 保存済みの標準方丈IDを中細へ読み替えない。

## 必須テスト

- 12本以外では候補に出ない。
- 標準方丈と中細のID、表示名、生成結果が異なる。
- 確定した中細差が数値または表面シグネチャとしてテストされる。
- 直線フィクスチャが期待する面と周期へ現れる。
- 糸ID保存、端面なし、長尺境界、Viewer操作、保存往復を検証する。

## 完了条件

- 方丈組（中細）を標準方丈とは別に選択・保存できる。
- 中細の意味と実装箇所が完了報告に明記されている。
- 直線フィクスチャを参考出力と比較できる。
- Task 007〜013および丸源氏に回帰がない。
