## 3. まず局所の重なりを成立させる

長い紐を描いて遠目の印象だけで選ばず、**中央のV字と隣接するV字が見える数束**で始める。
製品と同じ糸ID・配置・メッシュから取り出し、後で製品につながらない別の絵を正解にしない。

比較する表示:

1. 生成り単色、糸筋なし。形と輪郭を読むため、照明と素材条件を候補間で固定する。
2. 束を区別する診断色。V字の両側が別の糸であることと、どちらが上かを読めるようにする。
3. 上の形に通常の素材を戻したもの。

診断色は、可能な局所配置で作者の黒・黄・赤・青に対応させ、図のどの束を描いているかが分かるようにする。
実際の糸IDと配色の対応から生成し、図に合わせるために同じ糸の途中だけを別色に塗らない。
全周をこの4色の繰り返しにする指示ではない。

満たす形:

- 越える束の幅のある面が交差部へ続き、下の束を実際に覆う。
- 潜る束の輪郭は、上の束の輪郭に隠れて途切れる。両方の丸い端面を横に並べて接するだけにしない。
- 交差部で、続く輪郭と隠れる輪郭の差が分かる。暗い線だけで先後を描かない。
- 見えている束の流れが、各パッチの境界で四辺のある粒へ切られない。
- 同色でも重なりが分かり、別色にすると糸の所属が矛盾しない。
- 横から少し回しても、板の浮き・切れた端・隙間が露出しない。

現行はパッチの両端から中心線と幅を作り、長さ方向に補間した表面へ半径方向の山を付けている。
`overCrossingLap` の延長と断面指数だけで上記を作れない場合は、
**見える区間の中心線・幅・端の輪郭・潜る位置の作り方を見直してよい**。
必要な範囲で丸源氏の描き手へ局所曲線や幅の変化を導入する。端の丸め量だけを繰り返し調整しない。
色の正本と糸IDを保ちながら、描画用パッチの境界を実物の糸の終端と同一視しない形にする。

局所比較には、越える束と潜る束のID、輪郭が隠れる位置を注記した画像を添える。
**影と糸筋を外しても、作者の図と対応する重なりが読めることを先に確認する。**

**丸源氏組として採用できるかは、作者の判断**。私が見て残る差:

3. 潜る束の端が、越える束の縁からごく細く覗く所がある（N3 で減ったが残る）。
4. 糸筋は画面の上半分で弱い（前回からの光の側の差、未切り分け）。
