## 3. 一覧と立体の一致検査を先に直す

`KumihimoTests/RoundTube8CardAgreesWithSolidTests.swift` の
`theCardShowsWhatTheSolidShowsAcrossARepeat` に加えられた下地の除外は、報告と条件が一致しない。
現在は両者が `.beneath` で `centerlineStart.x` が同じなら除外する。
**同じ列というだけで、一致する標本も、境界から離れた異なる升の取り違えも通り得る。**
リピート番号、長手位置、隣接する升の共有端点を確認しておらず、「境界ちょうどの3点」へ限定する条件ではない。

- まず現行データで、通常比較・既存の形状誤差による除外・今回の下地境界による除外を数える。
- 一致した標本は比較済みへ数える。追加除外が必要なら、**実際に隣接する二つの下地セルの共有境界上**であることを確かめる。
  リピートを含む座標へ直して判断し、許容幅を数値誤差に限る。
- 境界そのもの、境界のすぐ両側、同じ列の離れた別セル、リピートの継ぎ目を小さな試験で区別する。
  少なくとも、同じ列の内部点で異なる糸IDへ取り違えた例を検査が拒むことを示す。
- 除外率の上限を残し、理由別の件数を報告する。実装に合わせて比較点を減らしたり、許容範囲を広げたりしない。

意図的に製品を壊して全件を失敗させる必要はない。誤った入力を与える通常の回帰試験で拒否を確認する。

5. 一致・不一致と根拠を試験・文書で固定する。未照合だった「対の中の先後」に何が言えるようになったかを結論として書く。

## 5. 最終版を測り、その結果で外観を仕上げる

### 5.1 比較条件と測定をそろえる

048の比較シート `new-vs-sketch.png` は写真とレンダーの紐幅がそろっていない。
まず、写真と製品画像を**紐そのものの輪郭幅 D**で合わせる。縦横比を保つ一様拡大縮小を使い、画像枠の幅を基準にしない。
向き、見せる長さ、撮影角度、拡大率を記録し、以後の候補比較は同じ条件で行う。

測る対象は別々にする。

| 対象 | 読み方と必要な記録 |
| --- | --- |
| 見える束の長さ・幅・傾き | 写真の明瞭な束を数個選び、輪郭と長軸の端点を示す。長さ/D、幅/D、紐軸に対する傾きを製品と比較する。046の読み取り点は再利用できるが、現行製品を測り直す。 |
| 同色の帯の向きと周期 | 同色の束の対応点を複数列でたどる。束1個の傾きや糸筋の方向を測っていないことを画像上で示す。写真と製品で軸・符号を統一する。 |
| 腹・肩・潜り込み・外周 | 幅をそろえた切り抜きで比較する。外周の起伏をそのまま谷の深さとみなさない。写真から読めない厚みは宣言値として扱う。 |
| 糸筋と光沢 | 大きな形と別に、線の密度・強さ・向き、明暗の出方を比較する。作者の塗りの往復線を繊維の指示とは扱わない。 |

S写真を主とし、Z-aの同色2束を1束と誤読し得る箇所や隠れた端は、不確かな観測として区別する。
旧尺度0.403の候補Bの+38°と写真の+53°だけで、最終尺度0.807の帯の角度が確認できたとはしない。
自動測定が束へ吸着したり列数で量子化したりするなら、明瞭な対応点を画像に記入して測る。
手法を複雑にすることより、何を測ったかが人に確かめられることを優先する。

作者の図から厳密な角度は採らないが、**束の長軸と色の帯がどちらへ傾くか、その関係**は照合する。
判読しづらい箇所は特定する。「模式図だから関係を一切確かめられない」とはしない。

### 5.2 形を直してから質感を整える

- 測定に基づき、束の腹のふくらみ、肩、隣へ潜る端、外周のつながりを調整する。
  端ごとの独立した粒や、平たいタイルの列へ戻さない。色帯の半ピッチと1束ごとの交替を崩さない。
- 048では既に腹の位置・幅・潜り込み長を変更している。「046のまま」と一括りにしない。
  今回は残った形状関数・高さ・材質のどれを変え、どの観察へ対応させたかを書く。
- 基準と少数の候補（まず最大2案）を同じ条件で比べ、改善のある案を選ぶ。
  長手の尺度や配置を再び動かす必要が出たら、写真の周期との関係も再計算し、理由を記録する。
- 次に8本の描き手の糸筋・陰影・光沢を調整する。丸源氏から借りている共通素材を直接変えて16本側へ波及させない。
  新しい物理計算、大規模な素材基盤、細い繊維を大量に作る方式は追加しない。

最終候補で、作者配色・書籍配色・生成りのS/Zを一覧と立体で確認できる比較を残す。
単色でも束の連続が読めること、2色で旧来の2束ブロックや帯の断絶が戻らないことを確認する。
改善できなかった差があれば比較画像と試した変更を示し、単に「未解決のまま」と繰り越さない。
