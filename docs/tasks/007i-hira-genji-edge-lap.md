## 中断（2026-09-06）

**このタスクは中断した。** 縁を升の格子の中で lap させても、色糸が腹の下で消えて現れる見えに
ならない。lap が紐に沿って一定になり、丸源氏の lap が交差の位置だけに出るのとは別物になる。

より深い理由は表現である。**平源氏が升の格子に起伏を浮き彫りにした「曲げたタイル」であって、
糸で作られていないこと**が根にある。糸で作られていないので、何も何の下も通れない。lap は
その上への後付けにしかならない。

`docs/tasks/007j-hira-genji-as-strands.md` で、丸源氏と同じく糸から作り直す。
このブランチはマージしない。実装した lap の仕組み（断面の弧長を越えて歩く、先細り、沈める、
継ぎ目の両側で測る距離）は 007J でも要るので、記録として残す。

## 指摘

作者の図では、縁の糸（赤）は**連続した1本**として面の外側を走り、**面の腹（青）の下へ潜って
消え、また出てくる**。作者の言葉では「左右端の紐は中央の腹の下をくぐる」。

図から読めることが2つある。

1. 赤の折り返しは青の横線の**ちょうど中間**に来ている。→ Task 007G が手番から導いた
   「左縁 = 本体の半段うしろ」と一致する。**位相は正しい。**
2. 赤は青の下へ**潜る**。→ **これがモデルに無い。**

## いまのモデルに無いもの

平源氏の表面は**1枚の布**である。断面の各位置はちょうど1本の糸に割り当てられていて、どの糸も
他の糸の下へ潜れない。縁は「同じ格子の中の、位相のずれた升」でしかなく、**潜っている箇所が
どこにも無い。** `layer = .under` は起伏を下げるだけで、別の糸の**うしろ**に置くものではない。

**丸源氏にはこの仕組みがある。** `MaruGenjiSurfaceMeshGenerator.overCrossingLap = 0.16`：
交差で上になる糸が自分の持ち分を越えて隣へ乗り上げ（`lapTaper`）、先細りして
`overCrossingLapSink` ぶん沈み、縁が下の面の上にちょうど乗らないようにしてある。

**平源氏には lap が1つも無い**（2026-09-06 に grep で確認）。

## 誰が誰の上に乗るか

作者の言葉のとおり。**面（中央）が上、縁の糸が下。** 縁の糸が潜る位置で、面の最外レーンの
升が**幅方向に外側へ**張り出して縁の糸の上に乗る。縁の糸はその下で沈む。

丸源氏の lap は糸の**長手方向**に伸びる。ここで要るのは面の升が**幅方向**に伸びる lap である。
**向きが違う。** これがこのタスクの設計上の問題である。

## 合格条件

1. **縁の糸が面の腹の下へ潜って消え、また出てくるように見えること。** 作者の図と
   bookA p97 左の作例と並べて示すこと。
2. **組紐は水密な面ではない。それを前提に番人を選ぶ**（2026-09-06、作者の指摘で改訂）。

   > 縫い付けるとか縫い付けないとか、水密である必要もない、もともと水密なものでもない。

   組紐は**別々の糸の集まり**であり、糸どうしのあいだに隙間があるのが本来の姿である。
   「メッシュのすべての辺が2枚の三角形に共有される」も「自由な縁を全部説明できる」も、
   紐を1枚の面として表していたことから生じた**表現側の都合**であって、対象の性質ではない。
   **Task 007E 段階0 で水密性を不透明性へ置き換えたのは正しく、その後も「水密」という言葉を
   引きずっていたのがレビュー側の誤りである。**

   守るべきものは2つだけ。

   - **見えてはいけない背景が見えないこと。** 段階0の不透明テスト
     （`hiraGenjiSurfaceIsOpaqueFromEveryLineOfSight`）。これが番人である。
   - **糸が糸を貫通しないこと。** lap の先端が下の糸の面にめり込まない。丸源氏の
     `overCrossingLapSink` が果たしている役目と同じ。

   `hiraGenjiSurfaceIsEdgeWatertightAwayFromItsTileEnds`（`interiorBoundaryEdges == 0`）は
   **平源氏でも退役させる。** 丸源氏で退役させたのと同じ理由で、理由をテストの跡地に書く。
   `consecutiveTilesMeetOnTheSameSurface` は「隣のタイルと隙間なく続く」という別の性質なので
   残す。

   **わざと lap の沈み（sink）を 0 にして、不透明テストが落ちる（または貫通が検出される）
   ことを確認すること。** 番人が発火することを確かめない限り番人ではない。

3. Task 007G/007H の合格条件がすべて通り続けること（縁の位相／段の乱れ無し／矢絣・はしご）。
4. **Task 007E で決めた定数が1つも動いていないこと**（3.3359 / 0.3665 / 0.45 / 弧長分割 /
   `faceStitchLean = 0`）。位相の値も変えないこと。
5. 丸源氏のメッシュが**1頂点も変わっていない**こと（ハッシュで示す）。

## 着手前の確認で分かったこと（2026-09-06）

- 断面の歩き方は変える必要がない。`crossSectionPoint` は弧長パラメータを一周として扱い、
  `regionU > 1` はそのまま隣の領域（縁）の弧の上へ出る。**幅方向の lap にはこれがそのまま
  要る。**
- lap は u（幅方向）で、007H の切り取りは v（長手）なので、**lap はタイル端へのはみ出しを
  増やさない。** 007H の仕組みで足りる。
- 副作用が2つある。どちらも「u が [0,1] の外に出る面」に合わせて定義を直すこと。
  - `boundaryDistance = min(x, 1−x, y, 1−y)` が u<0 / u>1 で負になり、lap 全体が境目の色群
    （暗い溝）へ入る。
  - `SharedRimAudit` の縁の判定 `textureCoordinates.x < 0.001 || > 0.999` が lap の内側を縁と
    誤判定する。
- lap の量の候補は2つ。丸源氏の 0.16 を糸幅へ換算した **0.21**、等径の丸い糸2本の幾何から
  **0.5**。2.4倍の開きがある。**両方をレンダーし、bookA p97 左の作例と紐幅を揃えて並べて
  選ぶ。目で合わせにいかない。** 選んだ値の根拠を定数のコメントに書く。

## やらないこと

- 位相を触ること。007G の値をそのまま使う。
- 「潜って見える」ために配色や陰影でごまかすこと。**幾何で重ねること。**
- 面の中央に lap を入れること。面の中央には交替が無い（Task 007E 段階3）。**lap は面と縁の
  境目だけ。**
- 丸源氏に触れること。
