## 何を確かめるか（同僚の指摘、2026-09-15 夜）

040 の 48 手完走で確かめられたのは「**各手の終了時（settle 後）に許容値を超える貫入が無い**」までで、「**途中ですり抜けていない**」は
確かめていない。運びの判定は数回の緩和のあと、縁の出し入れを最後にもう一度した後に変更前の値で合格を決めている。運び後の張りの
置き直しは経路を変えうるが検査していない。回復できない失敗は端を目的地に置いて続けている。そして**交差が裏返って見える**（先の手の
糸が後の手の糸の上に来る）候補がある——同じ交差のすり抜けなのか、交差の移動・消滅なのか、計測上の取り違え（手番号の付け替えを含む）
なのかが分かっていない。
`REST=held` はこの裏返りで生じた詰まりを完全固定で避けたもので、緩い形の原因候補でもある。だから、押し付けを足す前に、
**裏返りの正体と、検証の抜けを直す。**

## 3. 検証の抜けを塞ぐ（模型は変えない。041-2。**041-1 の結果を受けて書き直し、同僚の 7 回目の指摘で 0 項と検査の定義を足した**）

**検査の定義**（同僚の指摘 2）: 1 回の位置更新の前後の 2 つの状態を、**固定端からの弧長で対応させ**（両状態の弧長の和集合の上で。
`follow.py` の `common()`）、対応した点どうしを**線形に補間した道**の上で見る。置き直しは折れ線の角を切って幾何を変えるので、この道は
「材料が止まっている」ことを意味しない——**弧長の対応と線形補間は検査上の定義**であって、模型の道ではない（射影は瞬間の置き換えで、
途中の道は模型に無い）。**保証するのは「この道の上で中心線が交わらない」ことと「採用した状態の太さ」だけ**で、途中も太さを保つことは
保証しない（それを保証するのが C-IPC の厚みの扱い。ここでは入れない）。

検査は 2 つに分ける。**中心線の通り抜け**（2 本の線分の中心線が同じ時刻に触れ、両側で符号付き距離の符号が変わる）は**位置を変える全部の
遷移**で見て、**0 であるべきもの**。**太さの食い込み**（線分間距離が d − 0.02 d を切る）は、張りの縮めと置き直しが射影の前に毎 sweep 作り、
settle が解くものなので（041-1: 3 手目で 595 区間対・最小 0.941 d、手の終わりの (a) は 0）、**合格にする状態（運びの各刻みの settle 後、
張りの各 sweep の settle 後、手の終わり）で判定する**。途中の最小値は記録するだけ。

0. **検査器を直し、3・6・7 手目を再確認する（最初に。これが済むまで 3 節の残りに進まない）**: `follow.py` の `ccd` は、二分の反復の上限
   （`DEPTH + 1` 回）に達したときに残った区間を初期値の「安全（certified）」のまま返す——未確定にする条件「区間幅 < 2^−26」を調べる前に
   反復が尽きる（同僚が人工の 2 線分の交差例で再現: 途中で中心線が交わるのに標本の最小距離 2.8e−6 d で「安全」。審査側も再現: 1 遷移
   300 d の速さの交差で 100 例中 11 例が「安全」。組紐の走りの遷移は d/4 以下なので実際に見逃した証拠ではないが、証明器としては
   使えない）。**上限に達して残った区間は未確定（2）にする**。直したら、人工の交差例（速さを振る）で「安全」が出ないことを確かめ、
   **3・6・7 手目の対象の対を再確認**する。041-1 の「接触 0、未確定 0」はそれまで撤回。再確認で未確定が出たら、そのまま報告する。

1. **縁の出し入れの後に再判定する**: 出し入れで折れ線が変わる（取り込みは線分を差し替える。**1 回の呼び出しで取り込みと繰り出しを
   両方することがある**ので、前後は球の番号ではなく折れ線どうしで比べる——041-1 の 5）。出し入れのあとに settle・貫入・跳びを測り直し、
   その値で合格を決める。**未検査の状態を合格にしない。**
2. **運びの中の中心線の検査**: 運びの**各位置更新**（端の移動、縁の出し入れ、弛み取りの縮め・MOST の切り詰め・間隔・押し離し・押し出しの
   各呼び出し）について、更新の前後の状態のあいだで中心線の通り抜けを検査する（両状態を線形に結び、保証付きの下限 D(t) ≥ (D(t0) +
   D(t1) − M Δt)/2 で二分。`follow.py` の `ccd` をそのまま使ってよい）。**対象は全部の自由な糸の全部の線分対**で、候補は「動いた区間の
   移動範囲（前後の位置を含む箱を d 広げたもの）が重なる対」から選ぶ。通り抜けが 1 対でもあれば、その刻みを戻して刻みを半分にする
   （現在のやり直しと同じ扱い）。**未確定（2^−26 まで割っても下限が閾値を越えない）も通り抜けと同じ扱いで戻す**——合格に未確定を入れない。
3. **張りの中の中心線の検査**: 張りの**各位置更新**（縮め、置き直し、間隔、押し離し、押し出し。置き直しは前後の折れ線のあいだ）で同じ検査を
   置く。張りには刻みが無いので戻せない——通り抜けか未確定が出たら、**その手の始めの状態と直前の状態を保存して止まる**（止まる条件 (b)）。
4. **回復できない失敗**: 刻みが 0.02 d を切ったら、**直前の有効な状態（その手の始めの状態と、最後に合格した刻みの状態）を pickle で保存し、
   理由（脚・位置・判定値）を書いて実行を止める**。端を目的地に置いて続ける分岐は消す。
5. **監査の直し**（挙動は変えない。041-1 の修正案 1・2、同僚の指摘 3）: 手番号の順で数える `audit.py` の候補は診断に使わない。
   `crossings.py` は旧監査の候補を先に選んでいるので、**その絞り込みを外し、交差そのものを数える**——各状態で、全部の糸の対の折れ線の
   平面の交差（線分どうし）を、上下（どちらが上か。高さの差）と両方の手番号つきで列挙する。「交差にある候補の数」は交差の数ではない。
   手をまたいで同じ交差を追うときは `follow.py` の対応（固定端からの弧長）で結び、**同じ交差か決められなければ「未確定」として残す**
   （反転 0 に数えない）。各手の行に、交差の数、**前の手からの向きの反転の数、未確定の数**、端から外れて消えた交差の数を足す。反転が
   1 つでもあれば止まって報告（(a) の証拠か、模型の問題）。
6. 記録の各手の行に、途中の検査の結果（検査した遷移と対の数、中心線の通り抜け・未確定の数、途中の太さの最小値）と、合格にした状態の
   太さの判定を足す。検査の計算が重ければ、その旨と 1 手の時間を書く（止まる条件 (c)）。
7. **入れないもの**: 球ごとの手番号を `cover` に使うこと（固める判定が変わる＝模型の変更。判定の 4）。`REST`・閾値・縮めの値・乗られ判定・
   送りは変えない。

## 2. 道具と、場所の対応

  検出、区間が 2^−26 より短くなれば未確定。閾値は**中心線（1e−6 d 未満を接触、その前後で線どうしの符号付き距離が変われば通り抜け）**と

## 審査側の再現（cloud、`follow.py` の `ccd` をそのまま呼ぶ）

固定した線分 A（x 軸上）と、z を一定の速さで下る線分 B（y 軸方向）。交わる時刻 t* を二進で表せない値に振って 100 例ずつ。速さ 2・10・
50・100 d／遷移では 100 例とも「検出」。**速さ 300 d／遷移で 100 例中 11 例が「安全（certified）」**——標本の最小距離 1.1e−6 d（閾値
1e−6 のわずか上）で反復が尽き、未確定にならずに戻る。組紐の遷移は MOST = d/4 以下なので、この走りで見逃した証拠ではない。だが証明器
としては使えないので、041-2 の 0 項で直してから再確認する。
