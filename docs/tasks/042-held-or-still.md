## 何を確かめるか

040 の `REST=held` は、乗った区間（自由部の固定端側で固定球に触れている区間）を settle でも動かさない。これは 040 の最初の意味
「縮めないが押されれば動く（`REST=still`）」からの**模型の変更**で、041-2 の 9 手目の詰まり（根元が頭に引きずられ、裏返った交差の下で
解けなくなった）を避けるために入れた。同僚（4 回目・12 回目の指摘）: 完全に動かさない拘束が**詰め直しを妨げている**可能性がある。
現行のピッチは 4.02／3.04 d で、旧結果の 4.8 d を理由に押し付け不足とは言えない。**この実験は「動かさない拘束が詰め直しを妨げて
いるか」を 1 条件の差で確かめる**——押し付け（A1）や固定を遅らせる（③）を入れるかは、結果を見て決める。

**1 条件にするために**: `probe.py` の送りは `REST` で分岐している（`REST=still` は固定部と芯だけを下げる旧方式に戻る。`send` の
`if not REST_HELD(): return super().send()`）。**両条件とも「組み上がり全体を一緒に下げる」現行の送りを使う**（送りの分岐を外す）。変えるのは
**乗った区間を射影（間隔・押し離し・台の押し出し）で動かせるか**だけ。縮めと置き直しを受けないのは両条件で同じ。

## 042-0. 検査器の縁側の角落としを直し、041 の結論への影響を確認する（最初に。これが済むまで 1 以降に進まない）

同僚の 12 回目の指摘: `follow.py` の `common()` は前後の**短い方の全長**で分割点を切っている（`hi = min(pre.u[-1], post.u[-1])`、
`U[U < hi]`）。その先にある長い側の角は落ち、最後の縁の点へ直結される。人工例（同じ球数・同じ両端・最大変位 0.2 d）:
更新前 `[(0,0,0),(1,0,0),(2,0,0),(2.01,0,0)]`、更新後 `[(0,0,0),(1,0.2,0),(2,−0.01,0),(2.01,0,0)]`、相手 `[(2,−0.01,−1),(2,−0.01,1)]`——元の折れ線は接触
（0 d）、`common()` 後は 0.00971 d、CCD は「安全」。**審査側も現行の `follow.py` で再現した**（更新後の角 u = 2.0416 が hi = 2.01 の先で落ちる）。

- **直し**（検査上の対応の定義）: 分割点は**両状態の全折れ点と両状態の縁の端点**を含む（切らない）。短い方の全長を超えた位置は、
  その状態の縁の点に留める（繰り出す前／取り込んだ後の材料は縁の点にある。`np.interp` の端の値そのまま）。**両端状態の折れ線の形が
  保たれる**ことを確かめる。審査側が人工例で確かめた: この作りで更新後の距離は 0 d、CCD は「検出」。取り込み（後が短い）の向きも同じ。
- 直したら `ccd_check.py` にこの例を**繰り出し・取り込みの両向き**で足し、既存の例が全部通ることを確かめる。
- **元の走りを再検査する。再生する解法と設定を明示する**: 040 の基準結果は**当時の上限なし・当時の処理順**、cap48 は**上限 d/4・
  出し入れ後の settle を含む処理順**。各手の再生結果は保存状態と**球数・座標が一致**すること。一致しない走りを元の走りの再検査として
  扱わない。検査のために刻みを変えた新しい走りと、元の走りの再検査は区別する。
- 順: (a) 局所の 3・6・7 手目と保存した 31 手目（`start-h31.pkl`）→ (b) cap48 の 48 手 → (c) 040 の基準結果 48 手（(b)(c) は各 30〜45 分）。
- **31 手目の上限なしは、既知の通り抜けを検出するための対照**。検出されることが期待結果であって停止理由ではない。検出できなければ
  止まって原因を確認する。同じ開始状態の d/4・d/8 も確認し、件数の変化を記録する。
- **上限つき（cap48）や基準結果で新しい接触・未確定が出たら、前後の状態と検出箇所を保存して報告し、042-1 以降に進まない。** 出なければ
  「縁側の角も残した検査で通り抜け無し」と初めて言え、042-1 へ続ける（承認待ちはしない）。

## 042-2. 送りを共通にした held／still の比較

1. **`REST=still` の送りを現行の送り（全体を一緒に下げる）にする**（`probe.py` の `send` の分岐を外す）。変えるのは乗った区間を射影で
   動かせるかだけ——**縮め・置き直し・固定判定・上限・検査条件は共通**。分岐を外したあと、**`REST=held` の 1〜4 手目が cap48 と球ごとに
   一致する**ことを確かめる。不一致なら原因を調べて報告する。
2. **`REST=still` を検査つき・上限 d/4 で、まず 1〜12 手**。040 の実験②（`REST=held` を入れる原因になった 9 手目の詰まり: 送りの中の張りで
   残差 0.33／0.40、0.4 d の貫入）が今回の条件でどうなるかを見る——**041-2 の 31 手目の 1.7 d の跳びとは別の現象で、「上限があるので
   引きずりは消える」とは断定しない。** 詰まり（settle の上限到達が続く、(a) > 0.02 d、止まる条件）が出たらそこで止めて報告し、以前と
   同じ原因かは保存状態で確認する。
3. 通れば**その保存状態から 48 手まで続ける**（検査つき、上限 d/4、1 手ずつ前で、`PICKLE`）。held の 48 手は、再検査済みの cap48 を対照に使う。
4. **両条件を並べる**（042-1 の測り方で。ピッチはサイクル単位、実測値と変更内容をそのまま。1 件から誤差幅を出さない）: ピッチ、固めた球、
   乗られて固まらない球、外径、断面（固定球・自由球を別欄）、1 d の高さの球、交差の数と反転（追跡の未確定は別欄）、(a)、**残差、収束
   （settle の回数と上限到達）、接触・未確定**、上限が働いた手と球数、時間。
5. **乗った区間の移動量は settle の前後で測る**（各手、乗った区間の球の変位の最大と中央値。held では 0）。**送りの一括下降や球の追加・
   削除と混ぜない。** 「詰め直し」が起きたなら、どこで（天辺／脇／根元）起きたかを 1 d の高さの球数の変化で示す。
