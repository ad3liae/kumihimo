### 測定値の取り違えを繰り返さない

- Task 032の36°は**単位どうしの歩幅・格子のずれ**であり、糸束自体の長軸角ではない。36°をそのまま傾斜角へ入れない。

- Task 038の交互の傾きは丸源氏の結果。角度12.4°や横へ1.333升という値を八つ金剛へ持ち込まない。
- 丸紐の輪郭のさざ波から、谷の深さを逆算しない。写真から決められない量は未確定と書く。
- 写真から角度などを新しく測る場合は、測定区間・軸・投影補正・読み取れない範囲を残す。目で選んだ値は `.declared` とし、`.observed` や `.derived` にしない。

### 045-1: 糸束の形を変える（素材と照明は固定）

最初に、数周期ぶんの局所形状で、次を満たす構成を確かめてから長尺表示へ接続する。

1. **表面に見える区間の中心線を斜めにする。** 周方向への変化を持たせる。S/Zの形は向きの取り決めに沿う鏡像にする。
2. **区間の中央は幅を持ち、端はすぼまりながら隣の下へ沈む。** 端は切れた糸の端ではなく「見える区間の終わり」。端面を見せたり、丸い粒を独立して並べたりしない。
3. **接続相手と覆う相手を区別する。** 隣り合う升は別の糸の場合がある。同色だから、または同じレーンだからという理由で糸を接続しない。糸ID・色の帰属は現行の履歴から保つ。
4. **境界を隣と整合させる。** 区画を個別に傾けただけで生じる穴、突き抜け、面のちらつき、周期境界の段差を残さない。裏面表示や黒い線で隠さない。

曲線、幅、断面、沈み込みの具体式は実装担当が、小さく検証できる構成を選ぶ。
全面的な糸経路の再構築や物理による接触計算は要求しない。見えない内部の完全な幾何も今回の目的ではない。
ただし、どの区間がどの糸で、何の下へ隠れるかは説明できるようにする。

導出が傾斜量や局所の重なりを一意に決めない場合は、決めたと装わず、描画上の近似として明記する。
傾斜量、幅の変化、沈み込み量を隠れた定数にせず、意味と単位を持つ少数の値にする。
最初は従来の断面の高さを維持して比較し、扁平化が必要ならその効果が分かる比較を追加する。
Task 033の端の2値は新しい形に対して再較正可能だが、値だけを動かして完了にしない。

**形だけを変えた結果でも、単色で斜めの糸束と隣への潜り込みが読めること。**
改善が見られない場合は、素材の変更で覆い隠さず、形の案と失敗箇所を画像で報告する。

### 045-2: 接触部分の影を調整する

045-1と同じ形で、四辺を均等に囲む陰を見直す。
上に出る肩、下へ隠れる端、横で接する部分を区別し、形と対応する位置へ影を付ける。
照明と露出を変更前から固定し、全体を明るくしただけの比較にしない。
共通の素材生成器を変更して他の族を動かさず、まず8本側で対応する。

糸筋の座標・法線・接線は、新しい糸束の向きへ追随させるために必要な範囲で修正する。
同じ糸の見える区間と周期境界で筋が不自然に切れないことを確認する。
**本格的な絹の艶の作り直しやランダムな毛羽の追加は次の候補とする。** 今回は形と接触影の改善を分離して判断する。

### 045-3: 製品表示と比較資料を揃える

候補をS/Zの詳細表示と一覧サムネイルへ接続する。模様図の糸IDと配色は変えない。
比較専用の切替を本番UIへ追加しない。変更前・途中・最終の画像を再現できる手段を記録する。

比較資料は `.build/task045/` に置き、次の3状態を明記する:

- A: 今回の開始コミットの描画。
- B: 形の変更後、従来の陰影設定。
- C: Bに接触部分の陰影変更を加えたもの。

S/Zそれぞれ、生成り単色と本の配色を用意する。正面に加え、長軸回転30°・60°・90°を同じ条件で比較する。
裏側も含め一周回して、特定の方向だけで成立していないか確認する。
