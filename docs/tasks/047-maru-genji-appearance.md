## 4. 047-1: 束の肩と潜り込みを整える

現行 `RoundTube16SurfaceMesh` は半楕円の断面、越える側の張り出し、くぐる側の沈みを持つ。
この仕組みを使い、**端で急に切られた部品の印象を減らす**。
初手は次のような局所変更を推奨するが、式はClaude Codeが小さく検証できるものを選ぶ。

- 束の幅と高さが端へ向かって緩やかに移る形にし、肩の直線的な段差を和らげる。
- 越える側の幅のある面と、隣へ隠れる端を区別する。露出した先端で糸が途切れないようにする。
- 断面を変えるなら、幅を保った柔らかな膨らみを比較する。全面を平板にして谷を消さない。

**基準＋最大2つの形の候補**まで。形の比較中は素材・照明を固定する。
最初は `crestHeightRatio = 0.12` と `patternAspectRatio = 0.65` を保ち、
端の移り方を変えた効果を分ける。単純な頂の増量を第一案にしない。
なお高さ・幅の分布を変えると、設定値を固定しても見かけの紐幅は変わりうる。
候補ごとの外径・山形ピッチを同じ定義で確認する。

資料と比べても高さや縦横比の見直しが必要なら、第二候補でのみ、その組を明示して比較してよい。
その場合はTask 005I/Jの密度との関係を記録し、既存の較正を更新したことを明記する。
写真の輪郭のざらつきから畝の高さを逆算しない。読めない3D寸法を確定値にしない。
山形密度の旧数値を使う場合は、外径の定義と投影補正が同じか確認する。

配色や周方向の列数、占有履歴、時計、糸IDの対応、現在の交差の先後は維持する。
写真と似せるために同色の束を結合したり、糸IDを付け替えたりしない。
現行の交差規則は外観上の近似であり、本タスクを通っても物理的に正しいとは主張しない。

## 5. 047-2: 細い糸筋へ整える

採る形を決めてから、素材のみの変更を別画像として比べる。
通常倍率ではまず束の山形が読み取れ、拡大すると細い繊維が見える状態を目指す。

- 太く等間隔のうねりに見える糸筋の強さと間隔を見直す。
- 両方向の束で、束自身に対する撚りの向き・角度を保つ。光への向きによる明暗差は許す。
- 筋を細かくする場合は凹凸量も合わせて確認する。周波数だけ増やすと法線の傾きが増え、かえって強く見える。
- 接触影は束が隠れる位置に追随させる。全ての縁を同じ濃さで囲んだ黒い格子にしない。
- 色カタログ、共通照明、カメラを変えて外観差を覆い隠さない。毛羽・ランダム変形・新しいシェーダー方式は今回は不要。

素材も少数の説明できる候補で比較し、改善が小さければ元を採る。
メッシュの肩と糸筋の両方を変えた最終絵だけを提出せず、どちらが効いたか分かるようにする。

### 共通設定からの波及に注意

`RoundTube16` という名前でも丸源氏だけに効くとは限らない。

- `RoundTube8StrandTexture` は16本側の法線・粗さ画像生成を使っている。
- `Flat16StitchTexture` は16本側の谷・接触影・粗さ・糸筋の値を参照する。
- `Flat16SurfaceMesh.crossingRelief` は16本側の `underCrossingDip` を参照する。
- 平源氏の撚り角などにも16本側からの参照がある。

変更する値の呼び出し元を調べ、**丸源氏にだけ新しい値を渡すなど、必要最小限の分離**をする。
八つ金剛E2と平源氏の実際の出力は保つ。メッシュのハッシュだけでは素材の変化を検出できないので、
影・法線・粗さの出力も変更前後で確認する。全描き手の抽象化や全面改名は行わない。

**糸筋の強弱**: 0° と 90°（と 180°・270°）で、糸筋は画面の下半分で強く、上半分で弱い。**画面の位置に固定されて見える**。

### 7. 実メッシュでの確認と回帰

- **色で形が動かない**: 16本すべて青の場合と、糸3だけを桃にした場合とで、頂点・法線・テクスチャ座標が一致する。桃の頂点が属する帯の集合が、糸3の帯の集合と一致する（`aColouringMovesNoVertexAndOnePositionRecoloursOnlyItsOwnThread`）。
- **先端が誰の下へ隠れるか（中心線ではなく実メッシュ）**: タイル中央 60% にある越える糸の、重なりの先端（along = 1.32 / −0.32）の頂で、半径 0.03 以内に**別の糸の頂点がより高く**ある。糸自身の端（along = 0 / 1）の頂では、0.01 以内に自分より高い別の糸がない（`everyLapTipEndsBeneathAnotherStrandWhileItsEndStaysOnTop`、先端・端とも 8 か所以上）。**頂の線上での主張で、全幅・全経路は主張しない。**
- **影の位置**: 越える糸の 0…1 には接触の陰がなく、重なりの先端で最も暗い。潜る糸は両端が最も暗く、中央にはない（`aStrandIsShadedWhereItGoesUnderAndNotWhereItLiesOnTop`）。

- 穴・端面・外向きの面・有限な法線・長手と周方向の継ぎ目: 既存の `MaruGenjiSurfaceMeshTests`（有限・非退化・単位法線、谷で隣と接する、タイル境界と周方向の継ぎ目が一致、越える糸だけが段差を塞ぐ）と `BraidSurfaceWatertightnessTests` が通過。目視で、final の 5 方向 × 4 配色に穴・継ぎ目・ちらつきは見えない（`sheets/turns-*-final.png`）。

### 11. 採否の判断と残る差（見た目の最終採否は作者）

**合格の中心として見たこと**: 同じ表示条件で、M0 の「角の丸い部品が四辺を暗く囲まれて並ぶ」印象が弱まった。束が隣に重なって続き、先端が次の束の下へ潜って見える。単色（生成り・青）でも同じ。
通常倍率では山形の配色が M0 より読みやすく、拡大しても糸筋は細い。どちらが効いたか: **形（G1 の重なり、G2 の断面）で部品の輪郭が減り、素材（層ごとの影と谷の陰）で格子の縁取りが消えた**。

**残る差・悪化した点**:

1. 写真の束は**細く（紐幅の約 0.17 対 0.25）、軸に沿って寝ている（約 21° 対 40°）**。傾きは模様の縦横比の較正（005I）と結びついており、047 の範囲（0.65 を保つ）では動かしていない。次に変えるなら、縦横比と束の幅を同じ定義で読み直すのが先。
2. 糸筋は、画面の下半分で強く上半分で弱いまま。回転では光と腕の向きを分けられなかった。**光の側で分けるなら、共通照明を変えずに1本だけ回した診断が要る**。
3. 越える糸の頂には接触の陰が付かなくなった。そのため**単色では交差の奥行きが M0 より平たく見える所がある**（`all-states-plain.png` の F2 と M0）。影を戻すと格子に戻るので、ここで止めた。
4. 重なりの先端はテクスチャの解像度が 1.64 倍に薄まる（同じ 512 列で重なりまで覆う）。通常倍率・拡大で目立つ段差は見えない。
5. 写真の輪郭のざらつき・毛羽・糸の割れ目の暗さは描いていない（今回は不要とされている）。

**平源氏への申し送り**（本書 8 のまま。047 では平源氏に触れていない）: 共有の値を変えずに丸源氏専用の値を足したので、平源氏の外観タスクは同じやり方で（平源氏にだけ新しい値を渡す）進められる。
