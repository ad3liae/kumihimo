## この段の考え

**探索も反復もしない。構造は決まっているので、そのまま書き下す。**

Task 021 と 022 は、糸の置き場所を**探して**決めようとした。021 は高さを勘定で与えようとして
行き止まり、022 は台の上で組ませようとして**束が締まらず**行き止まりになった。**どちらも、
すでに導いてあるものを解き直そうとしていた。**

**すでに導いてあるもの**は次のとおりである。**どこに何が見えるか**（占有履歴、丸源氏
Task 004 と 32/32、平源氏 p97 の3実験）、**どの順で置かれるか**（bookC、1手1本）、
**長手方向のどこか**（積み重ね模型、k=3、pitch 0.375）、**断面の並び**（`BraidCrossSection`）。
**足りないのは、それを 3D の折れ線として書き下すことだけである。**

## 入力（**すべて既存の導出。手で置く値は d だけ**）

- **`BraidStand`**（32 の角度）と **`BraidMethod`**（bookC の順序、1手1本）。
- **糸の直径 d。**
- **断面**（`BraidCrossSection` の環と畳み）。表面上の各場所の座標はここから出す。
  - **丸源氏**: **正16角形、1辺 = d**（半径 d ÷ (2 sin(π/16)) = 2.5629 d。
    `docs/architecture.md`「丸台の寸法と錘」）。
  - **平源氏**: 導出した畳み。**表6・縁2・裏6・縁2**、幅は 007 系の値。
- **長手座標**（積み重ね模型）。**bookC の1手ごとに Z、場所ごとの層 × d。**
  各糸の各手について、**出発 z**（出発場所でのその時点の層数 × d）と**到着 z**（到着場所での
  到着層 × d）。**1サイクルの長さは k·d**（作者の定義）。

## 構成（**手順の順に**）

1. **留まり**: 糸 t が場所 P に留まる区間は、**P の表面座標に置いた縦の線分**、
   **到着 z から出発 z まで。**
2. **渡り**: **(P の表面座標, 出発 z) から (Q の表面座標, 到着 z) への直線。**
   **断面の内側を通る。**
3. **交差の持ち上げ**: 新しい渡り c が、先に置かれた渡り c' と**断面の投影で交わる点**で、
   c の高さが c' の高さ + d に満たなければ、**c をその点で c' の上に載せる。**
   **持ち上げの形は「直径 d の障害物を越える最短路」（接線2本と円弧）で幾何から決まり、
   自由な定数を持たない。持ち上げた量と場所を記録する。**
4. **自由部分**（描画には使わないが記録）: 最後の留まりの上端から**穴の縁（組み点の高さ）**への
   直線。
5. **出力**: 糸ごとの折れ線（中心線）と d。**021 / 022 の判定道具が読める形で書き出す。**

## 検査（**構成の後に、直さずに測る**）

- **非貫入**: 隣接しないカプセルどうしの最短距離が d 未満の対を列挙する。あれば、
  **どの区間どうし**（留まりと渡り、渡りと渡り）かを分けて報告。
  **0.1 d 未満の軽い食い込みだけなら、022 の入れ子の solver を「形を決める」目的ではなく
  仕上げ**（位置をほとんど動かさずに重なりを消す）**として使ってよい。使った場合は動かした量の
  最大を記録。それを超える食い込みは報告して止まる。**
- **反転**: **運ばれた手で数え、0 であること**（構成上 0 のはず。0 でなければ構成の誤り）。
- **面の見え**: 021 の道具で、**丸源氏 32/32**（鏡像は一致扱い、**E/W 未決**）、
  **平源氏 p97 の3実験**。**留まりが表面にあるので占有履歴と一致するはず。隙間は別に数える。**
- **記録（合否なし）**: **平源氏の膨らみ**（縦糸が横糸を越える持ち上げの高さ ÷ 幅）と **0.45**、
  **傾きの向き**（閉じ移動の1ノッチずれから出る留まりの傾き）と **Task 004 の周期2**、
  **丸源氏の見かけの山密度**と観測帯（1.8〜2.15）。
