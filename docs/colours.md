# 糸の色一覧（正本）

**2026-09-26、作者の決定**: 糸の色は、**ハマナカ アメリーエフ《合太》の30色**（色番号 501〜530）にする。
それまでの西陣の糸屋 正絹唐打ち紐の38色（Task 063、前日に入れたもの）は、作者が実機で見て「似たような色ばかりで鮮やかさがない」として
**消して置き換える**。見本配色も、いちばん近い30色へ置き換える。表示には「ハマナカ アメリーエフ」と書いてよい（作者）。

- アメリーエフ《合太》: ウール（ニュージーランドメリノ）70%・アクリル30%、30g 玉 約130m（[ハマナカ](https://hamanaka.jp/hamanaka/2458)）。
- **公式の色名は無く、色番号だけ**。下の「呼び名」は、読み上げと画面の添え書きのために審査側が付けたもので、公式名ではない。

## 色値の取り方

- 見本は作者が渡した色見本の画像（「30 colors」、毛糸玉の写真を丸く切り抜いたもの、透明の背景、655×585 px）。
  git の外の `.build/colours/amerry-f/swatch.png` に置く。**画像はリポジトリにもアプリにも入れない。値だけを使う。**
- 取り方は西陣の38色と同じ「光の当たった側の代表色」: 丸の縁 8 px を落とし、不透明（α≧250）の画素について、輝度（Rec.709）の
  55〜92 百分位の画素の sRGB 中央値。手順は `Scripts/colours/sample_amerry_f.py`。**色値は写真からの近似で、測った値ではない。**
- 見本と並べた図は審査側が作者に送った（`yarn-30-colours-preview.png`）。
