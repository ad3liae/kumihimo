# 糸の色一覧（正本）

**2026-09-25、作者の決定**: 糸の色は、西陣の糸屋の「正絹唐打ち紐」の色見本 **36色＋限定2色＝38色** にする
（<https://www.kinu.net/iro36.html>）。それまでの仮の12色（赤・橙・黄・緑・水色・青・紫・桃・茶・黒・白・生成り）は
**消して置き換える**。組み方の見本配色も、**いちばん近い38色の色へ置き換える**。

作者は、38色に鮮やかなピンク（マゼンタ）・空色（シアン）・真っ白が無いこと（江戸八つ組の教科書の色は藤色・浅葱に移り、
写真とはかなり違って見えること）を審査側から聞いたうえで、「それでも置き換える」とした。**実際に買える糸だけで配色する**前提になる。

## 色値の取り方

- 見本は紐を撮った写真（100×186 px）で、影と光沢がある。店の注記:「出来る限り正確に色を表現しておりますが上記の色見本は
  手染めによる色の誤差・モニターによる誤差がございます」。**色値は近似であり、測った値（`.observed`）ではない。**
- **光の当たった側の代表色**を取る: 縁 8 px を落とし、輝度（Rec.709）の 55〜92 百分位の画素の sRGB 中央値。
  3D とカードは基準色に陰影を足して描くので、影込みの平均（暗すぎる）は使わない。
- 手順: `Scripts/colours/sample_kinu.py`（画像は `.build/colours/kinu/` に落とす。**画像はリポジトリにもアプリにも入れない。値だけを使う**）。
- 審査側が 2026-09-25 に取った値が下の表。見本の写真と並べた図は審査側が作者に送った（`kinu-38-colours-preview.png`）。
