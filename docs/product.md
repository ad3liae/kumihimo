# Kumihimo プロダクト概要

- 状態: 初期ドラフト
- 更新日: 2026-08-23

## ビジョン

日本の伝統工芸である組紐を、実際に組み始める前に配色や完成イメージを確認できるiOSアプリを作る。

本アプリは単なる模様作成ツールではなく、利用者が「この糸の組み合わせで、どのような組紐になるか」を理解し、実際の制作で参照できる道具を目指す。

## 想定ユーザー

- 組紐をこれから始める人
- 配色を事前に試したい愛好家
- 制作案を保存し、実際に組むときに見返したい人

初期版では専門家向けの高度な設計機能よりも、迷わず新規作成でき、過去の案へ戻れることを優先する。

## 中心となる体験

1. 新しい作品を作成する。
2. 組み方、糸の本数、色と初期配置を選ぶ。
3. 完成イメージを確認する。
4. 制作案を保存する。
5. 起動画面から過去の案を開き、編集または参照する。

## MVPの範囲

- 保存作品を一覧できる起動画面
- 新しい作品の作成
- 対応する組み方の選択
- 糸の色と配置の設定
- 完成イメージの2D表示
- 作品のローカル保存、再編集、削除
- 組み方を未選択のまま、糸本数と配色だけを制作案として保存
- 保存済み作品の上書き保存と、名前をつけた複製保存
- 保存作品のサムネイル表示

対応する組み方の種類は、組紐の表現方式を検証した後に別途確定する。

## MVPの対象外

- ユーザーアカウント
- iCloudや複数端末間の同期
- SNS投稿や共同編集
- オンライン作品ギャラリー
- 編み手順の完全な動画教材
- 写実的な3Dレンダリング
- 材料の購入や在庫管理

## UX原則

### 完成結果を主役にする

装飾を増やすより、糸の色と組紐のプレビューがよく見える構成を優先する。

### 伝統性を記号化しすぎない

過度な和柄や筆文字に頼らず、落ち着きと精密さを感じる現代的なiOS UIを基本とする。

### 用語を丁寧に扱う

一般名称、組み方の名称、糸の位置を区別する。技術的な仮称をそのままユーザー向け表示に使わない。

### 制作中の安心感を守る

入力内容を不用意に失わない。削除など元に戻しにくい操作には確認を設ける。

保存済み作品を編集するときは、上書きと新しい作品としての保存を区別して提示する。配色を試している途中でも保存でき、組み方の選択を保存の必須条件にしない。

### 購入可能な色から選べるようにする

初期版では自由なカラーピッカーを使わず、名前と識別コードを持つ有限の色一覧から糸色を選ぶ。将来は購入可能な糸の商品色コードへ置き換えられる構造にする。

### アクセシブルにする

色だけで状態や選択を伝えない。文字拡大やVoiceOverでも主要操作を完了できるようにする。

## 初期マイルストーン

1. iOSプロジェクトと起動画面
2. 新規作品の基本設定
3. 組紐表現の技術検証
4. 2D完成プレビュー
5. 保存とサムネイル生成
6. MVP全体の操作・アクセシビリティ調整
